# Eleanor Story Expand
# 上层区的富家千金爱上在下层区开当铺的我：埃莉诺剧情扩展

《深空当铺：可能是偷的 / Probably Stolen》Eleanor 个人剧情线重制 MOD。

- 游戏版本：0.46D（Steam AppID 4348910）
- MOD 版本：0.6.0
- 内容尺度：全年龄
- 语言：简体中文 / English（剧情与 UI 均已翻译）

## v0.6 内容结构

- 从第 23 天起重写 Eleanor 的完整个人线，共 23 章核心剧情 + 路线丙 8 段 + 路线丁 4 段 + 第 60 天后的可选短日常。
- 主要载体是原生柜台访客、买卖、物品检视、举报、拘捕与新闻，不新建后间、通讯中心或案卷 UI。
- 关键行为会改变结果：公平收购、压价、让利、零价食物援助、假叔叔箱子、举报、警告、800 信用点调查款、数据盘保管人、保护渠道与最终公开/归还决定。
- 路线甲“把她接回来”：归还研究换母亲来到下层区，可发展完整恋爱。
- 路线乙“留下种子”：先落实保护，再处理研究；母女在下层区团聚，研究有机会公开。
- 路线丙“种子与代价”：未保护便公开，母亲遇害，Eleanor 加入革命军。
- 路线丁“生意做到这里”：擅自处置数据盘、收私钱、瞒着她公开或正常退出，关系结束。
- 朋友路线：可以救人而不恋爱；不会撤销救援成果。

## 开局时间

- **普通模式**：第 23 天开始，保留原版 Eleanor 剧情节奏。
- **提前开场（可选）**：新游戏选择 `Eleanor Story Expand · 提前开场（第 12 天）`。
  - 完整 24 章剧情从第 12 天开始，日程整体前移 11 天，约第 48 天收束。
  - 相对节奏与原版一致：调查款、声望门槛和章节间隔的可用天数不变。
  - 适合想早点进入 Eleanor 线的玩家；平衡仍在实机验证中。

## 行为与状态

- `RomanceState` 分开记录母亲状态、研究/数据盘去向、恋爱状态、工作去向与行为事实，不再用一个 true_ending 布尔值承担所有含义。
- 交易通过 `onItemBought` / `onItemSold` 读取真实成交价，并按物品基础价值判断公平、让利、抬价或压价。
- 拾荒调查款按实际收购收入累计到 800；若玩家收货不足，她会在第 42 天前用其他售货与短工补齐，不会凭空要求玩家掏整笔钱。
- 假叔叔箱子沿用原生物品与举报/拘捕流程；警告她会解除陷阱。举报和“只是起疑”是两回事。
- 数据盘由保管人决定谁能交出。玩家不保管时不能出售不存在的盘。
- 路线乙的保护渠道分别检查治安部/上层区声望与真实材料；条件不足会自动转成有完整内容的路线甲，不再只剩悲剧。
- 恋爱必须双方明确同意；朋友路线与“慢一点”都不会扣好感或撤销救援成果。
- 第 60 天后只有低频日常，不提供固定每周送钱/声望的提款效果。

## 终局奖励

- **自我补充的神经活性香水**：原版 Eleanor9 的纪念物，已恢复为终局奖励。母亲生还路线（甲/乙）在核心收束时获得；路线丙在离别时留下同一瓶香水。价值 1000、5 次使用、会自动补充，可自用或出售。
- **营养果种子解锁**：路线乙和路线丙按原版规则解除种子限制；路线甲研究被收回，不解除。
- 朋友路线也能收到香水；路线丁（背叛/退出）没有终局纪念物。
- **拾荒协助**：恋爱确认的路线甲/乙在收束后获得 Eleanor 的协助，拾荒次数 **+2**；路线丙/丁与朋友路线不追加。该效果通过 `ScavHelper.GetMaxScavAttempts` 的 Harmony postfix 生效，并尊重原版致残/0 次拾荒状态。
- 警告谢礼恢复原版二选一：便携净水器 / 信息素香水 / 婉拒。

## 安装

### 本地安装

把整个 `EleanorRomance` 文件夹放到：

```
<游戏根目录>\Mods\EleanorRomance\
```

进入游戏 → 改装件 / Mods → 启用 `Eleanor Story Expand / 上层区的富家千金爱上在下层区开当铺的我：埃莉诺剧情扩展` → 按提示重启。

### 创意工坊

订阅后，在游戏内启用并重启。MOD 会显示为 Local 或 Workshop 来源，取决于安装位置。

## 旧存档

为了不破坏已经推进到中后期的原版 Eleanor 剧情，本 MOD 默认**不会**接管这类存档。第一次开店时会出现一个“下层区档案员”事件，询问是否重置：

- **重置**：清除原版与 MOD 的 Eleanor 剧情标记，从下一次开店/过天开始重制线。已获得的物品不会消失。
- **保留原版**：本次存档继续运行原版 Eleanor 故事，重制线不会启用。

开发调试时也可以在 F9 菜单使用“重置埃莉诺剧情线”。F9 需要游戏根目录存在 `dev.txt`。

## 构建

需要 .NET SDK 与游戏 Managed 目录中的引用程序集。

```bash
cd EleanorRomanceDev
python tools/parse_v06.py        # 从 v0.6 台本生成 Content/story_v06.json
python tools/build_content.py    # 生成 StoryV06Content.g.cs 与中英 CSV
bash build.sh                    # 构建到 bin/Release，再部署到 Mods/EleanorRomance
```

`build.sh` 会在覆盖安装目录前保留一份 `dist/rollback_*` 备份，并检查 DLL 与 CSV 非空。

## 开发测试（F9）

- 游戏根目录存在 `dev.txt` 时启用 F9 调试面板和 F8 控制台；已为本机创建该文件，重启游戏后生效。
- F9 → Command 中有章节跳转预设：假叔叔、警告、救援、调查款、数据盘、威胁、方向、准备、团聚、表白、收束、路线丙/丁、后日谈等。
- `测试：准备资源` 会加 10000 信用点并拉满全部声望；`测试：打印当前剧情状态` 可查看章节、路线、母亲、数据盘、恋爱和 ScavAssist。
- 完整测试步骤、每个按钮设置的状态和验收清单见 `docs/TESTING_CONSOLE.md`。
- 调试跳章直接改状态，不能替代正常周目的经济/日程验收；请使用独立测试存档。

## 兼容与限制

- 目标版本 0.46D。版本不匹配时剧情补丁停用，但不会删除 MOD 存档数据。
- 只对原版 Eleanor 的三个剧情调度方法和游戏结束界面做 Harmony 补丁。
- 与其他修改 Eleanor 调度的 MOD 可能冲突；启动日志会记录状态。
- 本版尚未完成完整实机周目验收。新档、旧档、跨日、存读档、各结局分支仍需逐项测试。
