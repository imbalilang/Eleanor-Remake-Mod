请将高分辨率角色母图处理成游戏使用的透明 PNG，按下面的离线算法实现。

这里的“压缩”具体指：清理透明背景、按人物可见尺寸等比缩小、保留细节、处理边缘，最后保存无损 PNG。整个过程不需要重新生成或重画人物。

一、输入与目标参数

输入应使用原始母图或正确抠好的透明 PNG，避免聊天截图和有损 JPEG。

需要明确以下参数：
- 目标画布宽、高。
- 目标人物可见高度。
- 人物在目标画布中的水平中心。
- 人物底边位置。

画布大小与人物实际占用大小是两个参数，不能混为一谈。

本项目的现有流程是：
先在 288×211 画布中完成采样，再在顶部增加一行透明像素，输出 288×212 RGBA PNG。

人物可见高度需要根据目标游戏贴图或已确认的同框角色确定，不能把某一个角色的高度当成全员统一值。制作独立 PNG 不需要游戏资源键，但需要明确上述排布参数。

二、准备透明母图

保留原文件，建立工作副本。

如果已有人工检查通过的透明图，直接使用其 alpha，不要重新粗抠。

如果原图是纯洋红背景 #FF00FF，需要清除外部背景以及头发环、衣袖、手臂之间的背景空隙。这一阶段只改变 alpha，不改变母图 RGB，输出 alpha 为 0 或 255。

这次玫瑰角色采用的洋红识别方法如下，RGB 范围均为 0～255：

强背景条件：
min(R,B)>160，G<100，R-G>100，B-G>100。

弱背景条件：
min(R,B)>130，G<100，R-G>70，B-G>70。

先去除强背景；将强背景掩码做一次 5×5 最大值膨胀，再去除处于该邻域内的弱背景。

之后，仅在不透明轮廓向内 4 像素的边缘带内，清理满足下列条件的残余洋红：
R>110，B>110，min(R,B)-G>55。

以上颜色阈值适用于这类洋红底素材，需要检查是否误伤紫色头发、衣服和饰品。已经正确的透明通道优先保留。

三、确定缩放和位置

在透明母图中，以 alpha≥128 的像素计算人物包围盒：

[x0, y0, x1, y1)

注意右边界 x1 和下边界 y1 不包含在包围盒内。例如最后一行人物像素是 y=1069，那么 y1=1070。

设：
Hs = y1-y0                  // 母图人物可见高度
Ht = 目标人物可见高度
Cx = 目标水平中心
Yb = 目标底边，不包含该行
s  = Ht/Hs                  // 横纵共用的缩放系数

计算：
tx = Cx - s*(x0+x1)/2
ty = Yb - s*y1

源图坐标到目标图的关系：
目标 x = s*源 x + tx
目标 y = s*源 y + ty

通过同一个 s 保持原有头身比和人物宽高关系。不能把整张母图直接拉伸成 288×212，也不能分别修改横向和纵向比例。

四、采样前处理轮廓上的洋红污染

在派生工作副本上操作，保留透明母图。

原配方会检查距透明区域不超过 4 个源图像素的不透明轮廓带。距离按八邻域计算。

其中满足：
min(R,B)-G>24，R>55，B>55

的像素，其 RGB 替换为深灰紫色：
(48,46,50)

alpha 不变。

这是本项目的窄边缘除色配方，会修改派生图的边缘 RGB。它可能误判合法的紫色轮廓，必须查看结果；不能不加检查地套用到所有素材。

五、核心缩图：面积加权采样

本项目采用的“B/detail”是内部配方名，核心是精确计算像素覆盖面积。

对目标像素 (x,y)，它对应源图上的矩形区域：

xa = (x-tx)/s
xb = (x+1-tx)/s
ya = (y-ty)/s
yb = (y+1-ty)/s

区域总面积：
A = (xb-xa)*(yb-ya)

遍历与该矩形相交的源像素 (i,j)。
每个源像素占据 [i,i+1)×[j,j+1)。

交叠面积：
w = max(0, min(xb,i+1)-max(xa,i))
  * max(0, min(yb,j+1)-max(ya,j))

只累计 alpha≥128 的源像素：
W    += w
Rsum += w*R
Gsum += w*G
Bsum += w*B

透明像素的 RGB 不参与颜色平均，源图外部按透明计算。

前景覆盖率：
coverage = W/A

如果 coverage≥0.35：
  输出 alpha=255
  R=round(Rsum/W)
  G=round(Gsum/W)
  B=round(Bsum/W)

否则输出 alpha=0。

严格复现原配方时，直接在 8 位 RGB 数值上计算，不额外转换到线性颜色空间。非负数取整使用 floor(v+0.5)。

这样能保留细小发丝等部分覆盖的像素，同时避免透明背景颜色混入人物。

六、轻量细节增强

采样完成后，复制一份尚未增强的像素数组。所有计算都读取这份副本，避免处理顺序造成累积锐化。

仅处理：
- 不在画布最外圈的像素；
- 中心及上、下、左、右四个邻居的 alpha 全部为 255。

对 R、G、B 分别计算：

avg = (上+下+左+右)/4
delta = 中心值-avg

当 abs(delta)>6 时：
新值 = clamp(round(中心值+0.35*delta),0,255)

否则保持原值。

只执行一遍，alpha 不变。

这就是 detail 部分。不要换成任意全图锐化，也不要反复锐化来追求“像素感”。

七、游戏尺寸边缘与输出

1. 在采样后的图上，再执行一次与第四步相同的除边处理，范围改为轮廓向内 1 个目标像素。

2. 将不透明像素的 RGB 向透明区域扩展：
   - 所有不透明像素作为起点；
   - 按上、下、左、右四邻域广度优先传播 RGB；
   - 透明像素的 alpha 始终保持 0。

这是透明区域的颜色填充，可减少纹理过滤时出现黑边或彩边。不要因此把透明区域变成可见颜色。

3. 如果按本项目流程得到的是 288×211：
   创建 288×212 的全透明画布，将旧图的完整 RGBA 数据原样复制到 (0,1)。
   新增顶部一行为 (0,0,0,0)，其余像素不再采样。

   已经是 288×212 的成品不要再次补行。

4. 保存为每通道 8 位的 RGBA PNG。
   保留丰富颜色，不固定压成 32 色，不叠加马赛克滤镜，不再次缩放。

九、交付前检查

- 用原生 1 倍查看眼睛、嘴、耳饰、发丝、手部是否仍然清楚。
- 用最近邻放大 3 倍或 4 倍查看像素边缘。
- 分别放在白底、黑底、深灰底 #252C35 上检查残留洋红、暗边和误抠。
- 检查人物可见高度、水平中心、底边以及同框角色的大小关系。
- 确认 alpha 只有 0 和 255。
- 不要自动删除所有小连通块，细发丝和耳饰可能本来就是独立的小块。
- 保留原图、透明母图、游戏 PNG 和实际使用参数。

这套算法负责将已经完成的画风和人物设计稳定采样成小尺寸游戏贴图。原画本身的脸型、头身比和布料画法，仍由母图决定。
