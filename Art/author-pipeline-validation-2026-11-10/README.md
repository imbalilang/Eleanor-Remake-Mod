## 与之前 BOX 近似流程的区别

之前的流程使用预乘透明度的 Pillow BOX 缩小、整数人物尺寸/位置、50% 透明度阈值，没有这套配方的 detail 增强及透明区颜色扩展。它属于近似面积缩小，不能完整复现作者的采样结果。

本次在同一张已正确清理的母图上控制比较：

| --- | --- | --- |
| 作者完整 B/detail | 0 | 0 |

这说明精确小数坐标、35% 前景覆盖率和一次受约束的细节增强都应保留，不能再用任意 BOX 或全图锐化替代。

## 一个需要明确的边界细节

“画布外视为透明”用于面积采样。计算除色轮廓带时，只统计**图内实际透明像素**的距离，不能把被裁到画布底边的衣服当成透明轮廓。最初将画布外也算作除色边界时，恰好只有底部两行共 146 个可见像素发生色差；改为保留裁切边界后，全部 RGBA 像素完全复现。这是对说明的边界解读校准，不是增加另一种滤镜。

透明区 RGB 的四邻域扩展与 alpha 分开处理：透明像素仍为 alpha=0；最后新增的顶部一行严格为 (0,0,0,0)。未来校验器不应再把“所有透明像素 RGB 必须为零”当作作者算法的通用要求。

## 项目画像试用

`candidates/` 下已导出 7 张候选：女仆装、礼服、莉迪亚日常/约会的原版及美化版共 4 张、革命军黑色战术服 v3。

每张均保存：

- `previous.png`：现有画像副本。
- `author_strict.png`：完整作者配方。
- `preserve_coloured_edges.png`：对照变体，只关闭洋红轮廓除色，其余采样参数完全一致。
- `report.json`：输入哈希、排布参数、输出包围盒、颜色及轮廓差异。

已经正确透明的母图均直接沿用原 alpha，没有重新洋红抠图。排布按原有脸部尺度换算：在 288×211 内采样，底边设为原 top+缩放人物完整高度−1，再补顶部一行。对话画像允许完整人物缩放高度延伸到画布外；不能为强行容纳腰部而缩小脸。

已查看作者样例对照、项目原生尺寸/整数放大对照，以及白、黑、深灰底边缘预览。眼睛、发丝和衣物线条略更清楚，未见明显新增洋红边或黑色边框，人物包围盒保持原有排布。只有女仆、美化莉迪亚日常和美化莉迪亚约会会触发少量源图边缘除色，分别为 34、71、4 个源像素，对应影响 33、81、8 个输出可见像素；这类合法紫色与洋红污染仍应分素材判断，所以保留关闭除色的对照版本。

推荐今后使用这套已复现的精确采样作为基础；对本身正确透明且含紫色设计的素材，按边缘对照选择是否启用洋红除色。算法能统一采样与细节表现，人物脸型、头身比、服装材质仍取决于母图。

## 复现方法

项目根目录执行：

```powershell
python tools/verify_author_portrait_pipeline.py
```

实现为 `tools/author_portrait_pipeline.py`，使用 NumPy/Pillow，核心采样按源像素交叠面积精确积分，不调用 Pillow resize 代替采样。除原作者成图的逐像素验证外，另用独立二维交叠求和验证了小数偏移、源图外区域、35% 覆盖率边界、透明 RGB 排除与半值向上取整。

输出限于本验证目录，现有母图及运行时画像的 SHA256 在处理前后均一致。正式资源导出器和创意工坊未在本次验证中更新。
