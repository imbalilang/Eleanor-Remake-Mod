# 恋爱书 CG 的环境参考

日期：2026-11-18。用途：回应作者对新恋爱书 CG 环境过于现代校园化的反馈，整理已有场景依据。

总览：[environment_references.jpg](environment_references.jpg)。源文件、来源类别和 SHA-256 见 [references.json](references.json)。01 是原作提取贴图；02 是既有人工图层拼合研究图，不是实机截图；03—06 是当前工作区运行纹理中的项目原创 CG。

## 可复用的场景依据

- 01 原作 `wall_36.png`：蓝紫与灰青结构、明确的建筑接缝、工业设施和局部珊瑚色照明。适合校准空间站材质与底色，不照搬其中人物或涂鸦。
- 02 原作当铺图层拼合：磨损金属墙板、管线、终端和紧凑工作空间。用于确认原作空间质感；它是交易亭，不能直接当作角色的私人书房。
- 03 《停水》室内：金属舱壁与门框、少量旧木家具、玻璃水具、局部暖灯和冷色背景。是本次私服阅读 CG 最直接的居家参考。
- 04 上层区约会：金属与玻璃的大型拱架、石阶、黄铜扶手与人工栽培绿植。说明上层区可以明亮，但应保留空间站的围合结构。
- 05 上层区晚会：金属框架、黄铜装饰、复古灯具、深色墙面与窗外设施。可用于上层区室内的装饰语言，不把晚会舞台复制到阅读场景。
- 06 革命军街区：金属墙板、外露设施、窄通道和冷暖局部照明。适合室外下层区，不能作为白色私服居家阅读的主要场景。

## 新恋爱书 CG 的问题

新图的整面统一木书架、普通大型采光窗、窗外绿树与满室金色阳光，组合成了现代校园图书馆的视觉语境。缺少可辨认的舱壁、框架、紧凑空间和空间站设施；只改变饱和度或增加像素颗粒无法解决场景设计问题。

## 推荐的下一版方向

以《停水》的居家室内为主参考，设计小型私人阅读角：灰青或灰紫金属拼接墙、带结构框的窄窗、有限的旧木书柜、少量不齐的纸质书与暖色阅读灯。保留埃利诺穿白色私服、拿恋爱书遮嘴、害羞看向镜头的主体动作。人物附近保持柔和亮度，背景的金属接缝、灯具和家具提供项目世界观信息。

若改放在上层区私人书房，则结合04、05的玻璃金属结构与黄铜装饰，仍采用紧凑的书柜与局部照明。私服和害羞读书的情境更适合前一种居家方向。

以上是参考整理和下一版设计建议，不代表剧情已存在对应地点或事件；接入时仍需核对具体章节。
