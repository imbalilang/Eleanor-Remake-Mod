# 非结局 CG 美术规范

更新于 2026-11-18。适用于已接入的事件图与待制作的日常、主线拐点、晚间私密、店休外出 CG。采用投放规划中的 **A 规制**。地点、站位和时序按[地点与投放规划](../docs/CG_LOCATION_AND_PLACEMENT_PLAN.md)核对，具体候选按[路线备选方案](../docs/CG_CANDIDATES_BY_ROUTE.md)选取。

本次审阅涵盖 4 张工作区事件 CG 和 57 张母图及版本，部分母图已用于当前事件。图例和文件来源见[参考板](cg-style-2026-11-18/style-references.jpg)与[审阅索引](cg-style-2026-11-18/review-inventory.json)。

非结局 CG 的首要美术目标是**体现埃莉诺的性吸引力**。要让玩家认得出是她，并看清她此刻主动做了什么、对谁露出这个表情。她的面容、身材、服装和姿态都可以成为画面重点，选择随关系阶段和场景而变。莉迪亚独处、索菲娅递水等已有镜头保留原本的叙事主体。

## 人物、画法和镜头

- **埃莉诺**：保留成年脸型、绿眼睛、铜橙色长卷发、相同的斜刘海分束与正常耳位。耳饰按服装图核对。眼睛开合、脸红和嘴形可随情绪变化，眼距、眼角形状、鼻梁到下颌的比例和人物年龄感以母图为准。丰满轮廓按定稿在姿势和服装下自然变化，胸、腰、髋的受力和头身比例需要一起成立。公开场合可用目光、礼服剪裁和表演状态表现自信，私下可用靠近、触碰或躲闪的眼神加深亲密感。
- **莉迪亚和索菲娅**：莉迪亚保留琥珀眼、偏冷浅棕发色、以直发为主且发尾微弯的发束、约会装的玫瑰与珍珠。索菲娅保留成熟脸型、绿眼、铜红低髻、玉簪与圆耳钉。按各自定稿分别核对下颌、眉眼、肩颈、身材。母女同框时也可以只凭剪影认出两个人。
- **线条和色块**：沿用高清角色插画的清楚轮廓、分组发束、柔和赛璐璐明暗。眼线和遮挡边缘清楚，皮肤大面保持干净。材质纹理集中在看得清的区域，区分针织、缎面、金属和皮肤反光。背景也以同一套线条和明暗绘制，避免像素颗粒、照片贴图、全画面高光和高频纹理压过人物。
- **光线**：先确定该地点的实际光源，再安排主光和环境反光。下层街道可冷暗，室内可用一盏暖灯，上层公共区可用受控日照，舞台可用聚光灯。不同光源下仍能认出发色、瞳色和服装；需要辨认动作时留出清楚的手、脸或身体轮廓。统一画法无需把每张图都染成蓝紫加橙色。
- **距离和动作**：每张图先定一个动作及一个视觉焦点。例如递戒指时拍手与眼神，起身靠近时拍重心与衣料，接吻前拍两人视线。近景有空间交代肩、肘与支撑，坐卧可见床面或台阶的受压关系。特写可以裁去脸或腿，但需靠可辨认的服装、发束、动作或前后镜头承接身份。玩家第一视角、窗外侧拍和第三人称都能使用；只在需要时用手、袖缘、肩背暗示其位置，不指定玩家露脸或发型。
- **情绪和尺度**：日常可有吸引力，晚间可以更亲密，既有尺度以[项目创作原则](../docs/PROJECT_PRINCIPLES.md)和作者给定的场景为准。优先画埃莉诺愿意与谁拉近距离的动作，保留羞涩、自信、疲惫或悲伤的区别。流泪场景用靠近和依赖表达亲密，正式互动照顾角色当时的情绪。表情夸张实验和纯姿态图单独保留为参考，按章节的情绪选择。

## 同一座空间站的不同地方

| 地点 | 必须认得出的东西 | 连续性检查 |
| --- | --- | --- |
| L1 当铺窗口 / L5 主线当铺 | 卷帘轨道、售卖窗口、柜沿、货物或终端。 | 访客在外，玩家在内。递物、包扎或靠近都在两侧可够到的距离内。道具特写也保留一处空间方向提示。 |
| L2 当铺外 | 当铺卷帘、外墙、窗沿或相邻台阶中至少一项可识别关系，加下层区金属板、接缝、管线或外露构架。 | 打烊后双方可以同在店外。远处街道可复用材料语言，每个巷口和门牌按地理关系画，避免把同一条长走廊当成多个地点。 |
| L3 埃莉诺在配给站对面的住处 | 小尺度舱室、窄门或窗框、有限的旧家具。床、椅子、小桌按既定剧情使用。 | 连续图先定床、门窗和灯的位置。书可以拿在手里或放小桌。大书柜、私汤、沙发、露台等先查地点或家具依据，图里画出来不能反过来当作已经授权。发生留宿需有回店过渡。 |
| L4 上层区与特殊场地 | 上层公共区可用玻璃金属结构、石阶、黄铜或栽培绿植。晚会保留可辨认的演出设施和舞台视线。已有场外住宅分别按剧情地址。 | 亮度和装修体现阶层差异。水族馆、观景车、澡堂、后台等候选先查地点与转场，视需要确认新增空间。索菲娅家是《停水》已有场所，不能把它移作当铺里间或自动建立索菲娅的卧室。 |

## 交付检查

1. 每张 brief 附上地点代码、章节和动作、角色/服装、画法、环境三类来源。固定谁在何处、光从哪里来、主要看她哪一个动作。新地点和新家具按地点规划先确认。
2. 生图后把她的面部与定稿按相近姿态并排核对：额头至下颌、眼距、头肩比例、发色与潜在年龄漂移。再看遮挡，逐一查验双臂、关节、手指、重心和物件接触。
3. 在整幅画面和约 1920 像素宽的模拟界面检查焦点、裁切和空间标记。人物需与背景光源相容，插图不得承担只有图才能传达的剧情事实。
4. 存档保留母图、实际提示和来源。现有高清输出路径沿用 16:9 RGB PNG、接近母图尺寸、双线性过滤。四张事件图当前为 1664×936，资源键与母图见[导出记录](cg-display-2026-11-18/asset_validation.json)。记录选稿、接入和实机三个状态。
