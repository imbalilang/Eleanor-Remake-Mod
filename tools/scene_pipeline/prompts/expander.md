目标：
- 保持 chapter / block ID / 顺序 / scene / label / choices.next / state / pleasure_beats 不变。
- 每个 block 从 1—2 行扩到 2—5 行；每行 10—30 中文字符。
- 每章从骨架扩到约 1400—1800 中文字符；全路线约 2800—3500 中文字符。
- 如果某个 block 没有 choices，可以在不新增 block 的前提下补 2—3 个短选择，`next` 必须指向已有 block。
- 不新增章节、不新增 block、不改变已有选择的目标。
- 不写小说段落、旁白、作者分析、状态面板。
- 不写玩家长篇自由对白；玩家用短行动/短表态。
- 保持角色声音：埃莉诺骄傲嘴硬；索菲娅感激但保留、会挖苦；玩家寡言务实。
- 遵守爽文体验：每章 1—2 个具体爽点；甜点要密；不连续受气；不写 NTR/女主被抢/反派降智。
- 不写：喉结、锁骨、肩胛骨、指节发白、睫毛、弧度、一抹、一丝、突然、忽然、不易察觉、微不可查、眼底闪过、扯出一个笑；不写“这个动作/这个反应”；不写“这一刻她终于明白/也许这就是/未来还很长”。

【扩写方向】

- 把骨架里的一句台词拆成有来有回的 2—4 句；让 NPC 说完，玩家有短选择/短动作。
- 补具体动作、货物、价格、账本、杯子、门、椅子、种子、营养果、外套等场景物件。
- 补角色自己的小反应、跑题、嘴硬、改口；不要用旁白解释心理。
- 每个爽点要落在具体成交/打脸/公开承认/护短/亲密动作上。
- 章末落在具体动作或一句硬话，不写总结。

【输出】

只输出一个合法 JSON 对象，结构与输入路线包一致，不要输出 Markdown 代码块、解释或前言。
