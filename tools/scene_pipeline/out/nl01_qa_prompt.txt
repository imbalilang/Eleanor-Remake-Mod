世界书微上下文：
【世界观】
空间站。上层区富裕、控制公司与治安部；下层区是当铺、拾荒者、黑市、革命军和配给生活。
下层区当铺。玩家是店主，做收购、估价、转卖、补给和人情生意。
【关键事实】
- 埃莉诺原是上层区富家千金，母亲索菲娅曾是全空间站最大水培农场的负责人。
- 索菲娅因挪用公款罪入狱，实际是帕斯泰尔公司栽赃；她掌握让营养果重新结籽的研究。
- 原作的两种母亲结果：交回数据盘，母亲流放下层但活着；公开研究，母亲被杀。
- 本 MOD 的常规恋爱线默认母亲生还；甲线研究被收回，乙线研究公开/受保护。
- 埃莉诺 20 岁；莉迪亚 22 岁；索菲娅 38 岁、外表约 28 岁。
- 埃莉诺橙红/铜红发、绿眼；莉迪亚偏冷棕长直、发尾轻弯、琥珀眼；索菲娅铜红/红棕发、绿眼。
【角色】
### 埃莉诺
年龄：20
core:
- 阶级骄傲、审美骄傲、能力骄傲；落魄后仍懂货、懂礼数。
- 嘴硬心软：先顶一句，再用具体动作漏出真话。
- 要自己作主；可以求人，但不把人生交给别人代管。
- 阶级偏见不会一笔勾销；会具体道歉，也会在紧张时冒出旧刺。
- 母亲死后/获救后，悲伤转成行动，不反复自审。
voice:
- 直接、有起伏、会反问和感叹；上层区词汇和货物/价格/保养混在一起。
- 常用：喂、哼、绝了、荒谬、少来、别以为、谁……了、你倒是、我可没、行吧。
- 情绪峰值可以语塞；不要大量“……”开头，不要心理学术语，不要金句收尾。
- 傲是保护尊严，不是习惯性刻薄；娇是具体让步，不是娃娃腔。
boundaries:
- 不突然贤惠持家、不无条件告白、不放弃判断。
- 不让玩家替她决定研究、工作、去留。
- 不把“主人”当全局称呼；公开场合要尊严。

年龄：38
core:
- 普罗米修斯式：把让营养果重新结籽的技术交给所有人，因此被公司栽赃、监禁、消音。
- 得墨忒耳式：农场、母女分离与团聚；具体地爱女儿，不用长篇抒情。
- 雅典娜式：懂农场、研究、账、人；严格、有策略、会挖苦人。
- 不是慈祥岳母，也不是恶岳母；有自己的研究、骄傲和失去。
voice:
- 比埃莉诺稳、少感叹、多具体问题；不长篇说教。
- 会考试、会挖苦、会干巴巴地幽默；认可后会把玩家当家里人使唤。
- 台词示例：“你救了我们，我记着。可我得看她是因为喜欢你，还是因为那时候只有你伸手。”
- 不用心理学术语、网络流行语、政治演讲。
boundaries:
- 不写母女 Play、性化、真正恋爱三角、岳母福利。
- 允许和埃莉诺一起家庭式调戏主角、互相拆台、吃醋式玩笑。
- 年轻的是外观，不是辈分、权威和经历；不能写成同龄闺蜜/轻浮姐姐。
### 玩家
voice:
- 寡言、务实、冷幽默；不替 NPC 总结感情。
- 用短行动/短表态表达意愿：拒绝、靠近、留下、查看、递东西、谈价。
- 不写长篇自由对白；必要时一句，通常不超过 10 字。
【文风】
scene_contract:
- 每场戏一个具体事件，不是两人坐下来谈关系。
- 她想要什么？什么阻止她？
- 玩家能做 2—4 个短选择；每个选择有不同回应。
- 至少 2—5 条短动作/场景节拍，让角色有身体和位置。
- 结尾落在具体动作、交易结果、一句硬话或沉默，不写主题总结。
dialogue:
- NPC 连续独白不超过 3 行；每 3—5 行给玩家一次输入。
- 句子长短交错；允许半截话、改口、答非所问、跑题。
- 角色讲自己的事、兴趣、货物、价钱、旧生活；不必每句都推进恋爱。
- 删掉“以前我/现在/我知道/我不是/我只是”式成长总结。
- 不写心理学术语、抽象关系分析、金句收尾、不是X是Y。
- 不要每句都附动作；动作只用来钉场景/暴露情绪。
player:
- 玩家台词默认 0；必要短句 ≤1 句/block，≤10 字。
- 优先用短选择/动作表达：问、拒绝、靠近、亲、抱、留下、走开、查看、递。
- 玩家不是访谈者，也不是没有意愿的旁观者。
ai_tells:
- 不写：喉结、锁骨、肩胛骨、指节发白、睫毛、弧度、一抹、一丝、突然、忽然、不易察觉、微不可查、眼底闪过、扯出一个笑。
- 不写：这个动作/这个反应/这个认知/这个笑容；不写解释性比喻。
- 不写：空气安静了一瞬、时间仿佛静止、不知过了多久。
- 不写：这一刻她终于明白、也许这就是、未来还很长。

【检查项】

1. **JSON/格式**
   - 是否是合法 JSON 对象；是否只有 chapter/title/summary/blocks；
   - 每个 block 是否有 id/scene/label/lines/actions/choices/state；
   - block ID 是否符合 `nl01_bNNN`；是否重复；
   - speaker 是否只用 eleanor/lydia/sophia/player/npc；
   - 是否出现小说段落、旁白、作者分析、状态面板、数值台词。

2. **场景契约**
   - 是否有一个具体事件，而不是两人坐下来谈关系；
   - 是否写清她想要什么、什么阻止她；
   - 是否有 2—4 个玩家短选择，每个选择有不同回应；
   - 是否有 2—5 条短动作/场景节拍；
   - 结尾是否落在具体动作/交易结果/一句硬话/沉默；
   - 结束时是否至少一个事实/关系/信息/物品发生变化。

3. **玩家能动性**
   - 玩家是否有 2—4 个短选择；标签是否 2—8 字；
   - 是否出现玩家长篇自由对白（超过 10 字/超过 1 句/替 NPC 总结感情）；
   - 玩家是否只是听诊器。

4. **角色声音**
   - 埃莉诺：骄傲、嘴硬、爱美、要自己作主；不要温柔贤惠/心理医生；
   - 莉迪亚：明艳、嘴快、热心、虚荣；不是职业经纪人/阴谋家；
   - 索菲娅：38/28，研究者/母亲，感激但保留；不是慈祥岳母/恶岳母/可攻略对象；
   - 玩家：寡言、务实、冷幽默；不写长篇自由对白。

5. **AI 腔/重复**
   - 是否出现：喉结、锁骨、肩胛骨、指节发白、睫毛、弧度、一抹、一丝、突然、忽然、不易察觉、微不可查、眼底闪过、扯出一个笑；
   - 是否出现：这个动作/这个反应/这个认知/这个笑容；解释性比喻；
   - 是否出现：空气安静了一瞬、时间仿佛静止、不知过了多久、这一刻她终于明白、也许这就是、未来还很长；
   - 是否连续 NPC 独白超过 3 行；
   - 是否大量“以前我/现在/我知道/我不是/我只是/我发现”式成长总结；
   - 是否重复上一场的结构/句式/意象。

6. **连续性/边界**
   - 是否违背世界书事实、路线阶段、旧档状态；
   - 是否让角色知道不该知道的事；
   - 是否写母女 Play/露骨性描写/母亲恋爱线；
   - 是否引入未设定的新角色/新系统/新地图；
   - 是否把玩家没有做过的交易/承诺当成已发生。

【处理】

- 如果只是局部问题：`decision = "FIXED"`，在 `fixed_bundle` 里返回**完整的修正后 JSON**；不要只返回 diff。
- 如果问题伤及结构/事实/分支：`decision = "REJECT"`，在 `feedback` 里写清楚重写方向；不要返回 fixed_bundle。
- 如果完全通过：`decision = "PASS"`。
- `state_delta` 只放本场真正改变的状态；`summary` 用一句话总结事实。

【输出】

只输出一个合法 JSON 对象，不要输出 Markdown 代码块或额外解释：

{
  "decision": "PASS",
  "feedback": "",
  "fixed_bundle": null,
  "state_delta": {},
  "summary": "一句话事实总结"
}

如果 `decision = "FIXED"`，`fixed_bundle` 必须是完整场景包，结构与待审场景包一致。
