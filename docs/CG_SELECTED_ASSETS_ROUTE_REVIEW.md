# 试作立绘与 CG 筛选

这些图来自服装、构图和姿态试作。立绘主要出现在售卖窗，用角色会穿来见人的衣服筛选，同时检查游戏尺寸下能否看出换装。CG 的镜头可以离开窗口，衣服也可以随场合变化。先找剧情里值得画的动作，再取用合适的试作。地点、转场和画法见[投放规划](CG_LOCATION_AND_PLACEMENT_PLAN.md)、[路线备选](CG_CANDIDATES_BY_ROUTE.md)与[非结局 CG 美术规范](../Art/SCENE_CG_STYLE.md)。

## 路线取舍

- **侍从线**沿用晚会礼服与舞台图。私密内搭取 P4，放在《交完班》双向确认关系之后，等剧情进入只有两人的室内场合再画。她决定何时换衣服、何时开口。
- **共同线、革命军线**这批无需新增换装或 CG。革命军优先做好《天亮之前》的靠肩镜头。`v2_r1c2`《药先拿》已交代埃莉诺退掉配给站对面的房间，后段无从沿用这个地址。
- **后宫线**先核对 C5 的关系落点。若另有一晚埃莉诺与玩家单独相处，可以考虑 C2。黑裙只在窗口尺寸下确实有辨识度、来访也自然的情况下启用。
- **恋爱线**可继续用恋爱书作为私下近景候选。公主抱、睡衣早安、床上拥抱都等已有动作和地点明确后再选。决定留宿前要核对当时的同住安排和次晨回店时间。

有落点的 CG 按角色定稿、服装、地标和光源统一，并在实际显示尺寸检查人体受力与画面焦点。其余试作保存在美术档案。
