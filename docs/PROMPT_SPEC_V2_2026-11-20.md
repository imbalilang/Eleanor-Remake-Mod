# Prompt Spec V2（2026-11-20）

状态：基于各模型官方文档调研后修订，用来替代 V1 草稿。依据见 docs/OFFICIAL_PROMPT_GUIDES_2026-11-20.md。

## 一、统一结构

所有生成提示词按以下顺序组织，避免把风格、负向清单和 T0 检查混在一起：

1. 主体句：第一句写谁、在做什么、在什么环境。
2. 参考图角色：每张图只负责一件事。
3. 可见细节：服装、材质、取景、数量、视线、交互。
4. 姿势与构图：优先引用姿势图；文字只写镜像关系和必要差异。
5. 风格：像素颗粒、调色、描边、阴影方式。
6. 输出：比例、分辨率、无文字。

## 二、硬规则

- 第一句不要写 pixel art 或情绪、胶片、风格；先写主体和场景。
- 参考图必须分配角色：身份、姿势、风格、构图，角色不能重叠。
- 用正向可见性描述，例如两个角色全身可见、四肢分开、脚在画面内。
- 负向约束最多 3–4 条；能正向写的不要用负向写。
- 一次只改一个主要变量；不要在同一轮同时改姿势、服装、脸和风格。
- T0 检查放在生成后，不写进提示词；T0 失败自动重画。
- 双人镜像姿势必须同时提供原姿势图和水平翻转姿势图，不能只给一张图再用文字要求镜像。
- 胸围差异只写局部差异：Lydia 只比 Eleanor 大一个罩杯，腰、腹、臀、手臂和大腿保持同样纤细。
- 每角色只保留一条腿环；不要用两条腿环来补构图。

## 三、模型适配

### OpenAI（openai/gpt-image-2.6-flare）

- 适合结构化分段：主体、参考图角色、细节、保留项、输出。
- 编辑时先写只改 X，再写一段 preserve：身份、脸、发型、服装、构图、光线。
- 参考图按 Image 1/2/3 分配角色，每张只做一件事。
- 参数建议：size 2K，aspect 16:9，quality high。

### xAI / Grok（x-ai/grok-imagine-image-2.0）

- 写成主体优先的短散文，第一句必须是主体。
- 细节、镜头、艺术方向、光线、颜色、构图依次往后放。
- 不要堆 avoid 列表；把约束压缩成一句正向要求。
- 编辑时先写改动，再用一句 preserve 收尾。
- 参数建议：resolution 2K，aspect_ratio 16:9，quality medium。

### 腾讯混元（tencent/hy-image-v3.5-preview）

- Prompt 可以较丰富，但 PromptExtension 默认开启，会自动扩写；不要把关键身份和构图写得太绕。
- NegativePrompt 独立放；不要把负向要求混进正文长列表。
- 多轮编辑只做小幅调整；每轮只改一个点，避免颜色和像素漂移。
- 参数建议：size 2K，aspect 16:9，单轮生成。

### Seedream（bytedance-seed/seedream-5-5）

- 只用于构图、场景和摄影感描述；不作为最终像素 CG 风格生成器。
- 如果使用，提示词只写主体、动作、环境、镜头和构图，不写像素风格。

## 四、模板

### 单人 CG 模板

{主体第一句：谁、在做什么、在什么环境}

Image 1 = 人物身份参考（脸、发型、瞳色）。
Image 2 = 服装参考（只取服装）。
Image 3 = 像素风格参考（只取风格）。

画面：{镜头/取景/角色占画面比例/背景简化程度}。
人物：{年龄感、脸型、发型、眼睛、服装材质、颜色}。
动作：{姿势、手部动作、视线、与道具的交互}。

风格：{像素颗粒大小、局部抖动、描边、色阶、阴影方式}。
输出：16:9，2K，不要文字和水印。

### 双人镜像模板

{主体第一句：两个角色是谁、并排躺在什么环境}

Image 1 = Eleanor 身份参考。
Image 2 = Lydia 身份参考。
Image 3 = Eleanor 姿势参考。
Image 4 = Lydia 姿势参考，必须是 Image 3 的水平翻转。
Image 5 = 像素风格参考。

Eleanor 使用 Image 3 的姿势；Lydia 使用 Image 4 的姿势。两人的手臂、膝盖和伸展腿必须左右相反，不能是同一套动作的复制。
两人全身可见，四肢分开，脚在画面内。

服装：{Eleanor 黑兔女郎，Lydia 白兔女郎；三角泳衣、单侧腿环、手腕袖口、鞋}。
身体：Lydia 只比 Eleanor 大一个罩杯，腰腹臀和四肢保持同样纤细。

风格：{像素颗粒、局部抖动、描边、色阶}。
输出：16:9，2K，不要文字和水印。

### 编辑模板

只改 {一个具体点}。保留 {身份、脸、发型、服装、姿势、构图、光线、背景} 不变。

如果编辑涉及姿势，先写新的姿势，再用一句 preserve 收尾；不要同时改风格。

## 五、长度与迭代

- 软上限：OpenAI 1200 字符；Grok 1000；腾讯 1200；Seedream 800。
- 硬上限：不超过 1600 字符；超过就先删负向清单和重复形容词。
- 每轮只改一个主要变量；保留上一轮已经正确的部分。
- 同一配方最多连续修 2 次；第 3 次仍失败就重写配方或换模型。

## 六、生成后 T0 检查

T0 不写进提示词，生成后单独检查：

- 头、躯干、手臂、手、腿、脚、耳朵数量是否正确。
- 沿肩、上臂、肘、前臂、腕、手逐段追踪，不能只数端点。
- 沿髋、大腿、膝、小腿、踝、脚逐段追踪，确认两条腿没有被合并。
- 脚和鞋必须完整在画面内；不要让下边缘裁掉脚。
- 双人图默认检查总数：2 头、4 臂、4 手、4 腿、4 脚、4 耳。

判定：

- PASS：数量、连接和遮挡都清楚。
- T0：缺肢、多肢、融合、明显错位。
- OCCLUSION_UNCERTAIN：被遮挡但无法确认；按 T0 处理，不要猜。

T0 失败处理：

1. 不询问用户，自动用同一配方重画一次。
2. 第二次仍 T0，停止并报告失败，不把图当候选。
3. 记录失败原因和轮次。
