# 原作非台词表现与 MOD 应用审计

日期：2026-11-10
范围：Probably Stolen 本体的对话表现能力，以及当前 MOD 脚本对这些能力的实际使用情况。本文只做审计，不改代码或文本。

## 0. 结论

原作的“非台词表现”分三层，不能混为一谈：

1. **文本层**：斜体 `<i>`、粗体/下划线、TextAnimator 标签（如 `<wave>`、`<slide>`）。这些直接写进对白字符串，能在对话气泡里产生文字动画。
2. **肖像层**：`IdleAnimator` 让来客肖像上下浮动；被改造角色（`isAug`）可随机水平抖动或冻结。这是整次来访的肖像状态，不是逐句触发。
3. **场景层**：从左侧走入、剪影淡入、离店/右侧离场、跛行减速、切换 `spriteName` 肖像变体。由商店客户端生成和场景代码控制，不是对白标签。

**商店对话 UI 不支持逐句更换肖像或表情。** `Dialogue.SetPortrait` 只在 `RaidScene` 的突袭战斗对话中使用，商店对白始终使用 `StoreClient.spriteName`。

当前 MOD 的实际情况：

- 对白文本里 **0 个** `<i>`、`<wave>`、`<slide>` 或其他富文本/TextAnimator 标签。
- 却有 **76 条中文 `*...*` 伪动作/旁白**（story 7、maid 10、dual 59；dual 英文另 59 条），其中 dual 有 9 条中文超过 40 字、英文有 58 条超过 40 字。
- 代码里 **0 次** `SetPortrait`、**0 次** `isAug`/`augIdleTell`、**0 次**逐行音效/语音调用；只有场景级 `spriteName` 和一次 `QueueClientArriveAnimation`。
- 所以“人物画像左右摇一下”目前既没有写进数据，也不是普通对白能直接触发的；`*...*` 很可能只是原样显示星号，而不是斜体或动作。

## 1. 可用能力清单

| 能力 | 控制层 | 原作用法 | 能否直接写进对白文本 | 当前 MOD |
|---|---|---|---|---|
| 斜体 `<i>...</i>` | 文本 | 30 条 `<i>*动作*</i>` 式提示/动作，14 条斜体强调 | 可以 | 0 |
| 粗体/下划线 | 文本 | `<b>` 14 处、`<u>` 5 处，主要用于强调/界面句 | 可以 | 0 |
| TextAnimator 行为标签 | 文本 | `<wave a=0.25>`、`<slide a=0.25>` 各 1 处 | 可以 | 0 |
| 文本颜色/精灵等富文本 | 文本 | 主要用于 UI 和少量强调 | 可以，需控制范围 | 0 |
| 肖像上下浮动 | 肖像/场景 | 所有来客默认 `IdleAnimator` 上下浮动 | 不可以 | 自动继承，未主动调 |
| 肖像水平抖动 | 肖像/场景 | `isAug` 来客 5% 随机水平抖动；`AugIdleTell.Seizure` 可强制 | 不可以 | 0 |
| 肖像冻结 | 肖像/场景 | `isAug` 来客 25% 冻结；`AugIdleTell.Freeze` 可强制 | 不可以 | 0 |
| 切换肖像变体 | 场景 | 埃莉诺普通/无首饰/悲伤/拾荒/革命；其他来客按类型 | 不可以逐句切换；只能换整次来访 | 有场景级切换 |

| 离店/右侧离场/跛行 | 场景 | 原生离场与慢速离场 | 不可以 | 未主动使用 |

| 逐行音效/语音 | 音频 | 原作对白没有逐行音效；有走路/UI 音效。TextAnimator 带 `SoundWriter` 示例组件，但未确认挂在对话气泡上 | 不可以（未确认对话组件） | 0 |
| Start/End 代码钩子 | 代码 | 可在对白节点前后执行代码 | 不是文本层 | 只用于状态/流程 |

## 2. 原作实际用了什么

### 2.1 文本层

- 全部 2544 条对白中，`<i>` 44 对：
  - 约 30 条是 `<i>*叹气*</i>`、`<i>*咳嗽*</i>`、`<i>*掏出枪*</i>`、`<i>*眨眼*</i>`、`<i>*看着屏幕*</i>` 这类动作/语气提示。
  - 另外 14 条是斜体强调或动作词，如 `保险服务`、`灵活`、`叹气`、`眨眼`。
- `<b>` 14 处、`<u>` 5 处，主要用于强调。
- TextAnimator 只出现两处，且都用在乔·王尔德的保险台词：
  - `你好啊！<wave a=0.25>欢迎来到我们这个小街区！</wave>`
  - `我的名字是<slide a=0.25>乔·王尔德！</slide>`

这类标签的作用对象是**文字**，不是人物肖像。`<shake>` 抖动的是字，不是立绘。

游戏资产里包含的 TextAnimator 行为类（标签名为其 `EffectInfo`）：

| 标签 | 行为 | 适合的用法 |
|---|---|---|
| `<wave>` | 波浪 | 拖长音、轻佻、欢迎 |
| `<shake>` | 抖动 | 惊慌、威胁、压不住的怒气 |
| `<bounce>` | 弹跳 | 轻快、得意 |
| `<dangle>` | 悬摆 | 犹豫、晃神 |
| `<fade>` | 淡入淡出 | 压低声音、淡出 |
| `<pend>` | 钟摆 | 反复摆动、嘲讽 |
| `<rainb>` | 彩虹色 | 极少量；喜剧/夸张 |
| `<rot>` | 旋转 | 突然转头、强调 |
| `<incr>` | 放大 | 提高音量、揭示重点 |
| `<slide>` | 滑入 | 报名、揭晓、突然出现 |
| `<swing>` | 摇摆 | 轻松、调侃 |
| `<wiggle>` | 扭动 | 不安、撒娇、局促 |

这些行为类在 `resources.assets` / `globalgamemanagers.assets` 中都能找到；但具体标签是否全部注册到对话所用的动画数据库，仍以实机预览为准。参数方面，原作只验证了 `a=0.25`（幅度）；其他参数不要凭猜写进正文。

### 2.2 肖像层

`IdleAnimator` 是 `StoreClientMono` 上的组件：

- 默认所有来客肖像沿 Y 轴上下浮动（`amplitude` 默认约 0.25，`frequency` 默认 1）。
- `StoreClient.isAug` 的来客：
  - 25% 概率冻结；
  - 5% 概率改为水平抖动（axis=right、amplitude=0.035、frequency=4）。
- `StoreClient.augIdleTell` 可以强制 `Freeze` 或 `Seizure`；这是新角色生成时的属性，不是对白行属性。

它只能让**整次来访的肖像**一直抖/停，不能在某一句台词时“摇一下再停”。这正好对应你说的“人物画像左右摇了一下”，但原作把它用作被改造角色的长期异常状态，不是通用演出指令。

### 2.3 场景层

- `StoreClientMono`：走入、剪影淡入、左/右离场、慢速跛行离场。
- `GenericClientMono`：安保等通用来客的走入/离场。
- `spriteName`：整次来访使用哪张肖像；埃莉诺原线有普通、无首饰、悲伤、拾荒、革命等变体。
- 商店对话界面 `DialogUIManager` 的 `DisplayClientText` 只把 `dialogue.plainText` 交给打字机；不读取 `Dialogue.portrait`。`Dialogue.portrait` 只在 `RaidScene` 的突袭对话里被使用。因此商店场景逐句换表情没有数据入口。

## 3. 当前 MOD 用了什么

### 3.1 文本层

统计 `Content/*.json`、`tools/ui_text_zh.json`、`tools/ui_text_en.json`：

| 文件 | 带 `*...*` 的行（中文/英文） | 富文本/TextAnimator 标签 |
|---|---:|---:|
| `Content/story_v06.json` | 7 | 0 |
| `Content/maid_v05.json` | 10 | 0 |
| `Content/dual_romance_v04.json` | 59 中文 / 59 英文 | 0 |
| 其他 Content/UI JSON | 0 | 0 |

例子：

- `*叹气* 你有生活用品吗？`
- `*拧开瓶盖闻了一下* 上层区沙龙的定制款……`
- `*把一张折好的纸放在柜台上* 母亲的复核材料……`
- dual 里还有大量长旁白，例如：
  - `*她走得太急，又折回来拿落在椅背上的披肩。埃莉诺伸手去取，张了张嘴，最后把披肩递给了她。经过你身边时，莉迪亚压低声音。*`
  - `*埃莉诺先进门，手里拎着个纸袋。莉迪亚跟在后面，两只手护着一包用纸裹好的点心……*`

按代码路径，`Dialogue.plainText` 被原样交给 `TextBubble.typewriter.ShowText`；没有发现把 `*...*` 转成 `<i>` 的处理。**这些星号很可能直接显示在对话框里。** 需要实机/F9 预览确认，但不应再按“它会自动变斜体”来写。

### 3.2 肖像层与场景层

- 场景级 `spriteName` 有使用：
  - 埃莉诺 `eleanor1` / `eleanor_scav` / 侍从装 / 礼服；
  - 莉迪亚日常与约会；
  - 母亲双版本。
- 没有 `SetPortrait`、`isAug`、`augIdleTell`、`IdleAnimator` 调用。
- 没有逐句换肖像。
- 场景动画：晚会邀请使用一次 `QueueClientArriveAnimation`；侍从采购客使用一次 `SetImmediatlyArrive`。普通来访依赖原生走入/离场。
- 对白前后没有视觉/音效 Action；`SetStartAction/SetEndAction` 只用于状态和流程。

## 4. 风险

1. **星号不是动作**：`*...*` 没有 `<i>` 包裹，也不是 TextAnimator 标签；大概率原样显示。当前写法没有让角色“演”出来。
2. **长旁白塞进对白气泡**：dual 的中文长旁白 9 条超过 40 字，英文 58 条超过 40 字；这些会变成又长又带星号的台词，和原作短句差距很大。
3. **没有视觉节奏**：全篇零 TextAnimator、零斜体，所有人说话节奏相同；原作至少在乔·王尔德的介绍里用了 wave/slide，给角色一个短暂的语气标记。
4. **误用“肖像抖动”**：`IdleAnimator` 的水平抖动只适合被改造角色的持续状态；不能当作逐句“人物摇一下”的通用按钮。
5. **逐句表情不可用**：商店对话 UI 不读 `Dialogue.portrait`；不要计划在 c01–c23 这种商店场景里做逐句肖像切换。

## 5. 建议的呈现规则

具体的场景适配、频率硬上限和审批流程见 [`文风与玩家台词基准_2026-11-10.md`](文风与玩家台词基准_2026-11-10.md) 第 10 节。以下为摘要。

### 5.1 文本层

- 短动作/语气提示如果真的需要保留，写成 `<i>*叹气*</i>`，不要只写 `*叹气*`。
- 长动作/旁白不要塞进角色台词。能改成角色说的话就改；不能演的就删，或放到真正的旁白/场景文字里（如果该 UI 支持）。
- TextAnimator 标签只用于短句或词：
  - `<wave a=0.25>`：轻佻、欢迎、拖长音；
  - `<shake>`：惊慌、威胁、强调；
  - `<slide>`：名字、揭晓、突然出现。
- 建议预算：每章最多 1–2 处文字动画，只包一个词或短句；不整段包，不连续嵌套。先在实际游戏里预览，确认中文、标点和气泡宽度都正常。
- `<i>` 斜体可以保留给短动作；不要把所有强调都斜体化。

### 5.2 肖像层

- 肖像变体只在**来访/场景开始**时选，不逐句换。
- 需要不同表情时，优先用台词和标点表达；如果确实需要换图，只能换整次来访或走代码切换（并确认 `StoreClientMono.image.sprite` 会刷新）。
- 水平肖像抖动只用于 `isAug` 角色；埃莉诺/莉迪亚在设定不是被改造者时不要硬套。需要“这句话在发抖”时，用文字 `<shake>`，不要动整张立绘。

### 5.3 场景层

- 走入/离场用原生流程；晚会等特殊场景才用 `QueueClientArriveAnimation` / 立即到位。
- 不要用对白文本写“她走到门口”“他掏出枪”这类游戏没有对应动作的指令；除非只是短斜体提示，并接受它只是文字。

## 6. 对当前修订稿的影响

- v4 的 c01–c03、c23 已处理旧式星号：
  - `*叹气* 你有生活用品吗？` → `<i>*叹气*</i> 你有生活用品吗？`
  - `*把一张折好的纸放在柜台上* 母亲的复核材料……` → 删除动作，只留 `母亲的复核材料，递进去了。`
- 短斜体仍属原作常用形式，但 `*...*` 本身不是动作；不得再只写星号。
- 后续章节不允许再用 `*长旁白*` 充当动作；要么写成角色台词，要么删除。
- 文字动画作为可选表现，先做 2–3 处小样验证，不批量加。

## 7. 下一步

1. 在游戏内用一条测试对白验证：`<i>*叹气*</i>`、`<wave a=0.25>`、`<shake>` 在中文环境下的实际显示、打字机速度和气泡宽度。
2. 根据结果确定标签白名单；未验证的标签不进入正文。
3. 在逐章修订文档里新增“表现标注”：文本标签、是否需要肖像变体、是否只是文字提示；不改代码，不改场景。
4. v4 已清理两处星号动作；继续 c04–c12、普通13–23 时沿用 v4 的 B/C 分级与登记规则。
