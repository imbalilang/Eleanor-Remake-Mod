# dv11《停下》中文试改稿

以当前工作区的 `Content/dual_romance_v04.json` 为底稿。开场和三个选项沿用当前稿，试改段从店主说出埃莉诺来过开始。

## 开场

**莉迪亚**　早。你今天还开着？我还以为你会接着歇一天。

**莉迪亚**　昨晚回去怎么都睡不实，后来索性坐起来，把发夹一枚一枚收进盒子里。

**店主**　收起来做什么。

**莉迪亚**　说不上来，手没处搁。*（在柜台前挪了挪步子）* 埃莉诺这两天来过没有？

**莉迪亚**　我去她住处敲过门，她室友只说她不在。她以前不这么躲我。

**莉迪亚**　你直说吧，我最近是不是太闹腾，她烦了？

## 选项

**直说那天的事**　直接接下方正文。

**先让她坐下**

> **店主**　先坐好。  
> **莉迪亚**　你这么讲，我更没着落了。*（还是坐了下去）* 说吧，我坐定了。

**问她怎么想的**

> **店主**　你那天来之前，想过她吗？  
> **莉迪亚**　想了。我盘算的是不瞒她，就一天……你怎么忽然问这个？
