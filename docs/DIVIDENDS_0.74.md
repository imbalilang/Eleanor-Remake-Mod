# 0.74合作分红

按用户确认采用“每天累计、埃莉诺来访时领取”。新要求取代0.73评估中不提供自动经营收入的限制，保留真实买卖／估价作为另一类经营活动。

## 收益与投入

| 节点 | 日分红 | 起算 |
|---|---:|---|
| P3已付款，但第一单反馈未完成 | 0 | 不提前发钱 |
| 第25章第一单完成，P3结果确认 | 200 | 次游戏日 |
| 第27章事业开张，P4结果确认 | 600 | 次游戏日；此前日期仍按200计 |

两档分红是埃莉诺主动提出的合作收益，另账结算；不是再收一次样品钱、原交易货款或偿还预付工钱。现金／人脉方案收益相同，原报价、折扣、恩惠和声望成本仍按原生规则。P1、P2不凭空产生营业收益。

入线预付800与四项目纯现金基准17000合计17800（不含可选保护支出），成熟日收益600相当于约30日的这一基准投入，前期200日收益另计。实际购买价格有难度、恩惠与折扣差异，不能把基准回收期当成每个周目的实测结论。人脉方案有现金和声望机会成本；本轮没有追加收费或永久市场折扣。

## 领取与呈现

- 按游戏日期累计，无未领取天数上限，后台不开现实时间计时；不因为她没来或先处理紧急事件而扣账。
- 现有本人经营／日常来访可带款；没有合适来访时，每4日安排一次简短结算，主线、项目结果和紧急访客优先，相邻重要来访至少隔2日。原四次日常播完后仍继续结算。
- 第25章和第27章用简短对白说明合作账及日收益；王尔德P3/P4显示收益、待领与累计已领。第28章保留纯情感收束，未领余额留给之后的来访。
- 在分红金额那句播放完后才增加真实现金；创建／排队／刚打开对白不付款。交易货款、估价费和分红分别记账，其他顾客不会代发。
- 分红属于已做成的合作，正常转为平等恋人不抹除已成立的生意权益。背叛／合作终止等无继续合作条件的状态停止未来计提，已有账面余额不重置。

## 存档与数值

新增`er.maid.dividend.*`账目，不改全局schema2与侍从特性版本1。已完成旧档从首次更新读档当天建立游标，次游戏日起按当前阶段累计；不追造旧版本没有记录的历史利润。

按上次记录的日收益结清过去日期，再更新阶段收益，避免用600反算早期200日期。倒拨日期不回退游标，同日多次调用不重复计提。余额／累计收益／累计已领使用64位数值；实际现金仍遵守原版int上限，现金放不下的部分保留在账上。领取在一个无回调、I/O或让出执行的同步段内更新账和现金，UI通知在提交之后；通知失败不会再发一次钱。
