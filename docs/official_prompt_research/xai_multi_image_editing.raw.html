Model Capabilities

Multi-Image Editing

View as Markdown
Create API keyTry PlaygroundMeet grok-4.7

Use up to five source images for a single image edit. You can specify images in the order they are sent in the request. By default, the output aspect ratio follows the first input image. You can override this by setting the aspect_ratio parameter to a specific ratio, such as "1:1" or "16:9".

Each source image can be a public URL, a base64-encoded data URI, or a file_id from the Files API — and you can mix kinds within a single request. See Files API integration for image & video requests for file_id details and examples.
