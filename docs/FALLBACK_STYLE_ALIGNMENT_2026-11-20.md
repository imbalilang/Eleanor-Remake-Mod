# 大尺度 CG 的 Grok / 混元画风逼近方案

目标：OpenAI 拒绝大尺度内容时，让腾讯混元或 Grok 的输出尽量接近主标准，而不是直接接受另一种画风。

## 方案一：安全风格 patch 参考

不使用整张主标准 CG，只裁安全区域作为风格参考：头发、皮肤、布料、金属、背景各一小块。

优点：不触发内容审核，保留主标准的像素颗粒、色阶和描边。
缺点：模型可能只学局部，不保证全身统一。

## 方案二：腾讯一次性内容 + 一次性风格转绘

第一步用混元生成内容；第二步用同一张白花睡服 B 锚点和简单转绘提示词做一次风格转绘。

限制：最多两次调用，不连续改图；第二步只改渲染，不改姿势和身份。

## 方案三：打光/色彩锁定

以已通过的 OpenAI R1 为色彩目标，对混元结果做固定色彩匹配：亮度、饱和度、暖色偏移。

这能直接修正腾讯当前偏亮偏冷的问题，不改变构图。

## 方案四：确定性像素规范化

固定流程：角色裁切 → 目标逻辑分辨率 → 最近邻放大 → 调色板量化 → 局部硬边/抖动 → 色彩匹配。

这是最可控的兜底方式，不依赖模型重新理解画风。

## 模型判断

- 腾讯混元：有希望接近主标准，优先使用方案二 + 三 + 四。
- Grok：平滑倾向太强，只建议做构图/姿势；不作为最终画风兜底。
- OpenAI：主标准；拒绝后不重复重试。

## 下一步测试

1. 取腾讯简单转绘 T1。
2. 做一次 R1 色彩匹配。
3. 做一次调色板量化 + 像素网格规范化。
4. 对比原 T1、色彩匹配版、完整规范化版。
5. 人工判断是否可接受；可接受则登记为 fallback_tencent_v1。
