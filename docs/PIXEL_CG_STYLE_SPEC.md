# 像素 CG 核心画风定义

基准图：`dsh-image-gen/image-8ebd4ec5.png`

## 核心特征

1. 细密像素簇：1–3 像素级的小色块组成形体，而不是大块平涂。
2. 不规则局部抖动：只在明暗过渡区使用细碎、不规则的 dithering，不铺满整张图。
3. 清晰深色描边：原生像素尺度上的 1px 轮廓，允许局部断开，不画成均匀黑边。
4. 分层硬边色阶：用有限色阶和硬边色块塑形，不依赖平滑渐变。
5. 高光与阴影也用像素簇表达：高光不是柔光晕，阴影不是大面积平涂。
6. 高信息密度：头发、布料、皮肤、背景都要有像素级细节，不能只把人物勾出来。

## 明确不是核心特征

- 全图规则棋盘格 / screen-door 抖动
- 只把低分辨率图放大得到的粗马赛克
- 平滑动漫画风加一层像素滤镜
- 抗锯齿边缘
- 大面积纯色平涂

## 验收原则

- `hf_ratio`、`flat_ratio` 只作辅助指标，不能单独判定通过。
- 必须同时看：像素簇是否细密、抖动是否不规则且局部、描边是否清晰、色阶是否有层次。
- 规则棋盘格即使降低了 flat_ratio，也不等于接近基准画风。
