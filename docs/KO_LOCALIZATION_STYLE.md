# 한국어 로컬라이제이션 방침

> 대상: 게임 내 텍스트(Content / UI / 아이템 / 뉴스 / 짧은 방문). docs와 Workshop 페이지는 대상이 아니다.
>
> 원문: 중국어 `Content/*.json`과 `Localization/zh.csv`; 일본어 `Localization/ja.csv`는 말투와 용어의 참고 자료로 사용한다.

## 인물별 말투

- **엘리너**: 기본은 반말(`해라체`). 자존심이 강하고 말이 빠르며 비꼬는 투. 플레이어를 `사장님`이라고 부르되 문장 끝은 반말로 유지한다. 어머니·상층부 인물·경찰 등 존중 대상에 대해서는 주어 존칭(`시`)을 유지할 수 있다. 연인/친구 관계가 되어도 반말을 유지하고, 부드러워지는 것은 어휘와 태도로 표현한다. 일률적인 `해요체`로 바꾸지 않는다.
- **리디아**: 밝고 빠른 반말. 플레이어에게 `해요체`를 쓰지 않는다. 가족·경찰 등 존중 대상에 대한 주어 존칭은 유지한다.
- **소피아**: 차분한 성인. `해요체`를 기본으로 하되 차갑지 않게. `합니다체`는 공식/계약 상황에 한정한다.
- **어머니**: 품위 있는 `해요체`/존칭. 엘리너가 어머니를 주어로 말할 때 `시`를 유지한다.
- **점주(플레이어)**: 짧은 반말. 공무원·상층 인물과의 공식 대화에서만 필요할 때 존칭을 쓴다. 설명조로 길게 말하지 않는다.
- **가짜 삼촌**: 정중한 영업 말투 아래의 압박. **경찰/보안**: 절차적인 `합니다체`. **일반 손님/상층 구매자**: 정중한 `해요체`.
- **나레이션**: `한다체`. 인물의 심리를 설명하지 않고 동작과 사물만. 어머니 등 존중 대상이 주어일 때 `시`는 유지.

## 메이드/시종 루트

- 엘리너는 `주인님`이라는 호칭과 주어 존칭을 유지할 수 있지만, 문장 끝은 기본적으로 반말로 쓴다. 계약·공식 석상·타인을 인용할 때만 `해요체`/`합니다체`를 쓴다.
- `주인님`을 부르면서 모든 문장을 `해요체`로 끝내지 않는다. 감정이 날카로운 장면은 특히 반말을 우선한다.
- 인용문 안의 다른 인물 말투는 그 인물의 말투를 따른다.

## 표기와 검사

- 인명 표기: 엘리너(Eleanor). 비공식 한국어 패치 표기와 맞춘다. `엘레노어`로 되돌리지 않는다.
- `<i>...</i>`, `<b>...</b>`, `{0}`, `\n`, `*...*`는 보존한다.
- 대사에 화자 이름이나 표정 태그를 넣지 않는다(화자·표정은 Content가 담당).
- 큰따옴표/작은따옴표 안의 인용문은 화자의 말투를 바꾸지 않는다.
- 변경 후 `Localization/ko.csv`의 키 수, `{n}` 자리표시자, HTML 태그가 `en.csv`/`zh.csv`와 일치하는지 확인하고 `python tools/check_project.py`를 실행한다.
- UI/시스템 안내문은 정중한 말투를 허용한다. 인물 대사와 같은 기준으로 반말로 바꾸지 않는다.
