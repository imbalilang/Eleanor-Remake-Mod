# 方向A深化：四路线经营与莉迪亚荐店信物

日期：2026-11-09。性质：基于用户选定方向A的设计方案。路线经营分工按最新指示收敛；家世细节、具体数值、美术造型与排期为本稿提案，尚未实施。不覆盖闺蜜双恋v0.2台本。

## 1. 四线确定的主轴

| 路线 | 主经营循环 | 情感回报 | 视觉重心 |
|---|---|---|---|
| 侍从 | 王尔德投资→她的事业成长→持续分红 | 她在外面取得地位，私下仍选择你 | 已有双画风女仆，礼服可复用 |
| 平等恋爱 | 拾荒带货→母女参与水培→实际收获与日常销售 | 女友、母亲、玩家逐渐形成一家三口般的相处 | 下层生活私服，母亲已有形象获得更多戏份 |
| 战友 | Eleanor亲自购买管制武器/相关物资→行动后带回战利品出售 | 每次交易都能看见她出去做了什么、又如何回来 | 革命身份与私人卸装状态 |
| 双恋 | 莉迪亚荐店→橱窗引来上层客群→实际精品交易→口碑扩大 | 她先替闺蜜来，后来为你的店、最后为自己而来 | 新版莉迪亚，荐店信物，专属约会形象 |

本阶段不再引入治安部女二，也不以凑齐五阵营作为约束。原版核心玩法继续对所有路线开放；独占的是人物参与、额外机会与具体奖励。

## 2. 平等恋爱：让水培真正进入“一家三口”的日常

### 2.1 三人的作用

- 母亲：熟悉水培，能解释一个具体问题，提供有限的指导；有自己的生活，不成为每天来替玩家干活的免费技术员。
- Eleanor：从嫌麻烦到愿意观察、记录、采购和处理收成；可以与母亲意见不同，逐渐贡献自己的判断。
- 玩家：决定是否投入设备与资源，亲手操作现有种植系统，处理产物的使用与销售。

母亲来店不再只有感谢和买东西。她可能先看出水或营养安排的问题，之后顺路来看看，最后会问“上次那一批怎么样”。女儿第一次愿意认真听她说以前嫌无聊的农场小事，玩家见证关系修复。

### 2.2 建议的三阶段经营内容

1. **试着种一批。** 母亲带来一次有限的原生耗材/种植建议。玩家选择已有作物，不要求立刻建大型产线。已有设备的玩家直接试作；没有设备时先通过正常渠道准备，不凭空生成全套工厂。
2. **一起把问题解决。** 实际种植与收获后，三人围绕成品说话。Eleanor带来真正买到的补给或帮忙找销路，母亲点评的是可观察状态，不用一句对白自动给整店产量加倍。
3. **以后有稳定安排。** 解锁低频、明确数量的种植耗材优惠供货，辅以针对实际作物的收购机会；玩家获得的是更可靠的投入和销路。可在剧情中提供一个经过原生目录核实的水培模块购买/赠予机会，具体模块与数值另做验证。

玩法优先通过现有设备、耗材、模块和买卖表现，不新增作物成长界面。拾荒增益仍服务本线，水培是家庭生活的第二个支点；不再同时要求复杂酿酒、化学和全套自动化。

### 2.3 关系场景

- 母亲问玩家某批作物怎么样，Eleanor抢着回答，结果漏了一步，被母亲轻轻指出。
- 女儿替玩家记得补水，母亲替女儿记得吃饭，玩家发现两个人都开始自然地把这里算进日程。
- 收成用于正常售货，也可以实际留下一点；没有留下时以别的食物完成相聚，不把纪念品当通关条件。
- 终章不是母亲为恋爱盖章，而是三人讨论下一批种什么、晚上吃什么，已经自然使用“我们”。

### 2.4 世界事实

仅母亲已经安全、能实际行动的甲乙线展开母女水培来访。甲线归还研究，不能额外开启营养果自由结籽；乙线按实际公开状态处理。甲线可用正常可获得的其他原生作物，母亲保有常规专业能力不等于她仍持有已交回的研究。

旧存档已有机器和作物不能被重置；不把一次库存扫描误当作玩家已经完成亲手种植。收获记录及状态读取需要后续接入验证。

## 3. 战友：让买卖本身就是她的出发和归来

暂不以抽象市场军需委托为主。每轮直接由Eleanor来店：

**出发前买东西 → 玩家实际成交或没有合适库存 → 她离开 → 她回来出售行动所得 → 交易之后才谈自己的事。**

不是每次都重复同一批货。前段她会选武器但缺经验，中段已能解释使用需求，后段开始考虑同伴和持续补给；战利品也从零散回收物到更有价值但来源复杂的货。

- 她作为买家时，按原革命军可接受规则接收相应管制品，具有真实预算，不做无限收购。
- 她作为卖家时，对玩家提供有限优惠，仍有正常售价与原生赃物/违禁属性；利润来自价差和后续销路。
- 支持行动不等于免费献物。公平交易可以完整推进感情，赠予/让利是额外回应，不是必经付费关卡。
- 买卖品类、来访状态和批次应区分，禁止把她刚卖出的货立即高价卖回给她。
- 缺货时她可以另找来源，感情继续；后续反映这次实际是否帮上忙，不假记玩家已经支援。
- 初步以每轮3～4天容纳行动与回访，两到三轮完成主剧情；私人情绪在真实交易后的短段落中变化，避免每轮都受伤哭诉。

这样玩家不需要看任务列表才能知道自己与她有关：付出去的钱、卖出去的武器、摆回柜台的货，以及她回来的样子，本身就是故事。

## 4. 双恋：莉迪亚的家世与背书为什么有用

### 4.1 推荐背景

莉迪亚出身上层区一个经营多年、在高端生活用品或贸易圈有信用与社交影响的富裕家族。具体姓氏与家业待原作设定进一步核对后命名。

保留v0.2的成年、爱漂亮、热心、嘴快、有一点虚荣，也保留早期镯子试探与阶层偏见。她不是职业采购主管，权力来自她真实属于这个圈子、她的个人推荐有人愿意听。

“显赫名门的女儿”足够承载用户提出的贵族千金感觉。目前没有核实到原作的世袭贵族爵位制度，首版不直接发明公爵、伯爵或王室。也不需要新增有立绘的父亲、管家和家族会议。

### 4.2 她的影响范围

她能推荐一家店、让几个熟悉的消费者愿意下楼、为一次私人采购介绍买家。她不能签通行、指挥治安部、改变母亲案件或替别人保证录用。

家族在生活消费领域有声望，不代表能与帕斯泰尔在案件上抗衡。她在危机中能做的是陪伴、核对实际需要和已有范围内的帮助；这避免“家里这么厉害，为什么一开始不直接救母亲”的漏洞。

### 4.3 对旧剧情的解释

初见不必突然变成显摆身份。她依旧拿镯子试探玩家，因为她误以为自己熟悉的一套识人办法也适用于这里。之后承认自己做得不体贴。

家世补充只让玩家逐渐明白她以前的生活尺度，不追溯洗掉偏见，也不把每场台词写成“我父亲如何”。已发布剧情不重播，新场景补足事实即可。

## 5. 经营核心物品：“莉迪亚的荐店铭牌”（暂名）

### 5.1 物件与含义

一枚小型、可立在橱窗中的珐琅金属铭牌，带其家族可识别的纹样与莉迪亚个人署名。含义是“这里是我愿意推荐、自己也会光顾的店”，不是营业许可、官方认证或全家族的无限担保。

名称和说明明确是她的私人推荐。材质与图案体现上层生活；在64×64物品图里突出轮廓和色块，姓名放文字说明，不要求玩家读清图中微小字母。

首版建议1×1占格，只有一个实体物品；从初期引荐到口碑形成使用同一物件，不连发三枚升级徽章。不得把铭牌本身标成普通待售奢侈品让顾客买走，也不让它满足“橱窗已有奢侈品货物”的条件。

### 5.2 玩家怎么使用

莉迪亚交给玩家后，用几句话解释放进已有橱窗即可。玩家自行放置；取下后停止未来新增引流。无需新面板、每日点击、额外电话签到或新操作。

她的背书是送来了一个机会，玩家仍须选货、准备本金、陈列、检视、议价和成交。客人不会自动掏钱，也不会因为认识她就忽略假货和违禁品。

### 5.3 首版建议效果（待平衡）

| 条件 | 提议效果 |
|---|---|
| 铭牌在有效橱窗中，处于已建立的引荐阶段 | 每个新的营业日50%概率增加一名带有简短来源说明的上层买家 |
| 已交付两次明确的合作反馈，业务口碑阶段完成 | 概率可提升到75%，并扩大买家的有限需求/预算范围 |
| 上次额外买家已经来访 | 至少隔一个营业日再抽取；最多保留一个待来访客 |
| 展示着实际可售奢侈品 | 优先生成愿意购买这些品类的客户；不要求他必买某一件 |
| 没有合适库存 | 降低引流机会或暂不排额外买家；用首秀/已有来访反馈告知缺货，避免排一群空手离开的顾客 |
| 玩家取下铭牌 | 停止未来引流；已经确认在路上的一位客人正常到店，不把人凭空删掉 |

上表数值只是首版试算起点，不是已实现或平衡结论。重点是在10个营业日内能明显看见几位额外上层客人，又不把原店变成无限接客。不能用同日反复开店、重复放入铭牌或读档重新抽取。

优先使用**独立、有限的额外引荐客**，而不是直接增加全局上层随机权重。后者可能只是减少其他阵营客人，玩家得到的并非净增机会。额外客户不替换原剧情/执法来访、不抢晨间重要事件、同日不与大型双恋演出叠加成长篇队列。

原生挑剔买家的声望门槛和冷却继续保留。MOD引荐客是清楚标识的独立来源，不假装玩家已经解锁原版待遇。已有多个客流增益时应设总量检查，实际数量需测试。

### 5.4 为什么能卖得更多，而不只是“多几个人”

一是客群更匹配：愿意买实际奢侈品；二是有足够但有限的预算，能消化部分普通顾客买不起的库存；三是可通过莉迪亚的后续短段提前获知某种需求。

不同时叠加永久涨价、无限预算、任何物品都收、无条件免检。核心收益是高端货更容易找到买家，仍需要玩家拿出货。

仅增加销路还不够：首段业务给一次通过正常交易购入小批原生精品的机会，或引导使用现有库存；之后低频安排既有上层通用卖家作为可选供货。不能每次既低价保送货、又保送高价买家，形成毫无选择的提款流程。

### 5.5 反馈必须看得见

- 第一位来客明确提一句“莉迪亚说可以来这里看看”。不新建具名常驻NPC。
- 莉迪亚下一次根据实际成交、未成交或缺货反应，而不是一律宣布生意成功。
- 第二阶段有一次客户不只提她，也提店铺实际办成的事，体现玩家自己的信用。
- 铭牌物品说明写明当前引荐效果及冷却规则；若不能直接接入原生橱窗预测，应明确用自身说明/提示，不伪造预测显示。
- 重复客人用短台词，避免每隔一天重演一次长篇感谢。

### 5.6 赠予时机与关系

救母后、玩家接受撮合与相关合作内容时交付，最迟应在第50～55天让玩家体验首批收益。不是第68天双恋完成后才送，让玩家再空过十天测试。

初期她说是“让埃莉诺回来时，少听你抱怨生意”；实际她也想让玩家认真对待自己的推荐。中期她的心动不通过进一步加钱表达，而通过她即使没有生意也来、开始希望被单独看见来表达。

玩家拒绝第二段恋爱后，已经成立的正常推荐不因伤心被报复性撤销。莉迪亚私人来访会暂停，合作与感情分别处理；拒绝双恋的存档可转回普通恋爱后续，不能收一次铭牌就叠加解锁所有完整路线终局收益。

## 6. 双恋全流程骨架：人和生意彼此推动

阅读稿编号将与运行章节另做映射，下表是待细写的场景顺序。时间为正常模式设计目标，受已发生的救母和关系事实约束。

| 时段 | 剧情 | 经营行为 | 感情作用 |
|---|---|---|---|
| 第35～38天附近 | 保留初次镯子交易、Eleanor回应 | 原有真实交易 | 展示她的热心、偏见和不成熟，不直接加第二恋爱 |
| 第46～49天，母亲已安全 | 她道谢，提出撮合；见到店里一件适合上层消费者的东西 | 看实际库存或带来可购买样品的后续机会 | 她起初确实只想帮朋友 |
| 第49～51天 | “这块牌子，摆外面。” | 得到铭牌，玩家亲手陈列 | 这是她第一次以个人信用支持玩家 |
| 第50～53天 | 第一位介绍来的顾客 | 实际检视/买卖，缺货也有完整反馈 | 玩家看见她的帮助，女方也看见玩家如何对待推荐 |
| 第52～55天 | 原有Eleanor告白与三人约饭，莉迪亚先离席 | 生意反馈接在安全来访，不侵占告白 | 保留僚机成功却失落的关键反转 |
| 第54～57天 | 第二个需求，她与Eleanor对挑货意见不同 | 玩家据物品与需求完成一笔交易；不靠选“谁说得对”刷恋爱 | 玩家认真看见莉迪亚的个人喜好，她不再只是传话人 |
| 第56～59天 | 店有回头客，她却突然少来了 | 客流继续，合作不因她躲开就停摆 | 玩家发现缺的不是生意，而是她本人 |
| 第59～62天 | 她坦白；玩家与两位女性分别把心意说清，再共同确认 | 不新增付款或采购考题 | 关系选择明确，不用一轮轮重问同一问题 |
| 第63～65天 | 两次独立私人相处 | 业务短反馈可附带，不能替代相处 | 莉迪亚专为见玩家打扮，Eleanor也明确自己的位置 |
| 第66～68天 | 三人晚饭与共同收束 | 当天正常经营继续，实际客流能力已兑现 | 她不再为两人腾地方；牌子留在窗里，人留在桌边 |

“50～53”等是连续窗口，不要求每个场景都额外耗一个日槽。首笔交易结束后的反馈可同访交付，亲密与重大表态保留各自的完整场景。

关键经营段至少有首位引荐客与第二次需求两处实际行为，但不能要求玩家随机等到某件稀有货或连续完美成交才能告白。缺货时她会调整需求或另作安排；玩家愿不愿意开展这门生意与是否愿意双恋分开记录。

两次正常经营表现可推进口碑阶段，恋爱推进靠实际关系场景。达到第60天仍缺业务样本时，后续业务可继续，不能因此把人物的坦白无限冻结。

## 7. 双恋与侍从如何避免重复

侍从的资金主要投向她的外部事业，玩家得到分红，高潮是她重获地位后仍然留下。

双恋的资源主要流入玩家自己的当铺：她们带来消费经验和引荐，玩家亲自把生意做成。高潮是两位各有生活的上层女性不再轮流替别人传话，而是都明确为自己来到这里。

不复制侍从四个王尔德项目、不再购买一轮“返回上层区”、不追加同款分红账本，也不把她们变成两位侍从。Eleanor的工作机会仍由实际能力与甲乙事实承接。

## 8. 美术与资产预算

- 延续v0.2的新版莉迪亚方向：蜂蜜棕长卷发、奶油白/玫瑰色衣装、成年明艳气质。家族身份只需加入一处与铭牌呼应的小纹样或饰品，不改成权威官员或冷艳企业家。
- 基础画像若全局更新，原版/美化各一张，仍属于全局人物升级。
- 双恋独占建议为莉迪亚私人约会装，原版/美化各一张；首次用于关系确认后的独立相处。不能把全局基础图再次算作独占奖励。
- 新增一个荐店铭牌物品图，64×64透明像素图；不需要新场景、家族住宅、常驻家长或贵族宾客群像。
- Eleanor可在合适的双恋邀约复用已有礼服，但不复制侍从晚会剧情；未开美化时的造型一致性另做回退说明。
- 母亲已有双版本画像通过更多实际剧情发挥价值；平等线不必为每次种植另画一个表情。

## 9. 接入核查与实现边界

本次复核了当前游戏的 `StoreClientManager`，并参考上一轮已读取的 `ShowcaseHelper`：原作确有按橱窗与声望条件生成奢侈品买家的路径。说明该设计可以沿用原交互，但没有一个现成的“贵族信物加客流”功能，仍需新增物品资格、额外客户与防重逻辑。

建议用本MOD既有的客户生成钩子和独立存档键实现引荐，不重写原生总客群公式。物品唯一性、橱窗位置、玩家所有权、每营业日一次抽取、待来访状态、实际来访冷却、停用和读档均需验证。

物品应避免被原生夜间失窃或抵债机制误收，采用项目已经验证的重要物品保护；意外缺失时提供一次受控补领，不能刷出可出售的复制品。人为取下不丢失资格、不立即抽新的随机结果。

最终验收：原版剧情来访不被替换；客流提升真实且可归因；至少两种库存规模都有有效体验；没有同日刷客、无限套利、原版声望门槛静默解除；中英、双画风和旧档均正确。10个营业日的增量收入需扣除收货成本和额外营业负担后，再与另外三线比较。
