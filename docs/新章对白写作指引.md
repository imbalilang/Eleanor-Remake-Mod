# 新章对白怎么写

根据 2026-11-17 至 11-21 的删行试改、作者认可的《停下》、五条路线的修订，以及玩家对《窗口》的反馈整理。供写新章、改选项和监修简中时使用。人物口吻以原游戏简中、作者定稿和本路线走到此刻的经历为依据。[原作逐场对照](原作Eleanor章节_对照稿_2026-11-10.md) · [修订记录](文案修复_2026-11-21/执行记录.md)

## 动笔时先定这次来访

给主笔的场景说明，写清**谁来做什么、碰到什么事、这次由谁作决定**。例如《停下》可以写成“莉迪亚以为埃莉诺在躲她，来窗口打听，才知道自己约店主的前一天发生了什么”。这样开场她有一件想问的事，听见答案后也有理由乱了方寸。把“三个人的关系”“歇业款的归属”“莉迪亚的歉意”列成三项待解释的主题，她就容易照着讲完三段话。金额、前情和各选项的结果留在章纲里，供落笔和监修时核实。[《停下》的三个入口与正文](文案修复_2026-11-21/后宫.md#dv11)

## 写到这些地方时怎样落笔

| 人物刚受窘，就把善意、界限、责任和可能的误会逐一澄清。旁人还没反应，她已经替双方弄清了关系。 | 找到她此刻最介意的那件事。说出口以后，让对方有机会回答，也容许她带着没想明白的事离开。删去整句解释后，直接读下一句。 | 《停下》留“我还非要你夸我好看”、一句道歉和两千歇业款。末句“去啊。……最好还是她室友来开门。”既答了要不要去，也留下她还怕见朋友的那一点。 |
| 人物纠正自己的措辞、规定对方该怎么听，又把立场从头说一遍。 | 把改口前后两句并起来看。请求变了、软肋露出来了，就留。意思已经说足的地方，删掉后面的释义或预演。 | 手镯段“别卖。我是说，别卖给别人。”改口后给原主留下了回赎的余地。《嘉宾栏》里店主念出“我的店主”，她一句“谁让你念出来的。”便转头问外套。 |
| 两人轮流复述结论，或用同一套短答、嫌对方字少、要求重说的问答撑起一场戏。 | 让下一句出自听者自己的需要。确实要得到同意，就把问题交给本人，停下来等答。人物各有自己的话要说时，长一点也值得留。 | 《交完班》问“可我还想叫你主人。你肯不肯？”才轮到店主选。《嫁给我》保留埃莉诺想再听一次求婚，删去随后数店主用了几个字的几轮对白。《点头》保留两人分别答应，也保留莉迪亚想单独来见他的日子。 |

| 玩家点过选项或刚经历一场戏，合流、下次来访、结局页又解释一次，有时还替玩家改了主意。 | 把各选项末句分别接到共通段首句。已经办完的事让它过去。非得带到下一段的消息，交给有理由主动说的人。选项文字直接写店主此刻可以做什么。 | 《带话》选“继续谈货”，战士自己捎来杯子的口信，店主可以一直只谈货。《门外》的“我好想你。”留给埃莉诺当面说，结局页写她后来又来敲窗。 |

## 一框留多少字

原作 18 场对照中，埃莉诺有 109 个不同的口播框。按汉字、字母、数字计，标点不计。她的**框内单句 P95 为 22 字，含同框动作的对白框 P95 为 25 字，最长一框为 37 字**。原作也有一句话跨三框说完的情形。修后 MOD 同角色的框内单句 P95 为 19 字，含动作的整框 P95 为 28 字。写新章时，单句超过 22 字或整框超过 25 字，读一遍是否塞进了第二件事。整框超过 37 字，优先看动作和上文已经交代的部分。情急的一口气、交易条件和首次揭示的事实，可以按场景留足。原来报果子的台词只有 8 字，改成 14 字反而顺口。[原作与修后统计、计数方法](文案修复_2026-11-21/清单式对白与原版句长.md)

## 收稿时顺读本次新增的部分

从本次来访的上一句读进来，走过每个新选项，到下一句共通对白或交易反应为止。有不同前情时，分别从玩家实际见过的事情接入。比如拒绝送礼与接过本子，莉迪亚面对的是两个不同的回应。只在新段引用了旧承诺、旧物或上次来访时，沿那处往回核对。

听见解释多了一层，先试着整句拿掉，再读一遍对方的回答。如果因此少了明确的同意、拒绝、付款依据，或少了这个人硬撑时最好听的那句话，就把它恢复。拆合对白框时，顺手核对受影响块的说话人、动作、各语言行键和续读起点。这样改稿随新章完成，编辑只需回到真正受影响的几句。
