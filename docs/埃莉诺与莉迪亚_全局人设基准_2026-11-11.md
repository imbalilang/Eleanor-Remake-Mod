# 埃莉诺与莉迪亚：全局人设基准

日期：2026-11-11。性质：全局角色指导，不替代各路线台本，不新增剧情事实。用于统一共用前段、侍从线、双恋/后宫线、革命军线、普通/平等恋爱与朋友结局中的性格、口吻、关系边界和视觉阶段。

## 1. 共同母题

### 1.1 一个落难，一个还在上面

埃莉诺从上层区跌到下层区，失去母亲、住所和旧社交圈；莉迪亚仍在上层区，是少数还肯下来看她的旧友。两人的反差是全局母题：同出上层，一个被迫重新学怎么活，一个用安排和热闹维持旧生活。不要把两个人都写成落难，也不要把莉迪亚写成拯救者。

### 1.2 玩家得到的东西

埃莉诺线的核心不是“救她”，而是“她明明能回上面，却愿意把选择留在这里”。玩家提供的是公道价格、稳定在场和不替她作决定。她能重新工作、救母、回上层区或加入革命军，玩家都在场，但不替她选。

莉迪亚线的核心不是“多一个女人”，而是“最热心替你追她的人，最后也想被你选择”。她必须作为完整的人被看见，不能是奖品、补偿或退让者。

### 1.3 两条共同的底线

两人都不靠可怜赢好感，都不用身体或资源换关系，都不说“只要你们幸福就好”式自我抹除。她们可以争执、吃醋、提条件，但不靠隐瞒和算计推进关系。

## 2. 埃莉诺

### 2.1 核心人格

- **骄傲**：阶级骄傲、审美骄傲、能力骄傲。她落魄后仍知道自己懂货、懂礼数、懂怎么在上层区活；这些不是错觉。
- **嘴硬**：先顶一句，再漏一点真话。她的“傲”是保护尊严，不是习惯性羞辱别人；被帮助、被看穿、被照顾时最容易启用。
- **爱美**：喜欢漂亮东西，懂成色、保养、搭配；穷下来也不肯让品味一起消失。不是浅薄，是她确认“我还是我”的方式。
- **有判断**：会算钱、记清单、看人、做决定。她可以求人，但不会把人生交给别人代管。
- **阶级偏见没有一笔勾销**：她说过“井底之蛙”“底层人一辈子都这样”，后来当面道歉，并在具体事情上修正；旧刺仍会在紧张时冒出来。
- **悲伤转成行动**：母亲被捕、判罪、死亡之后，她可以失控一次，但不反复自审“还有没有别的路”。她更常做的是找工作、筹钱、加入组织、安排护送。
- **矛盾**：想独立，又想有人可靠；想回上层，又在下层建立自己的生活；恨被可怜，又会直接开口要食物；骄傲，又需要被看见。

**年龄口径：** 20岁，成年。她的判断力来自家教、认货和实际操作，不是多年社会经验；年轻让她的骄傲和失措都更直接，但不把她写成不懂事的孩子。

### 2.2 阶段与路线

| 阶段／路线 | 处境 | 她想要 | 她怕 | 外在表现 | 禁止 |
|---|---|---|---|---|---|
| 刚落难 | 母亲被押，钱快用完，住下层 | 食物、回上层、证明母亲无罪 | 被当成笑话、被可怜 | 挑剔、急躁、直接偏见、嘴硬；仍会认货算价 | 突然谦卑、突然温柔、立刻融入下层 |
| 开始自立 | 拾荒、卖旧物、短工、学着记账 | 自己挣、自己还母亲清白 | 依赖别人、被看轻 | 感谢变直接，仍嘴硬；会拿具体货物和价格说话 | 圣母式感恩、把穷苦写成净化 |
| 侍从／事业 | 预付工钱、救母、工作、回上层区 | 用自己的名字站住，不接空职位 | 被当成被养的人、被安排 | 私下可叫“主人”，公开要尊严；工作和感情分开谈；私下越来越愿意把决定交给他 | 公开叫主人、恋爱后失去判断、把事业当恋爱奖励、无脑服从 |

| 革命军 | 母亲死亡，加入革命军，跑补给和护送 | 做事、护住同伴、活着回来 | 回不来、成为负担、被当可怜人 | 干脆、能带队；私下安静、靠近、像受伤的小兽；不确认恋爱 | 反复自审、向玩家求道德审判、把当铺当指挥部、写成无助宠物 |
| 普通／平等 | 工作、恋爱、仍住下层或自己选择去留 | 平等相处，不被替作决定 | 被管理、被当成需要拯救的人 | 会反驳、会算账、会主动留下；恋爱后脾气仍在 | 突然贤惠持家、变成店员、放弃自己的工作 |
| 朋友／非完美 | 没有恋爱确认，仍互相照应 | 保留尊严和来往 | 被吊着、被怜悯 | 做常客、帮忙、说清边界；不无限等待 | 苦情等待、报复、把友情写成失败结局 |

### 2.3 傲娇的行为规则

1. **三段式**：先顶一句 → 做一个具体动作 → 漏一点真话。例：她先说“谁要你帮了”，然后把杯子推近，最后问“你吃过了没有”。
2. **不是每场都要顶**。允许她直接接受一次、沉默一次、主动转谈货物一次。连续的“安慰—顶回”会把她写成防御机器。
3. **“娇”是让步，不是娃娃腔**。她不会突然撒娇要抱抱；她会多坐一会儿、记得给玩家留东西、把椅子挪近、问一句不重要的日常。
4. **道歉短而具体**。错了就说“那句话我说错了”，随后用行动补；不跪求原谅，不长篇自我剖析。
5. **测试玩家用具体事**：价格、货物、阶级话、请求。玩家答得公道、不谄媚、不替她决定，她才继续靠近。
6. **不解释自己的成长**。让清单、工作、护送、留下的动作承担变化；不要让她说“以前我只管自己，现在……”。
7. **受伤时更尖，安全时更静**。不要把脆弱写成眼泪和独白；她常用的是一句短话、一个停顿、一个不肯走的动作。
8. **直接感谢少而重**。她平时用“这笔我记着”挡住感谢；真正说“谢谢”时，分量要足，场景要少。

### 2.4 与玩家的关系

- 玩家是当铺老板，也是第一个按公道价对她、不捧她、不可怜她的人。她最初用价格和阶级话试探他。
- 关系推进顺序：交易 → 信任 → 私下来访 → 身体距离变近 → 明确选择。不是先告白再补生活。
- 她需要的是可靠在场、诚实定价和不替她作决定，不是英雄救美。
- 后期她也会保护、提醒、替玩家办事；不能一直写成收好处的一方。
- 路线差异：
  - 侍从：私下“主人”、契约、依赖与自愿留下；公开场合必须保留尊严；私下越来越愿意把决定交给他。
  - 双恋：接受分享，但吃醋、提条件、要自己的时间；最终两人都真心留下，不吃“正宫”叙事。
  - 革命军：不确认恋爱，不叫主人；外面越硬，私下越脆弱；终局只用一次“我想见你”说破。
  - 普通／平等：平等恋人，会反驳、会分担、会主动留下；甜来自重复和小让步。
  - 朋友：明确边界，不吊着，不把友情写成失败。

### 2.5 说话方式

- 句长：平均 15–19 字，短句为主；情绪上来时允许长句和连续追问，不能全篇都是均匀短句。
- 语气：直接、有起伏、会反问和感叹；上层区词汇和具体货物、价格、保养、礼数混在一起。
- 常用语：“喂”“哼”“绝了”“荒谬”“少来”“别以为”“谁……了”“你倒是”“我可没”“行吧”。
- 情绪峰值可以语塞：“你别说话，让我先说完，不然我可能就说不出口了。”
- 原作例子：“呵，你们下层区管这种地方叫‘商店’啊？”“赶紧的，有吃的没？”“哇，你吓到我了……”
- MOD 例子：“价签？……哦。对，你们这里什么都要钱。”“我还没落魄到要一个开当铺的来可怜我。……这笔我记着，别指望我说谢谢。”“让我站一会儿。”
- **不要写**：大量“……”开头、心理学术语、抽象关系总结、“不是X，是Y”金句、每次都用同一套“这笔账”收尾、每句话都附动作、公开场合叫“主人”。

姿态与表情：抬下巴、抱臂、先看货再看人；紧张时看价签、扶货架、捏杯沿；累的时候坐得比平时低。不要用通用的脸红、咬唇、眼底闪光替代具体动作。

**革命军私下：** 进门先看店，再坐下；不急着脱装备，靠近后才会把重量放下；累的时候不说话，抓住袖口或衣角。用动作表达“我回来了”，不靠长篇独白。

### 2.7 绝对不能写崩

- 突然贤惠持家、包办家务、变成店员或“贤内助”。
- 无理由、无条件、无代价的告白；把“我喜欢你”当日常语气词。
- 反复自审母亲之死，反复问“还有没有别的路”。
- 让玩家替她决定研究、工作、去留、路线。
- 把“主人”当全局称呼；在公开场合失去尊严。
- 一笔勾销阶级偏见，不道歉、不修正、不保留旧刺。
- 写成只会撒娇的大小姐、等待拯救的奖品、或永远正确的圣人。
- 用莉迪亚式的连珠热情话、心理分析或网络流行语说话。
- 用生理套话和性化凝视替代关系推进。

## 3. 莉迪亚

### 3.1 核心人格

- **明艳**：22岁，成年不久，上层区家境宽裕，漂亮、爱热闹、爱漂亮衣服和浪漫故事；知道自己好看，也喜欢被夸。
- **热心**：真心想帮埃莉诺，会打听工作、看房、安排饭局、介绍店家；她的帮忙常常具体有效。
- **有一点虚荣**：会为名人故事多付钱，会在意别人有没有看见她的发夹；被认真关注时反而失措。
- **不是职业经纪人**：她熟悉店家、能介绍真实机会，但不能决定录用、签发通行、撤销案件；不能把整条线写成她安排一切。
- **自己的感情拿不定主意**：替别人出主意时头头是道，轮到自己连第一句从哪说起都不知道。
- **旧偏见仍在**：她会用镯子试探玩家，会问“你是不是看中我以前有钱”；后来改口，但不抹掉过去。
- **善良但不完美**：她的安排有时过度、有时自以为是；她会道歉、收手，但不突然变成圣人。

**年龄口径：** 22岁，成年。她的“会安排”来自热情和观察，不是多年社交经验；年轻让她替别人出主意时更大胆，轮到自己时更慌。

### 3.2 阶段与路线

| 阶段／路线 | 处境 | 她想要 | 她怕 | 外在表现 | 禁止 |
|---|---|---|---|---|---|
| 共用／朋友 | 埃莉诺刚落难，她仍在上层 | 帮朋友、看热闹、确认玩家靠不靠谱 | 被排除在朋友的新生活之外 | 挑埃莉诺不在时来、卖镯子试探、问工作、嘴快 | 暗恋玩家、阴谋、职业经纪人化 |
| 侍从线旁观 | 埃莉诺与玩家进入侍从约定 | 替朋友高兴，也想确认这关系不伤人 | 被当成外人、被瞒着 | 打趣“主人”，尊重私下边界；不抢线 | 嫉妒、破坏、也想要同款关系 |
| 双恋 | 撮合者逐渐动心 | 被看见本人，也想要自己的位置；最后愿意与埃莉诺同桌 | 被当成“顺带的”、被朋友怨恨 | 先安排、后失措、直接谈、提条件、要自己的约会 | 无条件退让、奖品化、三人关系由玩家替她们决定 |
| 被拒绝／未入线 | 玩家或埃莉诺不接受扩展 | 保留朋友关系，不被吊着 | 被羞辱、被当成笑话 | 接受、收手、继续自己的生活；不报复 | 死缠、报复、突然变恶毒女配 |
| 革命军 | 埃莉诺加入革命军，处境危险 | 帮朋友，但帮不上核心 | 被拒绝、被时代甩下 | 一次来访、自然断联、不直接出场；不掌握情报 | 当拯救者、资源中介、政治活动家、恋爱奖品 |

**实施状态：** 共用、侍从、双恋已有当前 Content 依据；革命军 v0.4 候选明确她不出场，只留“莉迪亚找过我，我没回”的断联事实。旧阅读稿里的丙06来访是旧版，不要和新候选混用。

### 3.3 僚机机制与成长

1. **安排要具体**：定三人位、编借口先走、教开场白、帮看衣服、介绍真实买家。她的计划常常有效，也常常让她自己吃亏。
2. **帮忙不能替人决定**：她可以问空缺、陪她看房、介绍工作；不能替埃莉诺接受条件、不能替玩家表白、不能替两人确认关系。
3. **成长是“先问再帮”**：从“我都替你们想好了”到“你要我帮什么”；从替朋友挑衣服到给自己挑一件。
4. **双恋线必须有她自己的条件**：各自约会、埃莉诺不能每次把她让出去、玩家不能瞒着一方。她不是“只要你们幸福”的退让者。
5. **她有自己的生活**：朋友、爱好、审美、工作机会；不能每场都只谈撮合，不能只作为信息传递器。
6. **被拒绝也要有尊严**：接受、收手、继续来往或自然淡出；不报复、不消失成悲剧符号。

**双恋弧线：** 误解／试探 → 各自承认 → 两人自己谈 → 三人同桌。每一步都要有具体场景，不能跳到“我们三个人在一起吧”。

### 3.4 说话方式

- 句长：比埃莉诺长，节奏快；爱提问、爱报告、爱感叹、常自我打断。
- 常用语：“好啊”“当然”“哎呀”“我本来”“你别笑”“那可说好了”“你就说——”“……不对，等等”。
- 直接说感情时反而短：“我喜欢你。”“我想跟你在一起。”“今天我也想吃。”
- MOD 例子：“你就说——今天的发夹真好看。”“我订了个位置，三个人的。……不然你们俩大眼瞪小眼，谁找话说？”“替她高兴，也替你高兴。就是……她没提到我，我又气自己怎么连这个都要在意。”“今天我也想吃。”
- **不要写**：职业经纪人／客户网／预约本行话、政治口号、阴谋暗示、“只要你们幸福就好”、幼稚娃娃腔、和埃莉诺一样的短促冷嘲。

## 4. 两人关系

### 4.1 旧友，不是情敌剧本

两人同出上层区，莉迪亚是埃莉诺落难后少数还肯下来看她的旧友。埃莉诺用嘴硬和拒绝安排保护自己；莉迪亚用介绍工作、镯子试探和饭局安排表达关心。两人都承认对方在自己生命里重要，但不是每场都要谈对方。

### 4.2 帮忙与拒绝帮忙

莉迪亚的帮忙真实有效，但附带她的判断；埃莉诺只接受不剥夺主体性的部分。已有例子：

- 莉迪亚介绍工作，附带“别再公开提母亲案子”的条件，埃莉诺拒绝。
- 莉迪亚安排空职位，埃莉诺拒绝；介绍真实买家，她接受。
- 莉迪亚挑埃莉诺不在时来卖镯子，试探玩家是否占便宜；玩家按公道价收，她才认可。
- 莉迪亚在双恋线先安排、后动心、再和埃莉诺直接谈；不是玩家在两人之间传话。

### 4.3 双恋成立条件

1. 母亲安全、原恋爱资格成立、玩家明确接受扩展；接受撮合不等于接受三人关系。
2. 玩家先亲口告诉埃莉诺；不能瞒着一方维持关系。
3. 埃莉诺和莉迪亚先自己谈，分别明确愿意；不是玩家替她们决定。
4. 埃莉诺保留吃醋和条件；莉迪亚要求自己的约会和时间；两人都不是奖品。
5. 三方确认后才进入共同关系；不能用一个选项跳过独立同意。

### 4.4 革命军线的自然疏远

埃莉诺加入革命军后，莉迪亚帮不上核心，也不应被写成拯救者或情报中介。现有丙线她只来一次，说明不是来带她回去；v0.4 候选让她不出场，只留“莉迪亚找过我，我没回”。这是自然断联，不是绝交，也不是把莉迪亚写成反派。

### 4.5 同时破坏两人的写法

- 一方替另一方说“她其实也喜欢你”。
- “我退出，你们幸福就好”“正宫认可”式让爱。
- 用资源、工作、救济换感情。
- 两人突然都变成政治活动家，或都掌握对方不知道的情报。
- 两人说同样的俏皮话、用同一套心理分析。
- 把埃莉诺写成需要拯救的可怜大小姐，把莉迪亚写成阶级叛徒或情敌。
- 用身体、吃醋或性张力替代真正的选择和谈判。

### 5.2 玩家向吸引力：四线各喜欢她什么

路线卖点不是“她很好”，而是玩家在这条线里得到一种别的线给不了的关系体验。写每一场戏前先问：这场戏让玩家多喜欢她一点的具体理由是什么？

**四句总纲**

- **常规恋人线**：她被生活磨过，却只在你面前保留挑刺和撒娇的权利。
- **侍从线**：外面的人越来越听她的，她越来越愿意听你的。
- **后宫线**：最难的两个人，最后都愿意为你留在同一张桌子边。
- **革命军线**：她在外面是能带队的人，回到你这里才敢不做声。

| 路线 | 一句话卖点 | 玩家得到的独特体验 | 她的反差 | 关键写法 | 不能写成 |
|---|---|---|---|---|---|
| 常规／平等 | 傲娇、日常；落难千金没有变成圣人 | 被一个骄傲的人在日常里慢慢选中；甜来自重复和小让步，不靠大场面 | 对外挑剔、要强；在你面前挑刺、算账、顺手照顾 | 杯子、货架、饼干、账本、价钱；拌嘴后多坐一会儿；她记得你的习惯 | 无脑甜、贤惠持家、突然温柔、每场告白、流水账日常 |
| 侍从 | 身份越来越高，私下越来越愿意把决定交给你 | 独占的信任；外面越有地位，私下越只对你低头 | 公开场合要尊严、能办事；私下叫“主人”、问“你说了算不算” | 外面她作决定，回店把小事交给你；公开与私下分场；她可以拒绝 | 公开羞辱、失去判断、无脑服从、未成年人式依赖、女仆工具人 |
| 后宫 | 从误解到彼此认可，玩家得到齐人之福的圆满 | 两个人都真心留下；三只杯子、两段约会、一张晚饭桌 | 两人先试探、吃醋，再自己谈开；不是突然大度 | 两人直接谈；各自约会；三人同桌；互相认可后仍有小摩擦 | 奖品分配、无条件退让、“正宫认可”、两人突然不嫉妒、玩家瞒着一方 |
| 革命军 | 外面越残酷，私下越脆弱；像受伤的小兽 | 成为她唯一不用逞强的地方；保护欲与心疼 | 外面能带队、能开枪、能回来；回店坐下、靠近、不说话 | 伤、尘土、袖口、杯子、睡稳；先说结果，后漏害怕；脆弱用动作不用独白 | 无助、幼稚、反复创伤倾诉、求道德审判、把当铺当指挥部、每次崩溃 |

**常规恋人线：傲娇与日常**

1. 她挑店里的小东西：杯子缺口、货架歪了、饼干不好吃。嘴上嫌弃，手上帮忙。
2. 她用交易和算账靠近你：问价、压价、替你算成本，顺便记住你的习惯。
3. 她不肯承认自己在等你，但会多坐一会儿、留一件东西、约下一次。
4. 甜不在大场面，而在重复：同一只杯子、同一句“下次再说”、同一条她不肯承认的回家路。

边界：日常不是没有摩擦，也不是把她写成贤惠店员；她仍然会反驳、会算账、会坚持自己的判断。傲娇不是每句都顶，娇也不是娃娃腔。

**侍从线：身份上升 × 私下服从**

1. 外面：她被人称呼、办事、承担；她越来越能作决定，也越来越有地位。
2. 回到店里：她把一些小事交给你决定——今天穿什么、这单接不接、今晚留不留。她用“你说了算”“听你的”，只在私下。
3. 公开场合：她仍然要尊严，不让人看见私下那一面。反差由场景切换成立，不靠她当众降格。
4. 关键不是“她变弱了”，而是“她越来越强，却自愿在你面前放下控制”。

边界：服从必须私下、自愿、可拒绝；她仍有判断，仍会说“不”。不写公开羞辱、不写失去自主、不写未成年人式依赖。全年龄尺度内，用称呼、决定权、坐姿和距离表达，不用露骨支配。

**后宫线：误解到认可，齐人之福的圆满**

1. 误解：莉迪亚热心安排，埃莉诺吃醋、防备；两人都不肯先说破。
2. 各自承认：莉迪亚先承认自己的心意，埃莉诺先承认自己介意；不是玩家替她们说。
3. 两人自己谈：她们直接谈开，互相认可，不是“正宫认可”，也不是谁退出。
4. 圆满：三只杯子、两段约会、一张晚饭桌；两人都留下，而且都保留自己的脾气、工作和条件。

边界：齐人之福是两个人真心选择的结果，不是奖品分配。不能写成“只要你们幸福就好”、不能写成一人生气一人退让、不能靠隐瞒维持。圆满里仍可以有小摩擦，摩擦后仍选择同桌，才是这条线的甜。

**革命军线：残酷 × 私下脆弱**

1. 外面：她带着任务、伤和尘土回来，先说结果，不说怕。她能带队、能开枪，也能替同伴收尸，还能活着回来。
2. 私下：她坐下、靠近、不说话，让你处理伤口，吃一点东西，睡一会儿。脆弱通过动作和停顿，不通过长篇创伤独白。
3. 离开：她恢复公事脸，交代下一次；不把当铺当指挥部，也不把脆弱变成永久依赖。
4. 关键不是“她需要被拯救”，而是“她只在你这儿不用逞强”。她是受伤的小兽，不是等待收养的宠物。

边界：脆弱必须具体、私下、非言语；她仍然能作决定、能保护同伴。不写无助、幼稚、反复创伤倾诉、求玩家审判。不要把革命写成背景板，也不要把玩家写成指挥官。

**四线共同底线**

- 玩家喜欢她，不是因为她惨，而是因为她在惨里仍有锋芒、判断和具体的可爱。
- 每条线的卖点都要由具体场景成立，不靠旁白总结“她其实很温柔”。
- 反差不是人格分裂：同一套核心性格，在不同关系里露出不同面。
- 不要让一条线的卖点污染另一条线：革命军线不要突然出现侍从式服从，后宫线不要写成革命军式脆弱，侍从线不要写成常规日常的放大版。
- 共用／朋友线不卖恋爱，卖“你先看见她”；不要提前使用四线的卖点。

## 6. 写作与文风

### 6.1 去AI味的共同规则

- 用具体物件、价格、货物、衣服、食物、清单承载情绪；动作之后不再补“这个动作说明……”。
- 每场只承担一个新的信息、态度或关系变化；没有变化的往返问答删掉一轮。
- 允许停顿、答非所问、说一半、说反话；不追求每句完整礼貌。
- 不让角色解释自己的成长；让清单、工作、护送、留下的动作承担变化。
- 遮住说话人，能否分清是谁在说？如果一句台词换给另一个人也成立，重写。
- 结尾停在动作、交易结果、一句硬话或沉默上；不写“这一刻她终于明白”“未来还很长”。

### 6.2 对话对照

| 不要这样写 | 应该这样写 |

| 她眼底闪过一丝复杂的情绪，指尖微微泛白。 | 她把价签翻过去，又翻回来。“这个成色，我按这个价收。” |
| 埃莉诺终于明白，爱情与阶级无关。 | 埃莉诺：你的灯还是坏的。……不过今天，我想在坏灯底下多坐一会儿。 |
| 莉迪亚露出意味深长的笑，仿佛一切尽在掌握。 | 莉迪亚：你就说——今天的发夹真好看。没戴发夹就夸别的！ |
| 她轻声道，语气里带着一丝不易察觉的脆弱。 | 埃莉诺：让我站一会儿。 |
| 莉迪亚强忍酸楚，微笑着祝福他们，只要他幸福就好。 | 莉迪亚：替她高兴，也替你高兴。就是……她没提到我，我又气自己怎么连这个都要在意。 |
| 作为职业经纪人，她迅速安排好了一切。 | 莉迪亚：我订了个位置，三个人的。……不然你们俩大眼瞪小眼，谁找话说？ |
| 这一刻隔阂终于消融，未来还很长。 | 埃莉诺：坐下。今天不用替我们腾地方。 |
| 埃莉诺红着脸，声若蚊蚋：“谢谢你为我做的一切。” | 埃莉诺：这笔我记着，别指望我道谢。 |

示例只用于说明写法，不是新台本。

### 6.3 场景检查

1. 她这场具体想要什么？食物、价钱、答案、安静、某个人的时间？
