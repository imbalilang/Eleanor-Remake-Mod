# 像素画风标准的定义原则

标准不是固定数值，也不是单张图。

标准 = 可低成本复刻、并能稳定产出可接受像素感的完整配方。

配方必须包含：模型 ID、channel、完整提示词、参数、参考图、后处理、至少 3 张成功样例与哈希。

成为标准的最低条件：同一配方独立跑 5 次，至少 3 次人工判定画风可接受，且不需要逐张改提示词或修图。

数值指标只作诊断和预警，不能单独否定一个人工接受的画风。

标准可以替换：新配方画风被接受、复刻率更高、成本更低或相当，即可成为新标准。同一时间只保留一个主标准，并版本化。

Seedream 降级为构图、舞台调度、姿势和镜头探索工具，不再作为最终像素 CG 画风模型。
