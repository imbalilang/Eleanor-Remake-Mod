## 根因与修改

实际运行日志及安装包为0.70。核对本机原生游戏程序集，`ModHelper.AddNetworkUpgrade`的最后一个布尔参数名为`recommended`，只写入推荐标志，不写`hidden`。0.70将其改成true并不能默认隐藏定义。

此外，新版`WildNetworkUI.Open`会依次调用`InvalidateDefinitions`、`AddMissingAfterLoad`、`BuildTabs`。`BuildTabs`从重新生成的定义缓存筛选卡片；此前`RefreshStates`只修改运行时对象及旧缓存，来源模板仍可见。等到`IsReady`刷新时，布局、名称和价格已经进入界面。只测试运行时hidden字段无法发现此问题。

修复使用原生`NetworkUpgrade.RegisterModUpgrade`注册明确的`hidden=true`、`state=0`源定义；在新版`BuildTabs`筛选之前刷新剧情状态，旧版`OpenUI`入口同步刷新。四个项目沿用既定剧情门槛和原生布局、购买与报价，不增加日历门槛、存档重置或额外付款。
