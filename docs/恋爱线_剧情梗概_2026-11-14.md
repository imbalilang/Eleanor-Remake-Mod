# 恋爱线 · 剧情梗概（2026-11-14 修订稿）

状态：2026-11-14 · 按“确认关系后的温馨日常 + 索菲娅认可”方向重写。用于确认路线方向，不是最终脚本。

本稿取消固定章号、委托阶梯和认可数值。只保留三幕日常与一个婚礼收束；每幕只给主笔 1–2 句目标，场景数、章节数、日期和断点由主笔决定。

## 1. 路线定位

- 埃莉诺单女主**恋爱线**，对应 **E1** 与 **E5**；不是后宫线、侍从线、革命军线。
- 入口：C19 接受告白进入；C19 做朋友走 E2/E6，不进入本线。
- 进入时关系已经确认；不写追求、不再写“她会不会喜欢你”，不写三角恋、情敌、分手或移情。
- 三幕：索菲娅之问 → 下层区的挑战 → 一家人；第三幕结束后直接接婚礼和 E1/E5 结局页。
- **婚礼不单独占一幕，也不等待**。没有天数、委托、认可、营养果或声望门槛。
- 营养果、水培、种子只作可选生活/经营风味，不进入主线目标，不卡婚礼。
- 不新增角色、路线、结局编号、地图、UI；无露骨内容；索菲娅不是可攻略对象。

## 2. 入口与共同线衔接

- C19 接受告白 → 本线；C19 朋友 → E2/E6。
- C19 之前的共同线事实保留：母亲安全/已探视；研究归还或研究保留；埃莉诺仍有工作和独立判断；莉迪亚是朋友。
- 线上 c20–c23+ep 不再作为本线主路径；它们的旧内容留给朋友线、旧双恋、旧档和回退使用，不在本线重写。
- C19 之后，本线只写“已经在一起”的日常；不再重复告白、确认关系或旧路线选择。

## 3. 主线：索菲娅的认可

母亲认可作为主线，但**不是任务条、认可数值或委托链**。它只有两个真正的转折点：

1. **第一幕：索菲娅之问** —— 她开始观察男主。
2. **第二幕：下层区的事件** —— 她看到男主实用主义背后的善良，认可他。

第三幕不再考验男主；写家庭、恋爱升温、求婚和婚礼准备。

索菲娅的担心要说人话，不把“吊桥效应”当心理学术语说出口：她怕女儿是因为落难时只有男主伸手，才把感激当成喜欢。她不正面反对，只用具体事情看人。

## 4. 三幕与婚礼收束

### 第一幕：索菲娅之问

**主笔提示**：
> 索菲娅搬来下层与埃莉诺同住；她为女儿重新站起来而高兴，但发现女儿已经和男主在一起。她担心这是落难时的依赖，保持距离、观察男主，并以“帮忙研究营养果”为由指导他水培。她看到下层区有人醉生梦死，也看到男主务实的生存策略；她半开玩笑地问：“埃莉诺和花不完的钱，哪个更重要？”埃莉诺不知道母亲在考验男主，沉浸在恋爱里，傲娇越来越藏不住“娇”的一面。

要点：
- 索菲娅不立刻认可，也不刻意刁难；她的问题是观察，不是考试。
- 营养果/水培是可选的生活细节和观察窗口，不要求产量、设备、种子或委托。
- 玩家怎么回答“埃莉诺还是钱”不会立刻改变认可；索菲娅看的是之后的事。
- 埃莉诺不知道这是考验；她因恋爱而喜悦，会护着玩家，也会嘴硬。
- 索菲娅对下层区的“醉生梦死”可以有偏见，但不要让埃莉诺被消音；埃莉诺可以纠正她。

### 第二幕：下层区的挑战

**主笔提示**：
> 写下层区的辛苦和埃莉诺带来的甜。一次具体的邻里配给/供水事件，让索菲娅看到男主在实用主义背后的善良：他用自己的货、钱或时间去补，不做慈善表演；埃莉诺想帮，他不替她决定。事件后索菲娅认可男主，开始穿现有居家私服来店。

建议事件（暂定）：
- 街坊的配给点/供水出问题；男主用店里现有的货、钱或时间补上，不图回报，也不摆救世主姿态。
- 埃莉诺想帮；玩家支持她自己的做法，不替她决定。
- 索菲娅看到：他不是圣人，但不会在该担的时候省掉该担的事。
- 不新增有名角色、物品、UI 或系统；人数和具体细节可由主笔排。

要点：
- 这是**一次事件**，不是连续任务；没有奖励、认可条或后续 KPI。
- 认可后索菲娅开始穿现有居家私服来见玩家；这是关系变化的具体标志，不新增服装/贴图。
- 埃莉诺的存在增加甜；她可以参与事件，也可以事后吃醋/嘴硬。

### 第三幕：一家人

**主笔提示**：
> 写感情升温、打情骂俏、吃醋、索菲娅加入后的家庭日常；用具体小事，不写主线危机。玩家求婚，开始婚礼筹备。第三幕结束后直接接婚礼和 E1/E5 结局页。

要点：
- 不写新的反派、绑架、革命、政治或主线危机；冲突只作生活小摩擦。
- 索菲娅已经是家人，不再考验；可以和埃莉诺一起拆台、开玩笑、留饭。
- 埃莉诺会有带有性暗示或者情趣向的挑逗、撒娇等热恋情侣的行为
- 求婚和婚礼准备由玩家/主笔安排；不设等待、委托、认可或营养果门槛。
