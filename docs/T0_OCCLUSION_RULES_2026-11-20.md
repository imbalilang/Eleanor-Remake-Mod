# 遮挡关系与 T0 判定

原则：不要求每张图四肢完全可见。允许合理遮挡，不允许解剖链断裂。

## 先看根部，不先数末端

每个角色应有：2 个肩根、2 个胯根。
手臂链：肩 → 上臂 → 肘 → 前臂 → 腕 → 手。
腿链：胯 → 大腿 → 膝 → 小腿 → 踝 → 脚/鞋。

## 合理遮挡

- 被前景物体、头发、另一条腿、床品遮住一部分。
- 遮挡边界两侧的肢体在位置、角度、粗细和长度上能对上。
- 有正确的前后层级：前面的物体边缘压住后面的肢体。
- 被遮挡的腿仍能从胯根进入遮挡区，并在另一侧露出膝、踝或脚。

## T0 不合格

- 少一个胯根或肩根。
- 手直接接在肩或肘上，前臂缺失且没有遮挡解释。
- 两段肢体断开，无法连成一条链。
- 肢体长度明显不可能，或同侧出现第三条腿。
- 遮挡边界处肢体突然变细、消失或换方向。
- 只看到一条腿的胯根，却出现两个脚。

## 不确定时

1. 裁切放大。
2. 标出肩、肘、腕、胯、膝、踝。
3. 如果仍无法判断，标记 OCCLUSION_UNCERTAIN，不直接判通过。
4. 高风险镜头宁可重画，不把不确定当合格。

## 判定标签

- PASS_OCCLUSION：遮挡合理，解剖链成立。
- T0：解剖链断裂、根部缺失、肢体数量错误。
- OCCLUSION_UNCERTAIN：信息不足，需要换角度或重画。

## 2026-11-21 修正：鞋子数量不等于腿数量

用户复核 v2_models 后发现：

- image-82807fd6.png（Grok）：Lydia 有 3 条腿。
- image-4ab29f91.png（混元第一套）：Lydia 有 4 条腿。
- image-117fe40b.png（混元第二套）：Lydia 有 3 条腿。

初检漏检的原因：当时数了可见的鞋和脚，没有从骨盆开始逐条追踪 Lydia 的腿；多出来但没有对应鞋的腿被当成了遮挡或背景。

## 新规则

1. 每个角色单独检查，不先数全图总数。
2. 从骨盆开始追踪每条腿：髋、大腿、膝、小腿、踝、脚。
3. 只数鞋不算数；腿可以暂时被遮挡，但必须能判断它属于谁。
4. 记录为 E_legs=2/2、L_legs=3/2 这样的形式。
5. 任一角色不是恰好 2 条腿、2 只脚，立即 T0。
6. 手臂同理：从肩、上臂、肘、前臂、腕、手逐段追踪。
7. 双人图至少分别裁出 Eleanor 和 Lydia 的下半身，100% 检查后再判断。
8. 第一次 T0 自动重画；第二次仍 T0 停止并报告。
