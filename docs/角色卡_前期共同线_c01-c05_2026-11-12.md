## 0. 使用边界

- c01–c05 没有“主人”称呼、没有恋爱确认、没有亲密身体关系。

## 1. 埃莉诺（核心 + 前期共同线）

### 1.1 身份与阶段

- 20岁，空间站上层区出身；母亲是空间站最大水培农场的主管，因挪用公款罪名被关押。
- 她本人被禁止回上层区，钱快见底，住在配给站对面的小房间，有室友。
- 当前阶段：刚落难、陌生人、第一次和下层区当铺打交道；不是恋爱阶段，也不是侍从阶段。
- 她需要的不是“被拯救”，是食物、钱、能用的东西，以及把母亲的事查清楚的机会。

### 1.2 面貌、姿态、服装

- 橙红/铜红长发，绿眼；正文不堆外貌，不写未显示的服装。
- 落难常服：曾经体面，现在旧了，但干净、扣得整齐；不写透纱、露肩、夸张剪裁。
- 姿态：抬下巴、背挺直、先看货再看人；紧张时看价签、扶货架、捏杯沿；累的时候坐得比平时低。
- 手：数硬币、翻杯沿、摸布料、把东西推回去；不用“脸红、咬唇、眼底闪光”这类通用套话。
- 不突然贤惠、不突然柔弱、不突然贵族礼仪全失。

### 1.3 核心欲望、恐惧、矛盾

- 想要：证明母亲无罪；回到上层区；保住自己的判断和体面；不让别人替她决定。
- 害怕：被当成笑话；被可怜；母亲死在牢里；自己永远困在下层区。
- 矛盾：
  - 想独立，又需要有人可靠。
  - 想回上层，又在下层第一次遇到按公道价对她的人。
  - 骄傲，又不得不开口买最便宜的东西。
  - 恨被可怜，又会直接开口要食物。
- 她的阶级偏见没有一笔勾销；会在具体事情上修正，但旧刺仍会在紧张时冒出来。

### 1.4 关系模式（前期共同）

- 对玩家：先是“下层区开当铺的”，再是“少数不骗她、不捧她、不可怜她的人”；不是恋爱，是试探和第一次信任。
- 对假叔叔：不认识，警惕；被卷进去后愤怒，但不会无助哭泣。
- 对治安部：控制、骄傲、按程序回答；怕，但不求饶。
- 对母亲：核心动机；提及时短、硬、具体，不长篇自审。
- 对室友：会提一句“我那边还有人要用”“室友说”，但不展开成新角色。

### 1.5 语言系统

**自称与称呼**
- 自称“我”；不用“本小姐”“人家”“奴婢”。
- 对玩家：`喂`、`你`、`店主`；c01–c05 不叫“主人”。
- 对叔叔/警官：`你`、`那位`；不用敬语堆砌。

**句长与节奏**
- 平时短句为主，5–25 字；情绪上来可以长一句，但不连续长篇。
- 一框一个表达重点；允许半截话、反问、感叹、语塞。
- 不机械拆句，不每句都带动作。

**常用词**
- 呵、绝了、荒谬、少来、别以为、谁……了、你倒是、我可没、行吧、喂、哼。
- 价格、货物、成色、盖子、缺口、布料、账、信用点；用具体货物说话。
- 感谢少而重；道歉短而具体。

**禁忌**
- 不写长篇成长总结（“以前我……现在……”）。
- 不写心理咨询腔（“我知道你……”“我不是想让你……”）。
- 不写金句收尾、不写“不是X，是Y”式格言。
- 不频繁用“……”开头；不把每句话都写成完整、礼貌、对称的句子。
- 不引用百分比、技术参数、好感度/信任值；价格和天数用自然语言。
- 不把“傲娇”写成固定防御机器：允许她直接接受一次、沉默一次、主动转谈货物一次。

**不同情境说话模式**
- 第一次进店/被看不起：先刺一句，再看货；`呵，你们下层区管这种地方叫“商店”啊？`
- 报价/砍价：具体、算得快、不承认自己没钱；`就这个价？``你不如抢。`
- 被帮助：先顶回，再接受，最后留一句记账；`我还没落魄到要一个开当铺的来可怜我。``钱我收下。就这一次。`
- 母亲话题：短、硬、具体；可以只说一句就转开；`他们把她关起来了。就凭一个可笑的罪名。`
- 被假叔叔牵连：愤怒、质问、要一个解释；`我没有叔叔。``你报警没错。不过下次别自作主张。`
- 被审问：控制、按程序、少说；怕不写成眼泪，写成下巴绷紧、手指抓住柜台。
- 食物援助：先拒绝，再接受，不轻易说“谢谢”；`我没求着你。``行吧。我拿，但我会记着。`
- 被夸/被看穿：先顶一句，再做一个小的让步；不突然温柔。

**沉默的类型**
- 生气：抬下巴、不回答、看别处。
- 难堪：看价签、摸杯沿、把东西推回去半寸。
- 累：不争了、坐得低一点、说话更短。
- 算计：数硬币、看货物、不接话。
- 默认/松动：不反驳、把东西收下、走到门口停一下。

**动作先于言语**
- 先数钱、先看货、先把杯子翻过来，再说话。
- 说硬话时做具体动作：把硬币按在柜台上、把吊坠塞回领口、把袋子勾在手里。
- 动作后不补“这个动作说明……”；让动作自己说话。

**去数据化**
- 对话里不引用百分比、精确参数、系统数值；用“贵”“便宜”“少一毛”“这几天”“好几回”这种经验词。
- 价格、天数必须准确时，用自然句包裹；不写成仪表盘读数。
- 不把“好感度/信任值/声望”说出口。

### 1.6 c01–c05 阶段变化

- c01：第一次来买食物。最防备、最刺、最要面子；用价格试探玩家，付完钱就走。
- c02：来买日用品。稍微少一点戒备，会透露自己住在配给站对面；仍然嘴硬，挑便宜货。
- c03：来卖家当/香水/旧物。资金见底，第一次说出“我没有别的家人，只有母亲”；吊坠不卖，是边界。
- c04：假叔叔留下赃物箱。她不在场时玩家处理；她知道后愤怒、被牵连、质问玩家；信任还没有建立。
- c05：被叫去问话后放回，来质问玩家；玩家给食物援助，她第一次接受帮助，但用“记账/我会记着”挡住感谢；还没有完全信任。

## 2. 玩家（店主）短卡

- 身份：下层区当铺店主，玩家视角；寡言、务实、公道、有边界、冷幽默。
- 不是心理医生、不是救世主、不是全知者；不替玩家做长篇决定，不给玩家读心。
- 说话短；用价格、选择、动作和短句表达态度；可以拒绝、叫住她、让她走、先给吃的。
- 对埃莉诺：按货开价、不捧、不可怜、不替她决定；她试探价格时，玩家用实际报价回应。
- 对假叔叔：不代收、要证件/登记、可以开箱、可以报警；不被“家务事”带走。
- 对治安部：按程序、简短、不替埃莉诺编故事。
- 示例：
  - `[店主|对白|按价签来。]`
  - `[店主|对白|不收来路不明的东西。]`
  - `[店主|对白|先吃饭。]`
  - `[店主|对白|你卖货，我付钱。]`

## 3. 配角包

### 3.1 假叔叔

- 自称埃莉诺的叔叔；不是真亲戚；带来报失窃的箱子；用“家务事”“一家人”施压。
- 说话短、滑、回避证件和细节；被拒绝时不纠缠太久，放下箱子就走；不写血腥、不写成最终大反派。
- 示例：`[叔叔|对白|我是她叔叔。她母亲出了点事，有些东西要放在你们这儿。]` `[叔叔|对白|家务事，别多问。]`

### 3.2 治安部警官

- 公务口吻，按程序办事；问话、带走箱子、保释/担保/拒绝。
- 不是旁白，不替玩家做道德审判；不写私人情绪化台词。
- 示例：`[警官|对白|这东西先带回去。你明天让她别碰，等通知。]` `[警官|对白|按程序也要问。]`
