## 1. 总结论

**v0.4 整体优于 v0.3，AI 感更低、更贴近原作；五处衔接修掉后，可以作为 v0.3 的替代底稿。** 当前为玩家 6 行、埃莉诺 187 行、主线可见字符 3,543；玩家密度 3.11%。R05 的具体货物、R07 的米拉细节、R09 的名字划痕、R12/R13 的鞋绳回调、R14 的具体动作都更有原作质感。

## 4. 已并入 v0.4 的五处

### 4.1 R06：不要假定“后厨拿面包”

审核时 v0.4：
```
**埃莉诺：** 你这儿有没有吃的。给我留一点，别问我要不要紧。
（玩家去后厨拿了面包。）
```
商店对话没有“去后厨”的玩家行动入口。建议回到 v0.3 的一句玩家台词：
```
**玩家：** 有面包。
```
或改成已有库存/柜台动作，不新增场景动作。面包仍按私人招待、不计补给。

**并入结果：** v0.4 现为 `**玩家：** 有面包。`，后厨动作已删除。

### 4.2 R14：杯子是选项1专属

v0.4 当前共同动作：
```
（她把杯子放下。门外有推车经过，没有人进来。）
```
但选项2是挪椅子、选项3是合账本，没有杯子。建议改成：
```
【若选项1：她接过水】**埃莉诺：** 我把杯子放这儿。
```
或把共同动作改为“她把手里的东西放下”，不特指杯子。

**并入结果：** v0.4 现为 `【若选项1：她接过水】她把杯子放下。`，选项2/3不再出现杯子。

### 4.3 R11：恢复“没货也来”的节拍

v0.4 结束在：
```
**埃莉诺：** 我走了。下次来，杯子再不换，我就自己动手。
```
这句好笑，但把“没有货也愿意来”的确认换成了对杯子的挑剔。规划确认保留该节拍。建议保留杯子句，同时补一句短的：
```
**埃莉诺：** 下次来，杯子再不换，我就自己动手。
**埃莉诺：** 没货也来。
```
或合并成“下次没货也来。杯子再不换，我就自己动手。”不要把“我想见你”提前说破。

**并入结果：** v0.4 现为“我走了。下次来，杯子再不换，我就自己动手。/ 没货也来。”

### 4.4 R08：“我这儿没有情面价”语感不对

她是卖方，玩家是买方；“我这儿”像店主口吻。建议：
```
**埃莉诺：** 别给我情面价。该多少是多少，别因为我用过就多给。
```
或“按货算。别因为我用过就多给。”

**并入结果：** v0.4 现为“别给我情面价。该多少是多少，别因为我用过就多给。”

### 4.5 短访十三：不要凭空说玩家动了

v0.4：
```
**埃莉诺：** 你刚才动了，别以为我没看见。
```
台本没有玩家移动物品的动作。要么加一个真实动作提示，要么改成自足拌嘴：
```
**埃莉诺：** 别动。我刚摆好。
```
不要新增玩家动作系统。

**并入结果：** v0.4 现为“别动。我刚摆好。”

## 5. 自审三问

### 1. 剧情逻辑

**PASS（修掉上述五处后）。** R06 首杀、R07 采购责任、R09 米拉死亡、R10 带队选择、R12 护送身份、R13 归来兑现都能接上；R01 研究公开、R02 旧物交易、R04 参军和 R05 战利品也保留了必要事实。当前 FAIL 点只在 R06 的后厨动作和 R14 的杯子共同动作，都是执行衔接，不是主线因果。

### 2. 更像原作

**PASS。** 玩家从 10 行降到 5 行，埃莉诺主动说事，货物、伤口、鞋绳、名字划痕等具体物件承担情绪；删掉了“以前/现在”成长金句和大量安慰-顶回。R01/R02/R04/R05/R06/R07/R09/R13 的玩家零台词也成立，因为交易、选项和行动在承担参与。

### 3. AI 感

**PASS。** v0.4 的短句、半截话、具体动作明显多于 v0.3；没有连续对称问答，没有 NPC 替玩家总结。保留的制作备注和括号动作不是游戏内旁白，接入时不得直接写进 NPC 气泡。R04 的“队里肯继续把研究的事往外捅”略长，但仍是具体事实，不是主题句。

## 6. 结论与采用建议

- **采用 v0.4 作为新底稿，不建议保留 v0.3 全文。**
- 五处衔接已并入 v0.4：R06 面包、R14 杯子、R11 没货也来、R08 情面价、短访十三。
- v0.4 在 AI 感、原作贴近度和体量上都优于 v0.3；主线逻辑可进入下一阶段。
- 不把 v0.4 直接写入 Content；英文、G1—G3、物品映射、调度、肖像回退、E9 页面仍未做。
