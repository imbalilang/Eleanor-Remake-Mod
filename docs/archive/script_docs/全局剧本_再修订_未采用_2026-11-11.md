# 全局剧本（去AI味逐章修订版）
日期：2026-11-11（基于《文风、玩家台词与非台词表现基准 v3.1》与《原作 Eleanor 章节对照稿》全量重构）
本文件保持原版全部 503 个正文 block ID、scene/label 元数据、选项结构与 `BuildSkipFirst` 首行保护不变，可直接用于对比与导入 `Content/*.json`。
核心修订重点：
1. **彻底清除“幽灵接话”（C类无依据隐含回应）**：修复此前删减玩家台词后遗留的“自问自答/对空气反驳”（如 `c01` 莫名其妙认不出价签、`c03`“那你接着算”、`c07`“你又没收学费”、`c08` 把自己攒侦探费说成“你还差调查的钱”、`c12`“一次都没有”、`rv11`“那你还让我进来”等）。
2. **破除“当铺算账”口癖与“不是X是Y”对仗金句**：删改全篇泛滥的“名字是名字，价钱是价钱”“毛病算在东西上，不算在人头上”“这笔账我记着”“不是X，而是Y”等AI高频排比与伪深刻收尾，回归原作直白、鲜活的口语。
3. **去除“心理咨询式”自我剖析与过度找补**：删去角色每次行动后解释自己动机的防御性赘述，以及句首滥用的省略号（`……`），让情绪自然落在具体物件与行动上。
