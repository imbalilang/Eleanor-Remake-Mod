# 后宫线 v0.5：声望检查点、三件橱窗饰品与现有问题修复

日期：2026-11-09。状态：已完成本地实现与离线验收，待完整实机及平衡验收。实施基线：manifest 0.81；发行号保持0.81，本轮未部署、上传或推送。实施与验证记录见《后宫线_v0.5_实施与验证_2026-11-09.md》。

配套参数：`后宫线_v0.5_声望检查点与问题修复_执行参数.json`。JSON用于实施时对照，不由当前游戏读取。

## 1. 本次确定的规则及替代范围

核心经营目标是建立上层区声望。玩家通过原有经营积累声望，分别达到50、100、150，取得三件可放入橱窗的饰品，并推动后宫主线进入下一阶段。

声望不足：停住对应主线节点，正常营业、普通顾客及阶段适用的角色日常继续刷新。达标后自动恢复排队，不让玩家重新报名，不判定失败，不退回普通恋爱，不增加“再想想”的选择。

这里的经营等待与被删除的感情暂缓不同：前者有可见、可达的具体目标；后者只会让玩家不清楚关系是否成立。按用户最新决定，明确保留前者，删除后者。

本方案取代以下旧构想：

- 两笔特定业务作为口碑升级任务、供应商补货、拒绝后补约、未成交后补做。
- 额外接待筹备费、住房或同居建设、收货转卖任务链。
- 关系确认自动将引荐率由50%提高到75%。
- 某个固定剧情日声望不足就判出后宫线。
- 普通恋爱旧档自动进入后宫、回补全套后宫前段。

不新增王尔德付费项目，不扣声望，不提供金钱代替声望的捷径。埃莉诺上层工作、母亲和研究事实、莉迪亚新性格与“僚机也动心”的主体保留。继续沿用现有画像；三件物品通过现有纹理资源实现，不增加新绘图任务。

## 2. 三个检查点与剧情落点

入口为明确选择后宫扩展，说明后续需要上层声望50/100/150、未达标可正常经营等待、途中不再有含糊暂缓选项。角色可以仍以撮合埃莉诺为动机；玩家可见的选项说明必须明确这是后宫方向，不能写“仅撮合”却强制进入后宫。

| 检查点 | 激活前置 | 挂起位置 | 达标场景及显性奖励 | 之后推进 |
|---|---|---|---|---|
| G1，上层声望50 | 母亲安全、甲/乙世界结果、非侍从，原母亲来访已完成；玩家接受扩展 | entry完成后，dr02之前 | 莉迪亚开始正式推荐店铺，交付荐店铭牌 | dr03真实售货后的停留、私人咨询、埃莉诺告白、三人约饭、工作 |
| G2，上层声望100 | dr08工作与原节点奖励处理完成，埃莉诺恋爱已明确 | dr09之前 | 在dr09开头交付珐琅座饰，说明更有购买力的上层来客；随后转到莉迪亚自己的生活 | dr09～dr11的个人来访、发夹呼应、原核心收束与察觉 |
| G3，上层声望150 | dr11完成，原合作和核心事实都已真实提交 | dr13之前 | dr13开头交付银饰，表达她在熟人圈认真推荐玩家；随后接她想退开的情绪 | dr14坦白、dr15～17三方表态、分别约会、共同晚饭 |

G3放在坦白之前。不能已经问出“你们是否愿意在一起”，然后暂停数天让玩家冲声望。G3通过后，三方讨论连续按原安全日槽推进，不再夹经营门槛。

entry与dr02拆成可恢复的两个逻辑节点；当日条件和队列允许时可以在同次来访接完。若entry完成时不足50，来访明确结束，不能把顾客留在柜台等声望。之后达标再排dr02领奖。

### 检查语义

1. 三个阶段分别检查当前原生上层区声望。已有`StoryEngine.UlRep()`可以读取；实现前实查原生声望标度和150可达性。禁止另造一条“上层亲密度”。
2. 只有前置剧情完成、该检查点已经激活后才监听达标。不以游戏早期一次150峰值替代尚未开启的全部阶段。
3. 达标锁存一次，不扣除声望。排队到领奖期间声望下降，不撤销已经通过的阶段；已获得关系和奖励不因后续正常波动回退。
4. 入线时已150者仍按剧情顺序领奖，三个阶段不在一次对话中倾倒，不跳章。每个阶段激活时再检查；当时仍满足即可立即通过。
5. 达标、奖励领取、饰品是否陈列是三个不同事实。达标放行；奖励交付失败留下待领；放入橱窗才产生增益。没有空位不得倒扣声望、重复判关或卡住感情。
6. 原生日程是最早日期，不是失败期限。保留提前开局整体减11天；各阶段实际日期取原目标日与前置完成后安全间隔中的较晚值。
7. 不再保证所有新档第67或75天必定完成。门槛等待可能顺延，和侍从筹资一致；原版游戏结束时按已发生阶段写尾声，不伪造完成，也不新增强制延期能力。

## 3. 三件饰品：规则明确，作用独立

| 声望 | 物品与建议ID | 放入有效橱窗后的作用 | 首轮实施参数 |
|---:|---|---|---|
| 50 | 莉迪亚的荐店铭牌；沿用`eleanor_romance.recommendation_plaque` | 增加上层普通买家 | 每个可用营业日50%机会排1名，最短到访间隔D+2，最多1名已承诺待来访 |
| 100 | 上层宾客珐琅座饰；`eleanor_romance.upper_patron_ornament` | 上层普通买家的购买预算增加 | 原生修正完成后的基础预算×1.30，向下取整，仅应用一次 |
| 150 | 名媛致意银饰；`eleanor_romance.upper_gratitude_ornament` | 上层普通买家真实购买后额外给小费 | 本次来访已支付商品价累计的10%，每次来访最多150；与原有小费相加，不复利 |

50/100/150是本次确定的挑战阈值；50%、30%、10%及150小费上限是明确的首轮可调平衡参数，不是已经实机证明合理的最终数值。应先按此跑通，记录经营收益后只调效果强度，不未经确认改声望核心目标。

### 饰品通用条件

- 三件各1×1、独立物品ID、唯一领取，全部陈列共占3格橱窗。按类别判定有/无，同一种物品即使异常复制也只生效一次。
- 玩家所有、真正位于有效橱窗、对应奖励已解锁，三个条件同时满足。仓库、背包、柜台或其他容器内不生效；不能仅凭剧情flag永久加成。
- 预算饰品和小费饰品对符合范围的原生上层买家也生效，不要求同时摆出荐店铭牌。三件全摆时可以组合，但不要求收集齐才启用。
- 不标为可售奢侈品，不参与“橱窗有合适商品”的库存判断；沿用重要物品保护。取下不损失资格或关系。
- 物品说明分别列数值、适用客群、取下后的生效时机和不叠加规则；不要把三种效果统写为“客人更喜欢你”。

### 适用客群

适用于原生随机上层普通/精品买家，以及本路线新增的通用引荐买家，均须是向玩家购买商品的真实交易。

排除埃莉诺、莉迪亚、母亲等具名剧情角色、原固定预算的合作采购、侍从商单、剧情交付、罚款/赎金、卖货给玩家的顾客、免费赠礼和服务费用。其他MOD客户默认不改写；无法确认是普通营业客户时不套效果。不能只按“头像像贵族”判断，也不能给所有Upper阵营剧情NPC加钱。

### 客流效果

在既有客户生成流程的可用空档添加一名上层买家，不删除原生顾客、不改全局派系概率，不抢紧急剧情。同一日抽取结果持久化，不因重摆、重开店或读同一存档反复抽。

依旧要求橱窗存在真正可售、符合买家偏好的商品，排除剧情物品、三件饰品和无效库存。统一`willAcceptItem`与原生购买标签，删除用所有HOUSEHOLD_GOOD冒充精品的宽泛判断。

取下铭牌停止新引荐；已经实际排入队列的买家照常履约，不能把移除道具当作取消已经生成的客人。日常、原合作买家、引荐客沿用当前每日限额，本方案不引入“双恋每天额外多个剧情槽”。主线等待时有更多经营空档，正是此奖励帮助下一阶段积累声望的时机。

### 预算效果

先实查当前游戏的预算初始化、原生修正和展示顺序，再在普通上层买家实际到店、第一次打开交易前取得最终基础预算B，应用`floor(B×1.30)`。例如B=500变650，B=1000变1300。只增加预算，不改商品估价、议价规则，不保证每位买家都愿意买贵。

到店时对三件展示物作一次快照，并为本来访保存稳定ID、基础预算、加成额、已应用标志和剩余预算。中途拿下/重放、保存重读、循环打开交易均不得再次加成，也不得重置已经花掉的预算。下一位顾客再读取新的陈列状态。

原固定任务预算不加成，避免破坏收货数量、订单剩余额和剧情反馈。原生特殊买家有硬限制时按其限制收敛，并在适用清单列明，不盲目覆盖。

### 小费效果

采用“额外小费”，不依赖原生该次交易本来是否随机给小费，因此玩家能感知第三件奖励。若原生已有统一小费结算，可挂入该结算并标清额外部分；没有稳定入口则使用真实成交后的独立加款与原通知，不伪称修改了原生小费率。

设本次来访合格商品付款累计为S，则应得额外小费`T=min(150,floor(S×0.10))`。每笔真实成交只付`T－本来访已付小费`，这样拆单、批发和回调次数不会改变总额。S不包含原生小费、额外小费、零价礼物和未成交报价。例：累计卖出500付50，之后又卖出600再付60；累计2000时全程只付150。

每笔成交后用既有现金提示显示“上层买家额外小费 +N”。不得通过虚构提高成交价实现，不用额外小费给原生声望计算再加一遍权重。小费不扣买家剩余购买预算，避免刚加的预算被奖励自己吃掉。

真实成交ID、来访S与已付T必须和游戏保存一致。优先复用可靠原生交易ID；若没有，使用可持久化的来访序号与一次业务结算序号，不能只拿物品ID或每次回调重新生成的GUID去重。钱和记录的更新需要防重入、溢出和中断恢复；不能设置标志后加款失败却永远不给，也不能恢复旧回调再次付。

## 4. 日常与门槛等待

目前DualDirector仅在最终结局后才排七组日常，不能直接说等待期已有完整日常。本轮必须补齐阶段日常路由，复用现有对白和画像，不开新面板。

| 等待位置 | 已成立的关系/事实 | 可播放的日常 | 不得提前说的内容 |
|---|---|---|---|
| G1未到50 | 接受撮合、母亲安全，埃莉诺尚未告白 | 正常旧货买卖、莉迪亚替朋友问近况、短胸针/生活闲谈 | 莉迪亚私下告白、三人已经交往、铭牌已经赠予 |
| G2未到100 | 埃莉诺恋爱已确认、工作按事实成立 | 埃莉诺普通恋人短日常，莉迪亚仍以闺蜜身份谈熟客/穿搭 | 三人恋爱、她已为玩家退让、未发生的核心礼物 |
| G3未到150 | 原核心完成，莉迪亚已渐渐动心但尚未坦白 | 埃莉诺恋人来访、莉迪亚个人爱好短聊，保持含蓄 | “昨天你答应了我”、同居、三人确认、约会装首秀 |

角色日常默认至少间隔4天，使用同一已有MOD访客槽；不每日增加一名女主，也不每次来访都催声望。所有阶段保留原生营业顾客刷新，不能把这个4天冷却误施加给原生客户。

实施交付至少包含每等待阶段两段不同的短日常（共六段），从现有适合的生活/交易段落改写。它们只更新日常日期和轮换索引，不能完成主线场景、增加任务成功次数或直接赠声望；已确认双恋的七组日常仍在结局后使用，不能整组提前搬入等待期。

调度优先级：原生紧急事件 > 必要共同世界结果 > 已达标的下一主线/领奖 > 已承诺经营来客 > 合适阶段日常与可选新引荐。保持同一日不重复插MOD事件。普通主线若已由双恋接管，不得因为声望不足就从旧章节绕过门槛。

等待判定返回“有主线但尚未达标”，不能返回“该路线结束”。它不得设置`LastQueuedDay`、`PendingScene`或完成flag；只在真正排入顾客后占位。主线与日常的完成时间分别保存，日常不能让主线的等待期从头计时，也不能无限推迟已经达标的领奖。

声望变化、开店/生成顾客、读档时检查激活中的门槛；读档不补造未发生的剧情。上层声望读取失败与真实为0要区分，未来schema或状态未准备好时停止该模块写入，不重置全模组。

## 5. 玩家可见反馈与剧情文字

不用新增进度面板。通过入口说明、每阶段开头一次系统提示、阶段日常结尾的短进度行和三件物品说明告知状态。玩家随时能在原生声望界面查看上层声望；数值变化不连续弹窗刷屏。

建议入口说明：

> 进入莉迪亚与埃莉诺的后宫剧情。上层区声望达到50／100／150时依次推进并获得三件橱窗饰品。未达标期间可继续经营和日常来访，不会失去路线；声望不会被消耗。

等待提示：

> 上层区声望：83／100。下一阶段奖励：上层宾客珐琅座饰。主线将在达标后继续，日常和正常营业不受影响。

达标提示：

> 上层区声望检查点100已达成。莉迪亚的后续来访已可安排；本阶段资格已保留。

领奖提示：

> 获得上层宾客珐琅座饰。放入橱窗后，上层普通买家购买预算增加30%。仅收进仓库不会生效。

对白保留人物自然动机，数值交给提示说明，不让莉迪亚开口说“你声望150，我才恋爱”。例如：

- 50：“她们总问我，这里的东西到底能不能买。我说我自己来过——牌子你摆着，让她们进来自己看。”
- 100：“前几天还有人问，来你这儿只带那点钱够不够。她原本只想挑一件，走的时候抱了半箱。”后接她自己的首饰/生活话题，不扩写成职业经纪人。
- 150：“现在有人提起这家店，都不用先说‘莉迪亚认识的那个老板’了。”随后回到她想退开、玩家留她的情感场景。

三件物品奖励的是玩家已经经营出来的口碑；熟人引荐、预算与小费在机制上有明示作用，不把饰品写成官方许可证或全家族担保。没有这类实际客人经历时，用概括性的口碑对白，不捏造具体成交。

## 9. 存档、奖励与客户事务

建议双恋自身schema从1升至2，不提高全局RomanceState.Schema。以下是职责而非强制字段拼写：

- 入口：未提供/明确接受/拒绝、接受证据、原流程接管边界。
- 场景：已完成集合、实际日期、当前稳定字符串ID、恢复游标、原节点完成事实。取消依赖`string.GetHashCode()`构造可持久化PendingScene编号。
- 检查点：每级active/passed/passedDay/notified/resultShown；不能拿物品是否在橱窗当检查点完成。
- 奖励：每物品earned/delivered/pendingClaim、存在扫描结果、首次确认遗失日期、待补领。领取与scene完成分开。
- 日常：阶段、循环位置、上次日常日期；主线用独立最近推进日期。
- 引荐：当日抽取、稳定待来访ID、预约是否已到店、上次实际到访日；排队失败不提前消耗到访冷却。
- 预算：来访ID、展示快照、基础预算、已应用修正、实际剩余额。
- 小费：交易去重、来访累计有效支付S、已付T、待提交/恢复记录；不用已出售物品上的永久tag冒充完整交易事务。
- 迁移：旧档来源、哪些门槛因既有剧情获续接豁免、原拾荒资格来源、退役业务的最终状态。

### 迁移矩阵

| 旧档形态 | 处理 |
|---|---|
| 普通恋人/朋友、无真实双恋接受行为 | 继续普通分支，不自动发后宫入口、饰品或补前段 |
| Entry=2仅由旧OnLoaded自动写入，entry场景未完成且无进一步实质行为 | 作为未接受，撤销自动接管标记，保留所有真实世界/关系事实；不能只看Entry=2认定玩家选了后宫 |
| 确实接受了后宫或已有后宫场景进度 | 接当前未完成节点。已发生节点不重播；未来检查点按新规则等待 |
| 已越过某检查点对应剧情 | 对该已发生剧情授续接豁免，不能倒回去卡住。但新饰品要到实际对应声望才获得，不伪造历史达标 |
| 已确认三人关系/已完成后宫 | 保持关系与结局；三件未获奖励按当前声望顺序交付，不追收、不开分手检查 |

| 原Romance=2暂缓 | 当前合法关系节点一次选择恋人/朋友，新流程不再提供暂缓；若已明确接受双恋，按这次明确选择接入或结束 |
| 已预约第二笔买家 | 该次按原约履约，结束后退役，不补约、不再用于升级；未实际预约的机会不新增 |
| 保存发生在场景/买家交易中 | 恢复实际已提交部分，不重发物品、预算或小费；没有存活顾客才释放失效占位 |

多件待领奖优先附在下一次合适的角色来访，在既有领取方式中处理；缺图/满仓不消耗资格。扫描所有已验证受支持存储和待交付位置，得到“未知”时停止补发。若用F9修复只算调试补救，不能充作玩家正常领取入口。
