# 项目现状与发展建议（2026-11-16）

## 一、当前基线

项目是《深空当铺：可能是偷的 / Probably Stolen》的 Eleanor 剧情扩展 MOD，当前仓库与稳定批次基线为 **1.12**，对应游戏 1.0.0.14。文本和界面提供简体中文、英文两种语言。Steam 创意工坊条目 3834588749 的可核验历史回执为 1.11；本轮 1.12 仅完成本地发布证据，未上传平台。历史 1.11 回执中的包数字不代表当前 1.12。当前没有查到 Nexus 线上上传回执；工作区保存的 Nexus 变体是 156 个文件、13,870,059 bytes，不能据此断言 Nexus 线上版本状态。

内容由共同线和四条正式路线组成：恋爱线、后宫线、侍从线、革命军线。现行结局是 E1 恋爱婚礼、E2 朋友、E3 侍从、E4 后宫、E9 革命军归来。E5–E8 是历史别名，E10–E14 为旧档保留编号，不能重排或复用。营养果研究只影响经营和背景台词，不另拆结局。当前路线图记录 20 个分幕；四条重制路线分别约 10、13、16、11 场，另有共同线。

代码、内容和资源已经形成可维护的生产链：`Content/*.json` 是剧情真源，生成本地化和 `*.g.cs` 不应直接手改；路线变化还需同步路线图维护文档和站点副本。当前工作区约有 68 个 C# 文件、17,000 余行生成前后代码。美术工作区有 132 张运行相关 PNG，包含 104 张表情、12 张角色立绘、8 张结局或事件 CG，以及 8 张物品/UI 图标。索菲娅的当前身份基线为 38 岁、外表约 28 岁，深青上层日常装和暖白针织私服已定稿；她不是可攻略对象，而是母亲、研究者和恋爱线的重要参与者。

已经完成的静态检查包括项目引用与中英键检查、路线图检查、侍从线和革命军线检查，以及 Release 编译（0 警告、0 错误）。对1.12 本地暂存包重新进行原生扫描也已通过：扫描 2,176 个方法，refused、error、capabilities、hard flags、findings、pending、deprecated 全为 0。离线回归已重放 50 场、114 条独立路径和 456 次选项/交易，但它不能替代对 1.12 停水事件和立绘模式的最新实机验收。

## 二、项目目标与硬约束

项目的核心价值是让玩家在当铺世界中，通过四种不同关系体验阶层反差、被主动选择或需要、共同经历和情绪回报。经营、声望、饰品、路线图和测试工具是支撑，不能代替角色体验。四条路线应保持不同的情绪结构：恋爱线强调已有关系后的日常、家庭和婚礼；后宫线强调 Lydia 从撮合者变成被认真看见的人，以及三方明确同意；侍从线强调身份上升与公开/私下反差；革命军线强调外部环境的残酷和只在玩家处放下防备。

必须遵守以下约束：

- 单次 POST 请求的序列化参数和请求体必须小于 20,000,000 bytes，目标控制在 16,000,000 bytes 以内；参考图先压缩、裁切和分批，保留原始母图及哈希。
- 新文档和界面只使用“恋爱线、后宫线、革命军线、侍从线、共同线”等正式称呼，不重新引入旧的甲乙丙丁或 A/B/C/D 路线。
- 发布文案保持现有事实，不新增未经确认的平台元数据。
- 当铺是售卖亭窗口：玩家在内、访客在外，卷帘是窗口而非入户门；亲密动作要符合隔窗站位，居家和场外事件另设地点。
- 保留旧档和历史编号；不要为合并路线而删除旧实现、压平经营背景或重排结局。
- 发布前必须生成可追溯的不可变包，并扫描实际安装目录；模组目录不能放改名为 `.bak` 的 DLL。

## 四、外部反馈现状

本轮尝试访问 Steam 条目 3834588749 的主页和评论接口均超时；Nexus 1345 及其帖子/问题页面返回 HTTP 403，公开读取和浏览器辅助通道也未成功。因此目前**没有取得可核验的最新评论原文、数量或玩家普遍意见**，不能声称“玩家普遍反映”某个问题。历史发布记录中的反馈（例如求食援助、囤水者饰品、合作采购立绘和旧侍从入口）可以作为已处理问题的来源，但它们不是本轮实时口碑数据。后续若能取得评论文字，应按“原文、版本、平台、是否已修复、能否复现”逐条登记，再决定优先级。

## 五、建议的发展顺序

**下一步：完成 1.12 实机验收。** 冻结当前版本内容，建立一份真实包清单和唯一哈希；重新生成最终验收记录，清理 stage 残留；用新包完成停水、关店跨日、读档、立绘模式和 CG/文字换行的实机矩阵。自动回归脚本已按当前 `VanillaEleanorBridge` API 修复，并把“夹具失败”和“剧情失败”分开报告。

**随后做：最小范围修复高反馈问题。** 处理 R01b 的元件持有条件，优先采用文本条件或回忆状态修正，不为单个道具引入复杂物品追踪。完成索菲娅和表情族的实机抽检后冻结批准资源，明确候选、退役和运行资源的目录边界。同步把 README、全局剧本、恋爱梗概和发布证据保持为当前 1.12 口径。

**中期做：提高选择和角色回报。** 依次挑选恋爱线和后宫线的高情绪节点，让玩家更常亲口表达立场、欲望、保护或暂缓；补 Lydia 的主动时刻，再处理侍从线的自愿留下和革命军线的归来回报。每次只改一个体验问题，复用现有路线、交易和美术机制，不先增加新路线、进度面板、声望门槛或饰品系统。英文优先审校结局、告白、争执和母亲来访等高可见段落。

**长期做：降低维护成本。** 在不破坏旧档的前提下，逐步把场景、状态和迁移逻辑拆出单体类；为内容源、运行包、外部反馈和美术来源建立版本登记。每次发布保留“源提交—构建包—扫描—实机结果—平台回执”的链条，避免同版本多个包互相覆盖证据。

本报告基于截至 2026-11-16 的工作区、1.12 本地稳定批次和可核验的本地 QA 记录；Steam/Nexus 的实时评论缺口需要在取得评论文本或可访问导出后补录。
