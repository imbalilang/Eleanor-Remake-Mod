# 0.75关系选项与退线焦虑核对

> 实施追记：2026-11-09已按本核对修复并随0.76发布，见 `RELATIONSHIP_CHOICE_FIX.md` 与 `RELEASE_0.76.md`。本文保留0.75的审查事实和当时建议；下列旧选项不代表修复后的当前流程。

日期：2026-11-09。核对对象为已发布0.75对应的运行代码、`Content/maid_v05.json`和实际UI文本。章节按侍从线阅读编号，主线代码编号另列。本次只分析，未修改剧情、运行逻辑或创意工坊版本。

## 结论

第20章确实在已经进入侍从线后，再提供“取消约定，改做普通恋人”和“做朋友”两条真实退出分支。第28章则存在明显的措辞误导：三个选项实际都继续侍从恋爱，却被“约定到此为止”“以后叫不叫自己决定”等句子包装得像又一次选线。

此外，旧伤和解、研究路线、背叛选择与普通态度选项的后果层级混杂。部分危险选项还丢失了本来已有的专用说明，使玩家难以从界面区分“回应方式”和“不可逆转的路线选择”。

没有发现第20章确认侍从恋爱之后，正常的第21～27章、筹备期日常或晚会再提供改为普通恋人的入口。不能把每次告白、约定和称呼谈话都算成实际转线。

## 1. 重点位置

| 阅读章节 / 主线代码 | 玩家看到的选项或对白 | 实际后果 | 评价 |
|---|---|---|---|
| 20 / 21：告白 | “我也喜欢你。约定作废吧，我们就做恋人。” | `Confess(2)`调用`MaidState.End`，结束侍从约定，保留普通恋爱，后续侍从归来项目关闭 | 最明确的重复选线；应优先处理 |
| 20 / 21：告白 | “你对我很重要，但我想我们还是做朋友。” | `Confess(4)`结束侍从约定，进入朋友状态，后续侍从归来项目关闭 | 同一菜单第二条退出；与前面长期投入不协调 |
| 28 / 来访28：终约 | 她先说“所以——约定到此为止”；选项三为“那个称呼，以后叫不叫，你自己决定” | 三个回答均推进至28，`Contract=3`，保留侍从恋爱；第三答的下一句仍是她主动叫“主人” | 安全的情感表达被写成疑似退出；容易诱发读档与查攻略 |
| 12 / 13：旧伤和解 | “今后该瞒你的时候，我仍会瞒着你。” | 仅明知箱子陷阱却未提醒、尚未和解和承诺的存档可见；结束侍从约定，当前转朋友状态，盘交她保管，救母调查继续 | 有真实人物冲突，但仍是入线后很快出现的退出点；拒绝句极端，缺少有意义的修复方式差异 |
| 19 / 20：旧伤兼容收尾 | 同一组坦诚/继续隐瞒选择 | 尚未和解的历史状态才出现；拒绝仍结束侍从约定 | 不应统计成正常新档又考一次：新档第12章答应坦诚后，第16章已兑现和解，通常不会再出现；主要用于旧档兜底 |
| 14 / 15：研究决策 | “他们拿你母亲的命来谈。这件事，我扛不住。” | 归还盘，结束调查与侍从约定，进入正常退出结果；并非暂停或回去筹备 | 选项表达的是能力不足，后果却是整条关系退出；容易把求稳的玩家导向弃线 |

第20章转线的说明已经明确写了“结束侍从约定、后续归来项目关闭、既付支持继续交付、不退款、不取消救母结果”。因此它是有意保留的转线设计。问题在于：第11章的入线条款已明确承诺开启侍从恋爱与上层区归来，第19章又刚建立私下称呼，第20章却把“是否继续这条路线”重新交给玩家确认。

此时已实付800入线费用，玩家还可能已经购买安顿。转线不会吞掉已付安顿的结果，但之后的侍从归来内容、尚未开启的项目和晚会都不再进入。当前流程没有提供转回侍从线的普通入口。

## 2. 与横跳相邻的危险决策

| 位置 | 决策 | 真实影响 | 当前提示问题 |
|---|---|---|---|
| 第13章黑市来访 | 交出盘收300 / 卖盘收600 | 明确背叛，终止当前关系并进入相应后果线 | 侍从版使用`Option(...)`，没有传入原本存在的专用说明，显示默认“不追加付款。按本次明确选择推进。” |
| 第14章研究路线 | 归还换人 / 先保护再处理 | 甲乙两条救母路径，都能继续侍从恋爱；乙若落实不了保护可回退甲 | 同样未复用原有路线说明，玩家更难知道两项都兼容当前关系 |
| 第14章研究路线 | 现在公开；二次确认“尊重她的决定，现在公开” | 进入母亲死亡、埃莉诺投身革命军的悲剧线，终止侍从关系 | 正文已两次警告母亲可能被杀，也有二次确认；但选项说明仍是通用文案，“尊重她”的正向表述还会与安全选择混淆 |
| 第14章研究路线 | 瞒着她交盘给报社 | 绕过她处理研究，进入背叛结果 | 原专用说明未接入侍从菜单，默认说明不说明关系风险 |

应保留救母方法和研究处置的剧情分量，并把“正常方案”“高风险选择”“明确出卖/退出”表达清楚。避免玩家为了保持已选关系，连普通态度和经营取舍也一律当成生存考试。补提示时无需预告全部后续剧情，可说明“继续当前关系”“明确结束约定”“母亲有生命危险”等当前决策已知的信息。

## 3. 不应误判为横跳的位置

| 位置 | 当前事实 |
|---|---|
| 第11章初次提议、最终确认或收回 | 仍在正式入线前；800只在最后确认成功时收取，属于合理的一次路线选择 |
| 旧800停线档专属序章的收回/重提 | 旧档尚未进入新侍从关系，属于一次迁移确认，不是新档重复弹出 |
| 第12章盘由谁保管 | 两个选项都可继续侍从线；改变保管人和后续可操作范围，不直接改关系 |
| 第15章保护办不成、退回交换救母 | 从乙方案退回甲方案，继续救母和当前关系，不是改做普通恋人 |
| 第19章估价、22章商单、24章现货、25章样品、27章采购 | 不完成估价、不接订单、不买现货或未领样品都不直接结束侍从恋爱；实际交易和服务的货款收益按各自规则处理 |
| 第22章拒收母亲吊坠 | 吊坠留她身上，不退出侍从恋爱；不能因物品没拿全就推断选错路线 |
| 第23章奖励稍后领 | 暂缓本章完成，保留后续领取入口，不解除关系 |
| 第28章三个回答 | 全部是续约成功的不同回应方式；已有回归逐一验证 |
| 晚会暂缓、第二次不去、预约时取消 | 只影响晚会与其后续，不终止恋爱或分红，说明已明确 |
| 普通线已有恋爱后的未来谈话 | 已确认恋爱时自动继续，不重新问是否做朋友 |

另有一处普通线的语义问题：此前选择“慢一点”、尚未确认恋爱的玩家，在后续确认菜单中选择“先按现在这样相处”，实际会被定为朋友。这是未定关系的最终确认，不属于侍从线横跳，但标签很像继续暂缓，宜一起澄清。

## 4. 建议调整顺序

1. **第20章优先收束为已选路线内的告白。** 入线选择保留在第11章。进入侍从线后的告白提供不同情绪与回应方式，共同确认侍从恋爱；普通恋爱与朋友路线继续从原有入口进入。已有转线存档保留历史，不在读档时强制改回。
2. **第28章保留“付工抵承诺 → 自愿留下”的高潮，消除假退线。** 提前点明旧约已经履行，感情和她的去留并非再次等待审核；第三个回应继续表达尊重，把三项写成玩家回应她主动留下的不同方式。
3. **把旧伤处理成修复过程。** 可提供两种确有区别的负责方式，减少明显只有一项能继续的形式选择。若保留明确拒绝负责，说明其后果；不把旧档兜底当成新档还要再考一次。
4. **第14章区分“暂时办不到”和“我退出”。** 前者可以回到已存在的交换救母/筹备路径；彻底退出若仍保留，应直接说清退出关系，放在明确的退出讨论中，避免与常规救母方案并列成一个看似稳妥的选择。
5. **补回已经存在的专用选项说明。** `Option`的默认“不付款”只适合普通回应，不能覆盖盘的出卖、公开与路线后果。甲乙两种正常救母路径可明确兼容当前关系；不可逆背叛需清晰表达。
6. **安全选项允许真实差异。** 交易结果、付款和未领取物品继续有经营后果；关系不受影响的回应无需通过隐藏惩罚区分高低。避免把所有选项都改为数值完全相同的无效选择。
