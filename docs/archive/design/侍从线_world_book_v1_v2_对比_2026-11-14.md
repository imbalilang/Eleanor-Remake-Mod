# 侍从线 world book：第一版 / 过渡版 / v2 对比

日期：2026-11-14  
范围：侍从线 world book 的剧情结构与投资/经营关系。  
对象：
- 原始第一版：m11 固定 800 预付工钱入口；四段王尔德项目链参与主线。
- 过渡版：当前 `tools/NovelWorkFlow_Eleanor/world_book_maid.json`（已改为 C07 起点、唱歌/试演、保留 C/m、E3/E7 与旧档付款规则）。
- v2：`tools/NovelWorkFlow_Eleanor/world_book_maid_v2.json`（C07 起点，更自然的幕卡，五幕 0–4）。

## 1. 结论

**故事结构上，v2 比原始第一版更好；作为可接入的生产世界书，v2 目前还不如过渡版稳。**

v2 解决了第一版最不自然的两点：
- 入线从“另付 800 预付工钱”改成 C07 第二次拾荒售货后的实际侦探费缺口；
- 主线从四段王尔德项目链改成“一次必做筹备 + 后续风味经营”，并用试演、付费返场、正式驻场承接“用自己的名字回去”。

但 v2 丢掉了过渡版里几条必要的接入约束：
- 不再提 E3/E7；
- 不再提旧档按真实付款结果回顾；
- 不再明确 C11、m18–m20、m24–m28、P1–P4 的替换关系；
- C07 未垫款且仍未凑齐 800 的玩家怎么入线，没有写清；
- 唱歌/试演是当前 Content 和角色卡里没有的新设定，v2 把它当成整条第三、四幕的主轴。

## 2. C07 起点是否更好

### 比原始第一版更好的地方
- **投资更自然**：玩家垫的是侦探费的实际缺口，钱直接推进母亲案；不是另立一笔“预付工钱”。
- **入线是共同决定**：C11 双方确认共事才正式进入侍从线；不是付款即入线。
- **更早建立关系**：从 C07 到 m28 有足够时间写工作、称呼、告白和回归；不需要把全部关系压进 m11 之后。
- **保留共同线事实**：C08 电子元件回礼、C09–C10 手镯往来照常发生；玩家垫款只影响调查进度，不跳过共同线。
- **不再需要固定 800 现金门槛**：她自己的拾荒所得照算，玩家只补缺口。

### 新增的风险
- **未垫款玩家的入口不清楚**：v2 的“分线”只说“垫过款或在谈及侦探时已自行凑足的路径”可以谈共事；如果玩家没垫、她当时也还差钱，是否还能进入侍从线、何时进入，没有写。
- **付款实现未定义**：C07 拾荒售货是原生 SELL；垫缺口是交易后的独立选择，但 v2 没写金额如何确认、走现金还是现有界面、旧档如何处理。
- **C07/C11 与现有代码的排期不同**：当前侍从入口在代码第 12 章（m11，800 预付）。把入线提前到 C11 需要新的排期、C11 分支、旧档迁移和路线图同步；v2 没有给迁移说明。
- **唱歌是新增设定**：当前 `Content/story_v06.json`、`maid_v05.json` 和角色卡都没有“她以前学过唱歌”。如果这是用户批准的新事实，应该写进角色卡/设定；如果没有批准，第三、四幕的主轴就悬空。

## 3. v2 相对过渡版的变化

|---|---|---|

| 入线 | C11 双方确认；明确“若 C07 没垫且尚缺，走共同线筹款路径” | “另一次来访谈共事”；未垫且仍缺的路径不再明说 |

## 4. 哪一版更“好”

### 按故事设计
v2 更好：
- 五幕从《还差多少》到《明天几点开门》是一条完整的“投资—工作—改口—试演—驻场—续约”关系线；
- 王尔德只保留一次真正必要的筹备，其余变成经营回访；
- 试演/返场/驻场让埃莉诺自己拿结果，不是玩家买东西换进度；
- 第四幕的“明天几点开门”比原来的事业亮相更像两个人。

### 按接入与风险
过渡版更好：
- 明确 E3/E7、旧档付款、C11、P1–P4、m24–m28；
- 不需要读者猜“没垫款怎么入线”；
- 唱歌虽已写进过渡版角色补充，但至少与现有过渡版结构一起出现；
- 更适合直接拿去跑主笔并映射回现有 Content/C#。

## 5. 建议

**采用 v2 的五幕故事骨架，合并过渡版的接入约束。**

最低限度要先补：
1. 恢复“E3/E7 保留、E1–E14 不变”的明确规则，并写回第四幕。
2. 恢复“旧档按真实付款结果回顾”，不要虚构 C07 垫款或 C11 付款。
3. 写清 C07 未垫款、且她尚未凑齐 800 时的路径：是继续共同线筹款后再谈共事，还是共事与侦探费分开、仍可入线。
4. 定义“通行与试演筹备”如何映射现有王尔德 P2（通行与正装）：是复用 P2 的 ID/费用/交付，还是需要改项目文案；不要新造项目。
5. 如果保留唱歌/试演，把它写进 Eleanor 的角色事实；如果不保留，第三、四幕需要换一个已有事实支撑的目标。
6. 把 C11、m18–m20、m24–m28、P1–P4 的替换/保留关系放回幕卡或单独的接入附录；正文仍可用 v2 的自然写法。
7. 明确 C07/C11 的排期、旧档迁移和路线图更新方案。

如果只看“哪版更适合马上接入”：**过渡版**。  
如果看“哪版更值得作为下一版正式故事”：**v2 的骨架**，但必须先补上以上七项。
