======================================================================
零、设计原则
======================================================================

1. 行为就是选择
   - 玩家不通过“选一个解决方案”来推进剧情，而是通过自己在店里的实际操作来表达立场。
   - 同样一句“我需要钱”，玩家可以：按公道价买她的东西、压价、溢价收购、送她物品、介绍联系人、什么都不做。
   - 好感与分支由这些行为产生，而不是由对话菜单产生。

2. 对话只做三件事
   - 让角色表达情绪与信息。
   - 在关键情感节点给玩家一个“说还是不说”的选择（例如警告 Eleanor）。
   - 在最终路线确认时，允许玩家用一句短对话/一个动作确认自己的决定。

3. 主角的能力来自玩家实际拥有的东西
   - 认出栽赃：来自玩家检查物品，或黑市/上层区声望。
   - 救她：来自玩家实际拥有的联系人、信用点、物品。
   - 破局：来自玩家实际经营出来的声望、金钱与关系。
   - 没有对应的物品/联系人/声望，就没有相应的行为入口。

4. 失败也是行为
   - 不买、不看、不帮、不警告，都是有效选择。
   - 不行动会让剧情走向更冷、更坏的结果，但不会用弹窗替玩家做决定。

5. 当前台本中的“选择菜单”要逐步退役
   - 第 1/2/3/6/7/9 章的解法菜单，改为交易/物品/联系人行为。
   - 第 4 章舅舅包裹，恢复原版行为链，只加“识破 + 警告”一个对话选项。
   - 第 5 章救援/帮助，改为资源与联系人行为。
   - 第 8 章 U 盘、第 10 章最终路线、第 11 章尾声，保留少量最终确认，但由物品与联系人支撑。


======================================================================
一、行为系统总表
======================================================================

【交易行为】
- 公平成交：按接近市价的价格买卖。
- 溢价/让利：高于或低于市价成交；需要交易 UI 支持，或用一个“差价物品/赠品”表达。
- 压价：把价格压到明显低于市价。
- 拒买/拒卖：不把物品放上柜台，或直接结束交易。
- 赠予：把食物、药品、工具、书等物品直接放到她的柜台/背包；资金用现有信用点/交易表达。

【物品行为】
- 检视：检查箱子、U 盘、吊坠、研究笔记等，发现隐藏信息。
- 放置：把箱子放到 Eleanor 面前的柜台；把 U 盘交给某个联系人；把钥匙放在柜台上。
- 保留：不把物品交出去，留在店里或背包里。
- 转卖：把物品卖给另一个客户/黑市。

【举报与安保行为】
- 举报客户：使用游戏现有的举报/逮捕行为。
- 报警/叫安保：使用店内报警或安保联系人。
- 保释/走关系：通过信用点、安保联系人、黑市律师联系人处理。

【联系人行为】
- 黑市联系人：借贷、找律师、打探消息、处理威胁、卖赃物。
- 上层区联系人：律师、改革派、法官、采购客户。
- 下城区联系人：住处、街坊消息、动员。
- 安保联系人：保释、反查、压下案件。
- 报纸/新闻系统：公开 U 盘资料；不新增联系人。
- 革命联系人：泄露路线后的地下渠道（可选）。

【资金行为】
- 信用点转移：直接复用现有信用点/交易/罚金系统；不新增信用芯片。
- 借贷契约：正常借款 / 高利贷 / 黑市借款，用不同契约物品表达。
- 保释金：向安保支付的大额资金行为。

【情感/警告行为】
- 警告 Eleanor：唯一保留的“对话选项”，当玩家已经识破陷阱且箱子还在手上时出现。
- 最终路线确认：允许一句短对话或一个动作确认，但路线本身由玩家实际持有的物品/联系人决定。
- 尾声手势：留下吊坠 / 交还研究笔记，用物品动作表达“留下”或“离开”；没有对应物品时用一句情感确认，不新增物品。

【压缩后的新增清单（重要）】
原则：能复用现有 NPC/声望/物品的，就不新增一次性联系人；只出现一次的角色用旁白交代，不单独做名片。

必须新增（2~3 个）：
- 吊坠 / 旧日信物：同一个自定义物品，第 3 章、第 11 章和新开局共用。
- U 盘：优先复用现有数据芯片/磁带类物品并加唯一标签；如果找不到合适载体，再做 1 个自定义物品。
- 母亲的研究笔记：现有纸书（已在 MOD 中实现）。

复用现有物品，不新增：
- 陷阱箱：复用原版 luxury_supply_crate，加唯一标签/特殊实例；不新增箱子美术。
- 假 U 盘：不新增物品；用旁白交代玩家拿了一个假货，或复用现有空白芯片。
- 当票 / 借款契约 / 价格指南：复用现有纸书、便条、指南类物品；不新增专用物品。
- 信用芯片 / 保释凭证：删除；直接用现有信用点、交易、罚金/保释系统，或旁白交代资金流向。
- 店铺钥匙 / 上层区通行证：删除；第 11 章用吊坠/研究笔记做手势，或保留一句情感确认。
- 装饰性/一次性任务物品：能删则删，不能在剧情里用“你找人办了”带过。

联系人不新增名片：
- 黑市：复用现有放贷人/贷款职员、黑市商人、黑市打手与黑市声望。
- 安保：复用现有安保官、巡逻/检查、举报/逮捕、罚金/保释系统与安保声望。
- 上层区：复用现有上层区客户、慈善客户、导师与上层区声望；律师/法官用旁白交代。
- 下城区：复用现有房东/下城区客户与下城区声望；住处用旁白交代。
- 报纸：复用现有新闻/报纸事件系统；泄露通过事件完成。
- 革命：复用现有革命客户与革命声望。
- 上层区采购渠道：不再新增专用客户；真结局后提高现有上层区买家的出现率/态度即可。
- 一次性律师、调查员、法官、编辑、住房联系人：统一用一次“人脉/电话”行动 + 旁白结果，不单独做角色。

注意：本文只做设计，不承诺全部已实现；但后续实现应优先按本压缩表执行。

【压缩结果对比】
- 新联系人名片：从 8+ 张压缩到 0 张。一次性律师/调查员/法官/编辑/住房联系人全部用现有 NPC/声望/旁白处理。
- 新增物品：从 10+ 个压缩到 2~3 个（吊坠/旧日信物、U 盘；研究笔记复用现有纸书）。
- 陷阱箱复用 luxury_supply_crate；假 U 盘、当票、借款契约、价格指南、信用芯片、保释凭证、店铺钥匙、上层区通行证全部删除或复用现有物品。
- 明确不新增：专用上层区采购客户、专用律师/调查员/法官/编辑角色、联系人名片系统。

第 1 章  上层区的客人
第 23 天 · 下层区当铺
======================================================================

【场景】
当铺门铃响起。一个穿着上层区服饰的女人走进来，身后没有随从。

【保留台词】
埃莉诺：
这就是下层区说的“商店”？铁锈味、霉味，还有一股……穷味。

埃莉诺：
我需要食物。能吃的，没被辐射过的。别拿你们平时糊弄下等人的东西来打发我。

埃莉诺：
我叫埃莉诺。记住这个名字——虽然你们这种地方，大概也留不住什么名字。

【剧情作用】
- 建立身份反差。
- 她不是来聊天的，她是来买食物的。玩家接下来的行为就是“怎么对待一个落难的上层区客人”。

【玩家行为】
Eleanor 是 BUY / FOOD 客户。玩家不选“请她坐下/冷笑/拿黑市食材”，而是直接做交易：

行为 A：按公道价卖给她食物。
- 判定：成交价接近市价，没有明显宰客。
- 好感：+1。
- 触发反应（新增）：
  埃莉诺：
  你没在账上动手脚。下层区居然还有这种人。

行为 B：抬高价格，宰她一笔。
- 判定：成交价明显高于市价，或把临期/劣质食物按高价卖给她。
- 好感：-1。
- 触发反应（复用 er_ch1_after_cold）：
  埃莉诺：
  你倒是有胆子。可惜，胆子在这条街上不值钱。

行为 C：把稀有/高级食物按低价卖给她，或直接作为赠品。
- 判定：卖出稀有食物，且价格低于市价/不收钱。
- 好感：+2。
- 触发反应（复用 er_ch1_after_bm）：
  埃莉诺：
  这盒东西……上层区的配给清单里根本没有。你从哪儿弄来的？

行为 D：拒绝服务，或什么食物都不放上柜台。
- 判定：没有成交，或玩家直接结束交易。
- 好感：-2。
- 触发反应（新增）：
  埃莉诺：
  连一包吃的都不肯卖？……好，我记住了。

【后续台词】
如果玩家实际成交（A/B/C 任一种）：
埃莉诺：
这笔交易……算你有点良心。下次我还会来。

如果玩家拒绝/没有成交：
埃莉诺：
（她看了一眼空柜台，什么都没说，转身走了。）

【章节收束】
- 无论哪种行为，她都会留下一个地址；区别是她对玩家的第一印象。
- 本章结束，推进到第 2 章（第 25 天）。

【实现依赖】
- 需要识别玩家卖出的食物与成交价。
- 如果交易 UI 无法精确判断“公道价/宰客/让利”，可以用特殊食物物品、赠品动作或交易前后差价来判定。

【旧菜单处理】
- er_ch1_choice_1 / 2 / 3 及其描述全部退役，不再作为对话选项。
- er_ch1_after_polite 改为“公平交易”的备用反应，或退役。
- er_ch1_after_cold / er_ch1_after_bm 复用。
- er_ch1_choice_prompt 退役。

第 2 章  不合时宜的体面
第 25 天 · 当铺
======================================================================

【场景】
Eleanor 穿着同一身衣服回来，手里攥着一张折得整整齐齐的购物清单。

【保留台词】
埃莉诺：
还是我。别露出那种表情——上层区的人也会连续两天出门。

埃莉诺：
给我一些日用品。杯子、灯、能锁门的东西。

埃莉诺：
上层区的公寓被收回了。我现在住的“地方”，隔壁整夜都在吵架，墙薄得像纸——不对，就是纸。

埃莉诺：
别问我为什么不回上层区。那些曾经叫我“埃莉诺小姐”的人，现在连我的通讯都不接。

埃莉诺：
我把清单折好了。别笑，这是我今天唯一还能控制的事。

【玩家行为】
Eleanor 是 BUY / HOUSEHOLD_GOOD 客户。玩家通过定价与是否赠送来表达态度：

行为 A：按公道价卖给她日用品。
- 好感：+1。
- 触发反应（复用 er_ch2_after_2）：
  埃莉诺：
  规矩？好。那我也按规矩来：下次我会带够钱。

行为 B：给她折扣，或额外送一包食物。
- 判定：明显低于市价成交，或额外赠予食物。
- 好感：+2。
- 触发反应（复用 er_ch2_after_1）：
  埃莉诺：
  ……这不是施舍。我会还你。

行为 C：抬高价格/把滞销货按高价卖给她。
- 好感：-1。
- 触发反应（复用 er_ch2_after_3）：
  埃莉诺：
  你倒是会做生意。可惜，我身上最值钱的东西，已经不在首饰盒里了。

行为 D：拒绝卖给她，或不做这笔生意。
- 好感：-1。
- 触发反应（新增）：
  埃莉诺：
  原来这里的规矩，是看人下菜。

行为 E：使用下城区联系人，帮她找一间便宜住处。
- 判定：玩家拥有下城区声望/现有房东关系，并使用现有人脉/旁白行为；不是对话选项。
- 好感：+2。
- 触发反应（复用 er_ch2_after_4）：
  埃莉诺：
  那间房……有窗吗？有窗就行。

【章节收束】
- 她离开时第一次没有回头确认有没有人跟踪。
- 推进到第 3 章（第 27 天）。

【实现依赖】
- 需要交易定价判定与赠品判定。
- 复用现有房东/下城区声望与电话或旁白；不新增名片。

【旧菜单处理】
- er_ch2_choice_1..4 及其描述退役。
- er_ch2_after_1..4 复用；新增“拒绝”反应。
- er_ch2_choice_prompt 退役。

第 3 章  被退婚的千金
第 27 天 · 当铺
======================================================================

【场景】
Eleanor 把母亲的吊坠放在柜台上。吊坠的链子断了一截。

【保留台词】
埃莉诺：
我带来了这个。我母亲的吊坠。

埃莉诺：
退婚的消息比判决书传得还快。以前追着我叫“嫂子”的人，现在管我叫“那个贪污犯的女儿”。

埃莉诺：
开个价。别因为可怜我就多给——我现在最受不了的是可怜。

【玩家行为】
Eleanor 是 SELL 客户，吊坠是她带来的物品。玩家通过“买不买、怎么买、买完怎么处理”表达态度：

行为 A：按她的开价买下吊坠。
- 好感：+1。
- 获得：埃莉诺母亲的吊坠。
- 触发反应（复用 er_ch3_after_2）：
  埃莉诺：
  成交。至少你没把我当成一个笑话。

行为 B：买下吊坠，同时给她一张当票/赎回凭证。
- 判定：玩家买下吊坠后，把一张现有便条/纸书（当票）交给她；没有合适物品时用 flag 记录承诺。
- 好感：+2。
- 获得：吊坠；她保留当票。
- 触发反应（复用 er_ch3_after_1）：
  埃莉诺：
  当票……你留着吧。等我把母亲弄出来，我会来赎。

行为 C：拒绝收购吊坠。
- 好感：-1。
- 触发反应（复用 er_ch3_after_3）：
  埃莉诺：
  你说得对。可我除了这点体面，已经没什么能卖的了。

行为 D：使用上层区联系人，压下退婚丑闻。
- 判定：玩家拥有上层区声望/现有上层区人脉，并在她的访问前后主动使用；不是对话选项。
- 好感：+3。
- 触发反应（复用 er_ch3_after_4）：
  埃莉诺：
  你为什么要帮我？……算了，别回答。现在别回答。

【后续信息】
埃莉诺：
退婚是帕斯特集团的人放出的风声。他们想让我彻底闭嘴。

埃莉诺：
我母亲查的东西，可能比贪污严重得多。

【章节收束】
- 吊坠被推过柜台，金属轻响。
- 推进到第 4 章（第 28 天）。

【实现依赖】
- 需要吊坠物品；当票复用现有便条/纸书，或只用 flag。
- 需要识别“买下吊坠”与“交付当票”的行为顺序。
- 复用现有上层区声望/电话或旁白；不新增名片。

【旧菜单处理】
- er_ch3_choice_1..4 及其描述退役。
- er_ch3_after_1..4 复用；新增“拒绝/未成交”反应。
- er_ch3_choice_prompt 退役。


======================================================================
第 4 章  舅舅的包裹（行为化核心章）
第 28 天 · 当铺
======================================================================

【场景】
一个自称 Eleanor 舅舅的男人走进当铺，门外停着一辆没有标识的车。

【保留台词】
自称埃莉诺舅舅的男人：
你就是那个当铺老板？我外甥女最近常来你这儿。

- 黑市：放贷人/贷款职员、黑市商人、黑市打手、黑市声望。
- 安保：安保官、巡逻/检查、举报/逮捕、罚金/保释、安保声望。

【一次性联系人处理】
- 律师、调查员、法官、编辑、住房联系人：不单独做角色/名片。
- 统一用一次“人脉/电话”行动 + 旁白结果，消耗声望/金钱后直接交代“你通过谁办了事”。
- 如果游戏现有的电话/Wild Network 联系系统能复用，就接进去；不能复用就用旁白，不新增物品。

【交互】

- 现有交易、议价、信用点、报纸、联系人系统。

【明确不做】
- 不做 8 张联系人名片。
- 不做信用芯片/保释凭证。
- 不做店铺钥匙/上层区通行证。
- 不做假 U 盘物品。
- 不做专用律师/调查员/法官/编辑角色。
- 不做专用上层区采购客户。

七、供评估的问题
======================================================================

1. 玩家如何学会“行为就是选择”？
   - 目前靠反应台词与结果反馈。是否需要在第一次交易后给一个轻提示：
     “你怎么对她，比你怎么说更重要。”
   - 还是完全不加提示，让玩家自己体会？

2. 陷阱箱的识破门槛
   - 方案 A：主动检视必发现；黑市/上层区声望 ≥ 20 自动识破。
   - 方案 B：只有检视才能发现；声望不自动给答案。
   - 方案 C：默认自动识破（主角是当铺老板，见多识广），检视只是确认。
   你更希望哪种？这直接决定“警告她”选项出现的频率。

3. 警告选项是否只出现一次？
   - 建议：只在玩家把箱子拿到 Eleanor 面前时出现一次。错过就不能回头。
   - 是否允许玩家事后去安保大楼警告/补救？如果允许，会削弱“当场选择”的重量。

4. “收下但转卖”是否要有道德后果？
   - 目前设计为：玩家获利，Eleanor 安全，风险转嫁给别人。
   - 是否要在后续街坊新闻/黑市传闻里出现“某个买家被安保带走”的后果？

5. 第 5A 救援如果玩家没有任何联系人/钱：
   - 现在只能放弃，浪漫线锁死。
   - 是否要保留一个“无门槛但代价极高”的行为（比如签下高利贷/卖掉店铺设备）？
   - 还是让“没有资源就救不了”成为残酷但合理的结果？

6. 交易 UI 能否支持“溢价/让利/赠予”？
   - 如果不能，是否接受用现有赠品/纸书/旁白来表达，而不新增信用芯片？
   - 还是需要自定义一个“定价/小费”界面？

7. 联系人系统是否要复用电话/名片？
   - 现有游戏有电话/网络，部分 MOD 已扩展电话服务。
   - 我们是否把联系人做成“名片物品 + 电话界面”，还是只做“使用名片物品”？
   - 这会影响实现成本和玩家理解成本。

8. 最终章是否保留“一句确认”？
   - 行为化之后，玩家已经把 U 盘交给某人/动用了联系人。
   - 是否还需要一句“最终确认”来强调情绪？
   - 还是让行为本身完成选择，不再多问一句？

9. 第 11 章“留下/离开”用物品手势是否清晰？
   - 放吊坠 = 留下；交研究笔记 = 离开。
   - 玩家会不会误以为只是普通物品交付？
   - 是否需要在物品描述/她的一句台词里明确暗示？

10. 恋爱浓度
    - 行为化后，很多“说情话”的机会被交易行为替代。
    - 是否需要在第 5B/6/7 章各加一个纯情感对话节点（不影响解法），让关系不只靠买卖体现？
    - 例如：她第一次主动留下吃饭、第一次叫玩家的名字、第一次承认“我怕”。

11. 反派与母亲正面登场
    - 行为化不解决“帕斯特太幕后”“母亲只在旁白里”的问题。
    - 是否要在行为链中加一个帕斯特中层客户/母亲来访客户？
    - 这会把“行为叙事”扩展到更多角色，但也会增加工作量。

12. 旧菜单文本是否保留？
    - 当前代码仍用旧菜单；新台本只是设计稿。
    - 确认后，是否要我先做“舅舅章行为原型”，再逐章替换？
    - 还是先完成全部设计定稿，再一次性改代码？

13. 一次性联系人只用“人脉行动 + 旁白”是否足够？
    - 例如律师/调查员/法官/编辑不出现实体：玩家花声望/钱后，旁白交代“你通过放贷人找到了律师”。
    - 这会不会显得敷衍？
    - 还是希望至少让其中一个成为可见的现有 NPC（例如放贷人/黑市商人）？

14. 删除信用芯片/保释凭证后，资金行为怎么表达最清楚？
    - 直接用现有信用点扣款（对话/旁白）？
    - 还是通过买卖一个现有纸书/便条当借款凭证，让交易 UI 完成？

15. 删除店铺钥匙/上层区通行证后，第 11 章只剩：
    - 放吊坠 = 留下；交研究笔记 = 离开；
    - 或一句情感确认。是否够清楚？会不会太隐晦？
