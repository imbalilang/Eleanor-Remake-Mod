# 侍从线：保留“偶像爽点”的替代职业方案

日期：2026-11-14  
背景：用户提出唱歌/偶像线的原因是它不需要解释——落难少女被买下，在主人帮助下成为耀眼的偶像；无论台前多耀眼，她只有一个主人。这是一个玩家天然能懂的经典结构。

## 1. 先抓住真正的爽点

偶像线的爽点不是“唱歌”本身，而是：

1. **落难/被买下**：她起点低，玩家有“我收留了她”的投入感。
2. **主人帮助她上升**：玩家是她的赞助者、训练者、第一个相信她的人。
3. **公开的耀眼**：很多人看见她的价值，她站在灯下。
4. **私下的专属**：台前越耀眼，台下“只有主人能看见”的反差越大。

**职业只是载体。** 只要保留这四步，换一个更贴世界观和她已有能力的职业，爽点仍然成立，而且不需要玩家学习新行业的规则。

## 2. 选择载体的标准

- 玩家一秒能懂：最好是一句话就能说清的经典身份。
- 埃莉诺已经有的能力：上层社交、下层生存、看货/议价、母亲的研究、变通。
- 有“公开舞台”：一群人同时看见她，且不需要新增大量场景。
- 有“私下归属”：台前/台下反差天然成立。
- 主角能帮，但不能替她成功：资金、场地、第一批货、第一次机会、保护。
- 不新增有名角色/路线/结局；演出尽量能用柜台、当铺、后台、转述完成。
- E3/E7、m28 续约保留。

## 3. 候选职业

### A. 天才鉴定师/拍卖师（最推荐）

**一句话爽点**：当铺老板买下/收留的落难千金，被他教会看货，最后站上上层拍卖台，成为一锤定音的女人；台下她只认一个主人。

- **公开舞台**：上层拍卖行/鉴定会。她鉴定一件争议藏品，所有人等她报价。
- **私下归属**：拍卖结束，她回到当铺后间，才叫“主人”。
- **她的能力**：认货、估价、议价、下层货源、母亲研究的辨识度——全是已经学过的。
- **主角的帮助**：教她看货、给她第一批货/旧物故事、用上层客户带她进第一场拍卖、替她挡威胁；不能替她鉴定/举牌。
- **玩家理解门槛**：低。“天才鉴定师/拍卖师”是成熟类型，和当铺、旧物、价格天然匹配。
- **世界观贴合**：当铺、旧物、上层收藏、下层货源、阶级差价；不需要新才能或新行业。
- **风险**：拍卖行需要一个上层场地；可以只写后台/柜台/转述，或作为一次外场事件。

### B. 沙龙女王/策展名流（第二推荐）

**一句话爽点**：她把下层的东西带进上层沙龙，成为上层最想邀请的女人；散场后她只回当铺后间。

- **公开舞台**：她的沙龙/展览；上层人争邀请函。
- **私下归属**：沙龙结束，她留下收拾，和店主两个人。
- **她的能力**：上层社交、下层经验、品味、变通、母亲研究。
- **主角的帮助**：当铺后间做场地、旧物/货物/第一批营养果、上层客人名单；她决定主题和规矩。
- **玩家理解门槛**：中低。“沙龙女王/交际名流”是经典身份；但需要玩家理解上层社交。
- **世界观贴合**：当铺是天然的跨阶层空间；上层客人已经存在。
- **风险**：沙龙容易写成“聊天”，需要有具体事件（鉴定、试吃、展示、冲突）撑住。

### C. 精英秘书/首席管家（经典主从）

**一句话爽点**：她成为上层机构里最不可替代的女人，所有人都要看她安排；只有店主知道她私下叫谁主人。

- **公开舞台**：上层机构/大家族/商会；她一开口，所有人安静。
- **私下归属**：下班后回到当铺，才是私下称呼。
- **她的能力**：上层礼仪、下层执行、记账、跑腿、应变。
- **主角的帮助**：教她下层实务、给她第一份推荐/担保、替她挡旧案牵连；她自己考试/面试/做事。
- **玩家理解门槛**：很低。“完美秘书/管家”是经典主从类型。
- **世界观贴合**：上层机构存在；不需要新行业。
- **风险**：离“侍从”太近，公开耀眼感不如偶像/拍卖师；容易写成日常而不是上升。

### D. 明星研究员/医生（母亲线延伸）

**一句话爽点**：被平反的研究员之女，靠母亲的研究和自己的下层经验成为上层最年轻的研究主持；她的实验室是店主替她保下来的。

- **公开舞台**：研究发布会/医院/学院；她的名字被公开引用。
- **私下归属**：发布会后回当铺，才放松下来。
- **她的能力**：母亲的研究、下层工人/种植户、案件真相、公开表达。
- **主角的帮助**：保护研究、第一批材料/场地、下层联系人、上层渠道；不替她做研究。
- **玩家理解门槛**：中。“天才研究员/医生”是经典类型，但需要一点世界观理解。
- **世界观贴合**：水培农场、营养果、帕斯泰尔、工人——全是现有事实。
- **风险**：研究内容容易写成说明文；需要具体的公开事件和对手。

### E. 歌手/偶像（用户原案，保留但改造）

**一句话爽点**：落难少女被店主买下，在当铺后间第一次开口，后来上层最想听的嗓子只为他一个人唱。

- **公开舞台**：上层沙龙/小型演出/下层街坊演出；不必是完整偶像工业。
- **私下归属**：演出结束，她只回当铺。
- **她的能力**：唱歌是新才能；需要先写成既有事实。
- **主角的帮助**：第一个听众、第一场场地、保护、上层客人；不替她唱。
- **玩家理解门槛**：最低。偶像/歌手是二次元最熟的设定。
- **世界观贴合**：需要新增“她以前学过唱歌”的设定；舞台/演出方/经纪可以尽量不写，只做沙龙/街坊演出。
- **风险**：新才能、新行业、台上高潮只能转述；容易变成“听她汇报演出”。

### F. 名厨/营养果料理人（生活化）

**一句话爽点**：她把下层营养果做成上层抢着预订的席面；厨房里只有店主能尝第一口。

- **公开舞台**：上层宴席/试吃会。
- **私下归属**：宴席散后回当铺后间。
- **她的能力**：营养果、下层食材、母亲研究、上层品味。
- **主角的帮助**：食材、当铺厨房/场地、第一批客人。
- **玩家理解门槛**：低。“天才厨师”是经典类型。
- **风险**：新行业；需要食物描写；和“侍从/主人”张力较弱。

## 4. 推荐排序

1. **天才鉴定师/拍卖师**：最贴当铺、旧物、价格、上层收藏和她的学习线；公开舞台和私下归属都自然。
2. **沙龙女王/策展名流**：最像“名流”，最能用当铺作为跨阶层空间；需要具体事件支撑。
3. **精英秘书/首席管家**：最经典的主从爽点，门槛最低；但上升感弱。
4. **歌手/沙龙歌手**：用户原案，爽点最直接；需要把唱歌写成既有事实，并把舞台压到沙龙/街坊规模。
5. **明星研究员/医生**：最贴母亲线；说明文风险高。
6. **名厨**：生活化、轻松；和主线张力较弱。

## 5. 如果选鉴定师/拍卖师：第三、四幕怎么长

### 第三幕《第一次报自己的名字》
- 上层拍卖行/鉴定会收到一件争议藏品（旧物、矿石、营养果相关物件或母亲研究相关样品）。
- 店主用现有王尔德“通行与正装”替她拿到第一次进场/鉴定机会；只此一次必做项目。
- 第一次鉴定不顺：有人压价、质疑她的下层口音/出身，或拿索菲娅的案子试探她。
- 她自己找出关键证据（灰、刻痕、编号、成分），第二次当场改判；拍卖行/收藏家开始记她的名字。
- 收幕：她带回第一笔鉴定费/第一份正式邀请。

### 第四幕《明天几点开门》
- 上层大收藏/拍卖行请她主持一场重要拍卖；有人想拿索菲娅的案子做宣传，她自己划掉。
- 她在台上只说货和价，不卖惨；台下回到当铺，才用私下称呼。
- 旧约结清；她主动问明天几点开门；E3/E7、m28 三语气、后日谈保留。
- 专场/分红/额外项目按实际购买写经营回访。

## 6. 主角在鉴定师线的帮助

- C07 垫侦探费缺口；C11 共事。
- 教她看货/定价；给她第一批旧物和故事。
- 用现有上层客户带她进第一场拍卖。
- 只投入一次通行/正装/进场条件。
- 在她被质疑、被压价、被威胁时站在前面，但不替她鉴定、不替她举牌、不替她谈价。
- 当铺是她的后台和第一个客户。

## 7. 一句话

**把“偶像”的舞台换成“拍卖台”，把“唱歌”换成“鉴定”，爽点不变：台前所有人都看她，台下她只回当铺叫主人。**  
如果用户更想要纯粹的“名流”，选沙龙女王；如果坚持唱歌，就把舞台压到沙龙/街坊，把唱歌写成她已有的旧事，而不是新行业的偶像工业。
