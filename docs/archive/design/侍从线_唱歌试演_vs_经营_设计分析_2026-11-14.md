# 侍从线：唱歌/试演 vs 做生意，哪个更适合做主线

日期：2026-11-14  
问题：v2 世界书把第三、四幕从“通行、第一单、采购、事业亮相”改成“试演、付费返场、正式驻场”。这个替换是否比现有经营线更好？

## 1. 结论

**唱歌/试演是一个有情绪、好写的方向，但不适合当整条侍从线的主轴。**  
**更合理的是保留“做生意/自己的名字”作为主线，把王尔德从四段门槛压成一次真正必要的投入；唱歌可以留作私下爱好或日常风味，不做职业线。**

原因不是“唱歌不好”，而是它和埃莉诺已经建立的性格、技能、阶级主题、店内演出条件都不够贴合；而经营线本来就是她的能力场。

## 2. 唱歌/试演的吸引力

- 容易写出“她自己的名字被念出来”的高光时刻。
- 有明确的成败节拍：第一次唱砸、改曲再试、拿到返场、正式驻场。
- 和“侍从/主人”的私下关系形成对照：台上是她的名字，台下才是私下称呼。
- 可以写成两人关系戏：店主只争取机会，不替她上台。

## 3. 为什么它不适合当主线

### 3.1 不是现有角色事实
当前 `Content/story_v06.json`、`maid_v05.json`、角色卡都没有“她以前学过唱歌”。这是新加的才能，不是从已有生活里长出来的。要用，必须先把“唱歌”写成埃莉诺的既有事实，否则整个第三、四幕都悬在一个新设定上。

### 3.2 和她的能力场不匹配
埃莉诺已经建立的是：认货、估价、议价、记账、跑腿、拾荒、和下层供货人打交道。她回上层最有力的方式，是用这些下层学会的本事被上层客户承认，而不是靠一副此前没提过的嗓子。

“用自己的名字回去”最有力的版本是：**上层买家必须按她的名字、她的货、她的交期和她谈**。这比“观众记住她的名字”更贴阶级主题，也更贴她“不接受施舍位置”的性格。

### 3.3 会换掉故事的行业和场景
侍从线的场景是当铺、货架、买家、供货人、母亲的研究和下层配给。唱歌/试演把主轴换到剧院、演出方、驻场合同，需要新的行业、新的评价体系和新的曝光方式；按当前“主客户 + 一个 backup、无舞台/人群”的演出限制，试演和登台大多只能由她转述，玩家看不到过程，容易变成“听她汇报”。

### 3.4 表演线容易把她变成被看的人
她已经在“被上层当景观/被同情”的问题上挣扎过。舞台职业天然把“被看、被评价、被鼓掌”放在中心；写不好会回到“她被别人看”的老问题。经营线则是她判断货、定价、交货，主动权在她手里。

### 3.5 “天赋”不如“劳动”贴主题
唱歌需要天赋和舞台机会；做生意需要她已经在学的判断、议价和交货。后者更能证明“她不是靠家里，也不是靠谁施舍，而是靠做得好”。

## 4. 现有经营线为什么也不好

现有“做生意”不是方向错，而是结构错：
- 四段王尔德项目（安顿、通行/正装、第一单、自己的事业）全部参与主线推进；
- 玩家在 UI 里付款，主线才继续，剧情回报被拆成项目交付；
- 第一单、采购、事业亮相抢走了两人关系的篇幅。

所以问题不是“经营 vs 唱歌”，而是**经营被写成了四段付款门槛**。

## 5. 推荐方案：一次真正必要的经营投入 + 自己的名字

### 主线骨架
- **C07**：第二次拾荒售货；玩家可垫侦探费实际缺口。投资直接推进母亲案。
- **C11**：双方确认共事才入侍从线；签约不再另付固定 800。
- **第一幕**：数据盘、威胁、救母；店主承担一件实事，埃莉诺自己决定救母方式。
- **第二幕**：救母后一起做店里的活；她自己谈成一笔货，回来仍想请他看报价；私下第一次改口；下一次来访告白。
- **第三幕“第一次报自己的名字”**：把“试演”换成**第一笔独立生意**。
  - 只保留一次必做王尔德项目：现有 P2 的“通行与正装”改写成“通行与第一次上层的正式会面/验货”。
  - 第一次会面不顺：对方压价、质疑货源，或拿索菲娅的案子试探她；她自己改报价、换货样、找第二个买家。
  - 第二次谈成：对方按她的名字和交期下第一单。玩家可以在场、可以垫条件，但不能替她成交。
  - 这样“通行/正装”是唯一门槛，P1/P3/P4 全部退成可选经营。
- **第四幕“明天几点开门”**：正式供货合同/自己的铺面替换 m27 的事业亮相。
  - 有人想拿索菲娅的案子做宣传，她自己划掉。
  - 合同上只有她的名字；她回店结清旧约。
  - 留一个明天可以不来的停顿，再由她主动问几点开门，或私下用旧称呼问能不能再来。
  - m28 三种续约语气保留，E3/E7 保留；专场、分红、额外项目按实际购买写回访。

### 投资 → 回报
- 玩家真正投入的是：C07 侦探费缺口、P2 通行/正式会面条件。
- 回报不是“买完项目看交付”，而是：她能去见谁、能带什么货、第一单怎么谈成、她在合同上写谁的名字。
- P1 安顿、P3/P4、订单、补货、样品、分红都可以留作风味经营；不买也能走完主线，只是少一些事业规模和回访。

### 唱歌怎么办
- 可以作为**私下爱好/日常风味**：她在打烊后哼两句，或母亲提过她以前学过；不把它发展成职业线。
- 也可以做成**一次可选的下层小型演出**，由街坊/工人自己组织，不是上层驻场；不参与主线和 E3/E7 门槛。
- 如果用户确实想保留“唱歌”作为她的重要部分，那应该把它写成既有角色事实，并接受它会改变侍从线的主题；不能既当新设定，又要求它承担“自己的名字”的全部重量。

## 6. 备选：母亲研究的合作线

如果想让第三、四幕更有“下层/母亲/工人”的分量，可以把第一单改成**营养果/水培研究的合作社供货**：
- 埃莉诺用母亲的研究和下层种植户/工人合作，自己做出第一批可交付的果子或苗；
- 上层买家必须按她的名字、她的合作社和她谈；
- 店主的作用是帮她拿到第一次正式验货/会面，不是替她买成果；
- 这条线用现有营养果、母亲研究、工人和配给站事实，比唱歌更贴现有世界观，也能承接索菲娅。

但它比普通经营线更依赖母亲研究的具体状态，适合作为 P3/P4 的可选经营扩展，而不是新的必做门槛。

## 7. 一句话建议

**把“试演/驻场”换成“第一次独立生意/正式供货合同”，只保留一次通行与正式会面的王尔德投入；唱歌降为私下爱好或可选日常。**  
这样既保留“主角投入 → 剧情回报”，又让埃莉诺用她已经学会的本事、以自己的名字回到上层，而不是靠一条新加的舞台线。
