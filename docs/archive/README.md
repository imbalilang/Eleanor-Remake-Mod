## 使用规则

1. 归档文件默认不再更新；若需引用其中的事实，先确认它没有被现行文档取代。
2. 归档文档中的路径、链接、路线名可能指向更早的结构，不要按它操作当前仓库。
3. 需要恢复某份被归档的设计时，先复制回 `docs/` 根并更新 [../INDEX.md](../INDEX.md)，不要直接在归档里改。
4. 新增归档：按类别放进对应目录，文件名保留日期；同时更新本文件与 `docs/INDEX.md`。
5. 发布记录（`releases/`）与工坊记录（`workshop/`）是证据，不是发布稿；对外文案以平台实际显示为准。
