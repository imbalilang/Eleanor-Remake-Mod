# 0.95：补回莉迪亚的僚机铺垫

2026-11-12。状态：**已构建、已打包、已通过 Steam 预检；尚未上传创意工坊**。

## 问题

玩家在双恋线感到莉迪亚没有实际当僚机，随后埃莉诺的告白和“这句也是她教的？”显得突兀。

根因是 `DualStory.CreateEntry()` 只构建了 `dr01_open`，没有把早已写好的 `dr01_notice` 接入对白。于是玩家在没听到莉迪亚“你要是真喜欢她，我可以帮你一把”的提议前，就直接看到“那你教我几句”的选项；后续 `dr05_confess` 又直接引用“她教的”，中间缺少可见的教练过程。

## 修改

- 双恋入口在 `dr01_open` 后追加 `dr01_notice`，先播放莉迪亚的提议与理由，再进入接受／拒绝选择。旧档兼容的 `v05_legacy_entry` 不追加该段。
- `dr04` 在莉迪亚咨询自己的胸针之后、看货之前追加 `dr04_lesson`：
  - 莉迪亚提醒玩家，埃莉诺最烦别人让她猜；真到开口时别等她问，也别先担心被笑话。
  - 玩家回应后，莉迪亚明确说只教到这儿，别背她的原话。
- `dr05_open` 开头增加埃莉诺的台词：莉迪亚最近总提玩家，劝她听玩家把话说完，别总拿货价堵回去。
- 选项结果、好感／数值、路线、E1—E14 与 0.94 的莉迪亚交易均不变。
