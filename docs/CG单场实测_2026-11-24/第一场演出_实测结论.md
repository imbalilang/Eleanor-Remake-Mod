# 《第一场演出》单场生产实测

2026-11-24。侍从线第 46 天，《日用品》后。两份初稿都由“索菲娅提到女儿会唱歌，收工时店主听她试麦，埃莉诺想听他亲口回应”起笔，使用同一幅表内草图和同一句配文。直写稿在调用 Opus 前存档校验。图片在排版时对两稿统一加入，V7 主笔收到的是本场的文字构图。

**生产决定**　本批采用直写加超级 QA。《第一场演出》取直写稿作编辑底稿，《两位老板娘》按同法生产。本次 Opus 产出了一次完整来访。V7 在格式化正文长度检查处退出，进入正式审核和出稿的条件尚未满足。

| 实测项 | 直写 | 原版 V7＋Opus |
| --- | --- | --- |
| 成稿 | 1 场，10 条玩家可见对白或动作 | 1 场，42 行带标签的正文（含章名、时间、选择元数据），另有 11 行选项附录 |
| 亮图 | 收工后发现麦克风断声，她从头唱给他听，配文出现一次 | 她唱到末尾，拿开麦克风才问。配文出现一次，原稿把它放在普通对白行。匿名读稿中编辑把这一句移到图上 |
| 游戏回应 | 店主主动说漏听了最后一个字，末尾也亲口答话，走一条线 | 给店主“说听清了／请她再唱／只点了点头”三个回应，V7 本地分支校验通过 |
| 单场交付 | 转成游戏行标签后，超级 QA 合同检查 P0/P1/P2 均为 0 | 引擎计得正文 1,163 字符（含标签），要求至少 1,800。开启首次失败即停，进程退出码 1，正式 Final 产物 0 份。完整候选从主笔输出取回 |
| 候选的另行检查 | 原句、人物和相邻章节由编辑核对 | 正文与分支合并送超级 QA，P0＝0、P1＝1（时间标签不被检查器识别）、P2＝3（口头词、人物标志语密度、动作密度）。格式检查与编辑核对分别记录 |

**对白取舍。** Opus 写她第一句起高、自己停下来重唱，台上这一下很具体，也给店主一句“重来的那句也听清了”的机会。稿中还让她回顾“上午在库房，我哼了两句”，这一共同经历没有在前情中建立。她开头复述母亲已经讲给玩家的话，结尾又约好下次穿礼服来唱，把第 51 天才开始谈的上层机会拉得太近。这些属于需要改动的段落，逐行洗口吻帮不上忙。

**接入量。** 两稿都要把台上段落落到项目允许的 CG 呈现中。直写稿主要处理两处现场衔接：店主在台下说漏听的那句，以及图后他怎样亲口回应。Opus 稿另需处理四处内容：缩短窗口的旧事复述及账房交代，去掉虚构的上午库房共同经历，收掉礼服预约，把三个回答分别接到共同段。“只点头”接“你说听清了，我就信”前尤其要读一遍。两份稿均出自本次测试，尚无实机计时或人类盲评结果。

**运行范围。** 真实使用项目 V7，主笔配置 `anthropic/claude-opus-5.5`，独立侍从线世界书副本，原版两份提示词。只发起一轮主笔生成，后续检查在本地完成。生产模板、游戏内容和发布包保持原版。
