## 人物声音

- **エレノア**：私。誇り高く、早口で皮肉。お母様、あいつら、かしら、〜のよ／わ。説明口調にしない。原作の短い棘を優先。
- **リディア**：明るく早口。私／あたしは要確認。感情を説明せず、言葉が先に出る。
- **ソフィア**：落ち着いた大人。私。丁寧だが冷たくはない。
- **店主（プレイヤー）**：俺。短い。説教しない。相槌だけで済ませない。
- **おじ（偽）**：丁寧な営業口調の下に押しの強さ。
- **警察官**：手続き口調。です／ます。
- **ナレーション**：過去形、短く、動作と物だけ。心理説明を足さない。

## 表記

- `<i>...</i>`、`<b>...</b>`、`{0}`、`\n`、`*...*` は保持。
- 台詞に話者名や表情タグを入れない（話者・表情は Content 側）。
- 中国語の四字熟語・慣用句をそのまま日本語に持ち込まない。原作用語がある場合は原文の言い回しを優先。
- UI は短く。長い説明を足さない。
