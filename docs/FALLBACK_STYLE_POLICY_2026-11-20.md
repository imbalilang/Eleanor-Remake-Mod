# 拒绝时的画风兜底策略

OpenAI 拒绝时不重复重试，也不把 Grok/混元直接当成同一主标准。

主标准：OpenAI 简单转绘。
兜底变体：腾讯混元一次性转绘，单独标记为 fallback_tencent_v1。
Grok：只做构图、姿势和镜头探索，不承担最终像素风。

腾讯兜底：母图 + 白花睡服 B 风格锚点 + 同一简单转绘提示词；只生成一次；不连续改图；打光问题最多修正一次。

兜底结果必须保持角色主导构图、同一身份服装和像素锚点。允许轻微差异，但不能静默混入主标准。

当前证据：腾讯简单转绘勉强通过但打光偏亮偏冷；Grok 不通过；OpenAI 主配方 4 次中 3 次通过。
