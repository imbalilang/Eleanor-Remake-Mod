# 原作 Eleanor 章节对照稿（Probably Stolen 本体）
日期：2026-11-10
用途：把游戏本体里 Eleanor 相关对白按场景顺序整理成可反复阅读的对照稿。只使用官方中文本地化，不混入 MOD 文本。
## 格式说明
- 文本来自游戏 `Dialogue` 本地化表；场景标题是为阅读整理的索引，不是游戏内官方章节名。
- `玩家（行动）`、`玩家（选择）` 是游戏里的行动/选择提示，不是玩家说出的台词。
- `{0}` 是运行时数字；文中在需要处注明实际值。
- 原文的 `<i>` 斜体已转成 Markdown 斜体 `*...*`，保留动作/语气提示。
- 分支按代码里的选择/条件展开；同一句在多个分支共用时会重复出现，方便逐条对照。
## 触发顺序
第一次来访 → 第二次（+2）→ 第三次（+4）→ 假叔叔（+5）→ 警告/第四次来访 →（被捕/保释/释放）→ 第五次来访 → 侦探筹款与拾荒 → 数据盘 → 威胁 → 方向选择 → 结局。具体日期由 `StorylineSchedule` 决定，这里只保证触发先后。
