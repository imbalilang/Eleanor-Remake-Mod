# C08 · 不是拿来卖的

**处理：重点优化**

来源判断：MOD 新增回礼来访。

编辑判断：回礼事实重复，反复推元件收手，多个分支都有装饰性收尾；拿着就走指向含混。

保留重点：送礼时别问、付钱后的不满、被拒后的倔强及全部赠礼结果。

### c08.b101 · 她带来一块回礼材料

旁白：她来到窗口前，手里只捏着一小块东西，用布角包着。

埃莉诺：今天没货。

埃莉诺：就这一块。

旁白：布角摊开，里面是一枚电子元件，边角干净，没沾灰。

埃莉诺：从废料堆里捡的。接口没锈。

埃莉诺：这块材料别跟其他的算在一起。给你的。

埃莉诺：拿着。别问。

旁白：她把元件推到柜台正中，手停了一下才收回。

## 本章修改记录

**c08.b101，旧索引 5**

原：我留了一块。

新：〔删除整行〕

只带这一块、给店主的台词已说明留下元件用于回礼；删除一次重复交代，少一点专门挑留的强调。

**c08.b101，旧索引 7**

原：拿着就走。别问。

新：拿着。别问。

保留强硬遮掩的送礼口吻，去掉让守店的玩家拿着就走的歧义；shy 表情保留。

**c08.b102，旧索引 0**

原：你不算钱？

新：你倒收得痛快。

刚明确说是礼物，接受分支不再惊讶玩家为何不付钱；改为借打趣遮掩羞意，仍接以后每回得带点。

**c08.b102，旧索引 2**

原：我记着。就这一句。

接受礼物后的反应和下回还带的打趣已足够，删去指代不明的记账与宣布只说一句。

**c08.b102，旧索引 3**

新：〔删除整行〕

主段已经把同一元件推到柜台正中并收手，省去接受分支再次推、再次收手。

**c08.b102，旧索引 4**

付钱分支保留不满和收下硬币的动作，简化退场的逐步手部调度。

**c08.b104，旧索引 2**
