# 莉迪亚：僚机双恋线角色与美术设定

日期：2026-11-09。配套台本：`全流程攻略_纯阅读版_闺蜜双恋线_设计稿_v0.1.txt`。本稿为角色重设与概念美术，未替换游戏资源。

## 1. 核心形象

**她很会让别人心动，直到这一次，她自己先认真了。**

莉迪亚是27岁的成年女性，上层区出身，替几家小商户协调展示、预约和寄售接洽。她不缺与陌生人说话的本领，也知道自己漂亮。她会选择合身的衣服、看人的角度、适当的停顿，享受自己能让一场谈话变得有趣。

她的不足同样具体：太习惯替别人安排，容易把“我知道怎样省事”误当成“我知道你真正想要什么”。面对自己的需要，又常拿玩笑遮过去。她不是没有脾气的热心助手，也不是任何男人多看两眼就爱上的社交花瓶。

前期她主动当僚机，是关心埃莉诺，也有一点看不惯两人笨拙的自信。中期发现玩家会记得她本人的疲倦、工作和选择，开始想为自己多留一会儿。后期她失去“替朋友办事”的借口，必须学着直说“我想见你”。

## 2. 保留与改变

| 保留既有辨识 | 新方向 |
|---|---|
| 深栗／偏紫棕的短发，侧分、蓬松轮廓 | 发型更利落有层次，保留耳边发丝和成熟感 |
| 橄榄／榛绿色眼睛，清楚的眉形 | 平视、略带笑意，目光主动；认真时视线会短暂避开 |
| 金色菱形耳饰，深青绿服装 | 延续菱形到项链和扣饰，形成个人标志 |
| 与埃莉诺的旧友情，对下层区有过偏见 | 明确承认试探与过度安排，靠具体行为改变 |
| 嘴快、会观察 | 台词不再只报告埃莉诺的近况，也讲自己的工作、欲望与失误 |

不改成金发长发，不复刻埃莉诺的衣服和表情，不因为新恋爱线就抹去镯子试探。少女感不作为主要吸引力，强调成年女性的从容与偶尔失措。

## 3. 性感的表达

服装采用深青绿短外套、香槟色缎面垂褶内搭、深色高腰贴身裙、细金项链。领口露出锁骨与适度胸线，腰线清楚，肩部仍有正式外套的利落感。整体像一位下班后仍愿意来当铺坐一会儿的漂亮女人，不像只能出席一次宴会的造型。

身体吸引力通过合身剪裁、自然曲线和放松姿态表现。保持不透明面料、正常穿衣，不加情趣配件或强制性的服从符号。性感不靠对白反复描述胸腿，也不把她变成一位没有自己的生活的诱惑者。

她可以主动说“我今天好看吗”，也可以在玩家看出耳饰变化时忽然接不住话。前者建立自信，后者使自信背后的人可亲近。

台词原则：每次暧昧有具体对象与情境，不句句双关；真正在意时减少技巧，句子反而更短。埃莉诺的认真、嘴硬和依恋不被她的社交能力压成陪衬。

## 5. 表情与场景

| 表情建议 | 使用位置 | 表演重点 |
|---|---|---|
| 从容浅笑（基础） | 初见、业务咨询、僚机建议 | 先看人再说话，知道自己说得有趣 |
| 得意调侃 | 撮合进展、换耳饰、双恋日常 | 嘴角更明显，眉眼带一点挑战 |
| 短暂失措 | 玩家关心她本人、夸她好看 | 刚想笑着带过，却慢半拍 |
| 收起笑容 | 撮合成功后的失落、告白、被拒 | 保持尊严，不用哭脸证明真心 |
| 柔和亲近 | 双恋确认后单独相处、三人晚饭 | 不再一直维持应酬表情 |

首轮游戏美术可先完成基础与认真两种，不以表情数量拖延剧本。其余可由台词和停顿承担。差分要有明确状态接入，不能仅把图放进目录就当它会自动播放。

## 6. 与埃莉诺的视觉关系

莉迪亚：短发、深青绿与香槟、金饰、侧身与目光；成熟、主动、懂得展示自己。

埃莉诺：沿用当前原版及美化风设计；本线使用她自己的常服或回到上层区的既有形象，不套侍从女仆装，不复制侍从舞会礼服作为本线终局奖励。

三人场景轮换说话者画像，服装不应相似到需要靠名字才能分辨。两位女性都美，不以降低埃莉诺的表现来突出莉迪亚。

## 7. 游戏成品规格与替换边界

- 延续已有双画风：无少女当铺使用原版像素风，启用时使用美化风。两套需分别绘制／适配，不能直接把本概念板缩小两份充数。
- 单张目标288×212、RGBA透明背景，人物取景和光向与现有UI一致；原版风与美化风分别核对色板、像素密度和描边。
- 服装吸引力集中在脸、肩颈、领口和饰物；概念板下半身的裙形用于完整角色参考，不要求游戏把全身塞进头像区域。
- 首版保留现有莉迪亚资源和键名，待用户选定形象并完成成品后再实施替换。本轮未覆盖`Textures/Items/er_portrait_lydia_female_*`。
- 若换装只限新线，应新增明确的专属资源和场景解析；若全局重设，则两种画风同步更新，不能把非恋爱剧情也改成持续脸红的表情。
- 含`female`的命名、少女当铺启停、缺图回退与读档队列处理沿用现有兼容要求。

## 8. 剧情验收

1. 她的每次主要出场至少表达一个自己的判断或愿望，不能全是埃莉诺近况播报。
2. 撮合阶段和自己动心阶段可分辨；没有提前把玩家当恋人，却又在后面假装第一次告白。
3. 第28章前的暧昧不自动等于交往；双恋在三方明确表态后成立。
4. 玩家拒绝时，她有尊严地退出，不用哭闹、失业或被抛弃威胁玩家。
5. 埃莉诺有独立相处与表达不满的篇幅；莉迪亚不以帮助回上层区换取分享恋人。
6. 角色仍与原镯子事件和旧友情连续，不靠重设外貌把旧行为悄悄清空。
