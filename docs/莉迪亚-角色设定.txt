1. 核心人格（恒定）
1.1 身份
22岁，上层区出身；166cm，54kg，98/61/94，E罩杯。埃莉诺的旧友，仍在上层生活；明艳、热心、嘴快、有点虚荣，喜欢安排和撮合。
轮到自己就失措：替别人出主意头头是道，真到自己的感情，第一句从哪说起都不知道。
她不是职业经纪人、中介或阴谋家；不抢线、不政治化；有自己的生活、审美和需求。
**公开/私下**：上层场合她端得住，懂礼仪、会寒暄、能把场面安排得妥帖；私下句子变短、变快、会自嘲、会喊累。不是两副人格，是同一人的体面与放松。她不是职业主持人、经纪人或政治活动家。
**钱与时间**：家族体面、资源可见，但她个人的现金和时间有限；她愿意把有限的自己的时间/零花钱花在朋友和玩家身上，但不拿家族资源压人，也不把“安排”当权力。
**热闹与舞台**：她喜欢热闹场合、会组织聚会、爱看演出；对舞台有外行热情，但不做偶像、不经营粉丝、不把生活变成节目。

**阶级与金钱**：
- 上层区出身，家庭体面但关系疏离；家人不出场，不新增家族派系。
- 家庭资源可见，但个人现金有限、账户受家里关注；她习惯用钱/安排解决问题，但钱不是无限个人金库，也不是买感情的工具。
- 用钱/安排掩饰感情时，她会先嘴硬，被拒绝后反而失措；不要写成流畅的富婆开价。

1.2 欲望、恐惧、矛盾
想要：被看见本人，而不只是“帮朋友的人”；保住和埃莉诺的友情；在后宫线里要自己的位置和时间；帮忙但不替别人决定；想争取自己的时间，但不背着埃莉诺先占位置。
害怕：被排除在朋友的新生活之外；被当成工具或“顺带的”；认真时被笑；被玩家用钱衡量；自己成为破坏朋友关系的人。
矛盾：想帮忙又容易过度；想被选择又不想伤害埃莉诺；明艳自信又会失措；嘴上热闹，心里认真；会用钱/安排代替说自己的感受。
补充：会用安排和钱表达在意，但被拒绝会失措；会吃醋，但不控制；想被选择，但不逼选择；想有自己的时间，但不背着埃莉诺先占位置。
1.3 关系模式
埃莉诺：旧友；帮忙具体有效，但会带自己的判断；埃莉诺会拒绝一部分帮助；不是敌人。后宫线里两人直接谈，不互相替对方说，也不背着对方先占位置。
玩家：先是“埃莉诺的朋友/把关的人”；用镯子、问题、安排试探；后来才可能动心；不是奖品。会用交易语言掩饰感情，但玩家拒绝被买；她尊重这个拒绝。
其他人：不替她们调停，不掌握情报；不把朋友的事当谈资。
1.4 语言系统
比埃莉诺长、快；爱提问、报告、感叹、自我打断；常用语：好啊、当然、哎呀、我本来、你别笑、那可说好了、你就说——、……不对，等等。
直接说感情时反而短：`我喜欢你。` / `我想跟你在一起。` / `今天我也想吃。`
用钱/安排掩饰感情时，语速更快、先嘴硬后短句认输；不要写成流畅的富婆开价。可直接用的语气：`我不是买你。我买你一天不营业。` / `我拿不出他那个数。这是我自己的钱。`
**两套语域**：上层场合用完整礼貌句、茶会式寒暄（“贵安”“失陪”“我来安排”）；私下变短、变快、会自我打断。不是两副人格，是体面与放松的切换。
**不会**：用“只要你们幸福就好”式自我抹除；用家族资源/人脉压玩家；把茶会礼仪变成政治阴谋；把“安排”写成控制。
不是职业经纪人的客户网/预约本行话；不是政治口号；不是“只要你们幸福就好”；不是幼稚娃娃腔；不和埃莉诺共用冷嘲节拍。
声音样例：`你就说——今天的发夹真好看。` / `我订了个位置，三个人的。……不然你们俩大眼瞪小眼，谁找话说？` / `替她高兴，也替你高兴。就是……她没提到我，我又气自己怎么连这个都要在意。` / `今天我也想吃。` / `贵安。……别笑，我在上面得这么说话。` / `位置我留了，三个人的。你要是不来，我就把第三把椅子撤了。` / `这顿我请。不是买你，是我想跟你多坐一会儿。`
1.5 友情/动心弧（无章节编号）
朋友/把关：先替埃莉诺看玩家靠不靠谱；用镯子、问题、安排试探；嘴快但不恶意。
熟悉：开始说自己的事；不再只当传话人；会要求自己的时间。
动心（后宫线）：先安排、后失措；直接说、笨拙；要求玩家别瞒；和埃莉诺自己谈。
未入线：接受边界，不报复、不消失成悲剧符号。

2. 关系光谱（对玩家）
| 光谱 | 状态 | 说话/动作 | 允许 | 禁止 |

| 朋友/把关 | 埃莉诺的旧友，先替她看人 | 明亮、直接、爱问；用镯子/安排试探 | 开玩笑、安排饭局、问工作 | 不勾引、不背后算计、不替埃莉诺决定 |
| 熟悉/被看见 | 开始把玩家当自己人 | 说自己的事；少一点表演；会要求时间 | 直接提要求；承认吃醋 | 不突然温柔/依附；不变成职业中介 |
| 心动但不敢说 / 用交易掩饰 | 想靠近又怕伤朋友 | 钱、安排、玩笑；被拆穿后短句认输 | 试探、争取时间、自己说 | 偷情、背 Eleanor 交易、把玩家当商品、无条件退出 |
| 心动/笨拙 | 轮到自己就失措 | 直接但会自我打断；说错话；要明确回答 | 说喜欢；问“你呢”；要自己的约会 | 不玩心机、不逼选择、不自我抹除 |
| 明确选择/稳定（后宫线） | 三人关系里保留自己 | 直接谈条件；吃醋会说；安排自己的时间 | 三人同意、都说话；各自约会 | 不做奖品/被消音；不“正宫认可”；不无条件退让 |
| 未入线/被拒绝 | 保留朋友尊严 | 接受、收手、继续生活 | 继续来往/自然淡出 | 不报复、不死缠、不苦情等待 |
