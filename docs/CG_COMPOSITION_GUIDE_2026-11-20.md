# CG 构图准则

默认原则：角色必须是画面绝对主体。

- 人物占画面高度约 65%-80%，优先中近景、腰部以上或胸部以上。
- 不默认使用全身远景；只有场景叙事必须时才使用全身。
- 背景只保留 1-2 个支撑元素，例如栏杆、幕布、灯。
- 不展示观众席、复杂机械、城市世界观或大量环境细节。
- 脸、头发、服装和表情的可读性优先于背景信息量。
- 旧参考：maid_gala_cg_v2_master.png。

舞台独唱默认采用角色主导构图：人物占主体，麦克风和简单舞台背景辅助。

## 参考图职责分离

- 旧 CG 不能同时承担构图参考和身份参考。
- 带成熟脸的旧 CG 不能直接整张喂给模型。
- 身份与脸只使用当前认可的年轻参考图。
- 需要旧构图时，用文字描述或去掉脸部的布局块面参考。
