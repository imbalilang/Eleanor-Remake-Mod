# 垃圾填埋场：埃莉诺的协助

初版实现于2026-11-08；2026-11-09已随0.75发布，见 `RELEASE_0.75.md`。下述分项验证保留当时记录，正式包已通过54组回归。

## 玩家看到的变化

- 恋爱确认、母亲平安的路线甲/乙，在原有收束节点解锁协助。朋友、路线丙/丁不增加奖励。
- 去掉静默的永久拾荒次数 +2，改为原版交通地图中垃圾填埋场卡片上的 **「埃莉诺的协助」**。卡片有埃莉诺帮忙整理废料的说明，以及两条明确效果：**拾荒次数 +2**、**拾荒时不会受伤**。
- 事件持续当天。原版每日随机事件阶段按 **70%** 概率抽取，可以连续出现；没有出现的日子没有这两项收益。
- 原版先处理固定星期事件；当天有新启动的固定事件时会跳过该地点的随机抽取。例如周三新启动的「垃圾倾倒」保留原版优先级。因此 70% 是随机阶段的概率，不是所有游戏日必定独立抽取。
- 收束对白相应调整，新解锁时追加效果提示。新增事件和提示均有中英文文本。

## 复用原版与旧存档

`ScavAssistance.Register` 通过原版 `ModHelper.AddAfterhourEvent` 注册地点事件。直接使用 `scav_attempts=2`、`injury_immunity=1`，原版 `ScavHelper` 同时负责显示数值、次数消耗以及轻伤/重伤判定，不新增拾荒或受伤补丁。

保留已有 `er.scav_assist` 存档键，含义调整为事件解锁资格。已解锁的旧存档在下次原版每日事件抽取时参与随机；加载存档、打开地图、重复注册均不会额外抽取或凭空增加次数。活动事件的 ID 和结束日期使用原版 `afterhourState.activeEvents` 保存，读档后保留当天事件及原本的到期日。

致残及关节退化导致的 0 次拾荒仍由原版提前返回，不会被 +2 复活。免伤只涉及垃圾填埋场的拾荒判定，不治疗已有伤势，也不修改其他地点或其他受伤来源。与其他原版次数事件正常相加，免伤可以覆盖同时存在的「垃圾倾倒」伤害概率上升。

启用时只注册定义和延迟求值的文本/资格函数，不访问 `PlayerStore`；禁用时移除本 MOD 的事件定义，残留的原版活动 ID 不再提供效果。全局存档 schema 仍为 2。
