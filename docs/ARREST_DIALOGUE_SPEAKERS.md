# 拘捕对白发言归属修复

2026-11-09，基于0.76发现并修复，已与全线发言归属适配一起随0.77发布。本文保留最初个案的定位和当时62组验证记录；完整66组验证与149种组合复查见 `DIALOGUE_SPEAKERS_0.77.md`、`RELEASE_0.77.md`。

## 原因与范围

假叔叔举报成功后的 `c04.b003` 原文包含治安员、假叔叔及玩家三种发言，源数据没有把它们全写成假叔叔。

本机0.46D的 `DialogUIManager` 只把 `Dialogue.title` 等于 `PLAYER` 的句子送往玩家通道，等于 `SEC` 的句子送往治安员通道，其余均送往当前顾客通道。顾客通道的气泡名称和历史记录直接读取当前访客 `displayName`，不使用该句填写的中文/英文名字。

MOD此前将 `StorySpeaker.Officer` 映射为本地化“治安部警官”，导致治安员的三句对白进入当前假叔叔通道。假叔叔自己的三句同样走顾客通道，因此该段七句里有六句记在假叔叔名下。最后一句玩家发言原来已经使用 `PLAYER`，本次验证确认仍归玩家。

修复位于 `src/StoryEngine.cs`：治安员改为原版 `SEC` 控制标记，展示名称和记录名称由原版按语言解析。MOD内治安员发言仅出现于两块：假叔叔被拘捕 `c04.b003`，以及埃莉诺被箱子陷害 `c05.b007`，两处共用修复。没有新增全局UI补丁、改顾客姓名、重写举报机制或改写对白。
