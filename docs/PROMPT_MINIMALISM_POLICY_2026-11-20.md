# 提示词精简与 T0 分工

T0 规则用于生成后的验收，不写进生成提示词。

原因：
- 长提示词会稀释注意力。
- 多条肢体数量锁会和姿势参考冲突。
- 过度负向约束会让模型只盯着错误。
- 供应商模型本身知道手、腿、耳朵的基本结构。

正确分工：
1. 提示词只负责：角色、服装、场景、姿势参考、画风。
2. 姿势参考图负责：手臂、腿、镜像和遮挡关系。
3. T0 检查负责：生成后验收。
4. T0 失败：直接丢弃并重画，不把 T0 清单塞回提示词。

提示词优先级：
1. 图像角色（谁提供身份、谁提供姿势、谁提供风格）
2. 场景和服装
3. 姿势参考的服从要求
4. 画风
5. 简短禁止项（文字、水印、多余角色）

T0 连续失败时改这些，而不是加长提示词：
- 换姿势参考图
- 调整构图/画幅
- 把两个角色分得更开
- 换模型
- 使用局部版面块面参考
