Eleanor Story Expand 1.02 — Nexus package
==========================================

中文
----
- 本包与创意工坊版使用同一套内置美化立绘，不需要另外安装《少女当铺 / CutePortraits》。
- 埃莉诺的基础五套立绘（eleanor1/2/3/scav/rev）使用经作者授权的 CutePortraits 资源，已随本 MOD 内置；莉迪亚、母亲、女仆、礼服使用本 MOD 的美化定稿。
- 革命线：公开/队伍场合绿色正装；R06 后私下/亲密场合黑色战术背心（v3 已导入）。常规恋爱线的亲密私服与结婚结局 CG 仍在计划中。
- 不再检测或兼容其他替换立绘的 MOD；请不要同时启用《少女当铺》，避免重复贴图或覆盖。
- 版本 1.02；游戏 1.0.0.14 / 1.0.0.13 / 0.46D 兼容。
- 内容分级：成熟向；含性张力、暗示与非露骨身体描写，不直接出现 R18 场景。
- 主要改动：后宫线、埃莉诺线、侍从线和革命军线的后期回应选择；后宫线停用普通恋爱线拾荒协助；保留全部路线、数值与 E1—E14 结局。

旧存档兼容
从未订阅过本 MOD 的存档，在首次开店时会触发“旧档案”事件；无论原埃莉诺进度如何，可选择重置埃莉诺的故事，并从本 MOD 剧情的第 1 章重开。
旧存档中的 `cp_portrait_*`、莉迪亚/母亲 `_vanilla` 键会在载入时迁移到内置美化立绘；未内置的通用 `cp_portrait_*` 键回退原版。

安装：将 EleanorRomance 文件夹放进
`Probably Stolen/Mods/EleanorRomance`，在模组菜单启用后重启游戏。
不要同时安装创意工坊版或另一个 Nexus 副本。

English
-------
- This package uses the same bundled beauty portraits as the Workshop build; the separate CutePortraits mod is not required.
- Eleanor's five base portraits (eleanor1/2/3/scav/rev) use authorized CutePortraits assets bundled with this mod. Lydia, Mother, maid and gala use the project's own beautified portraits.
- Revolution route: green formal wear in public/team scenes; black tactical undersuit in private/intimate scenes after R06 (v3 imported). The regular romance intimate outfit and wedding ending CG are still planned.
- Other portrait-replacement mods are not detected or supported; do not enable CutePortraits alongside this package.
- Version 1.02; game 1.0.0.14 / 1.0.0.13 / 0.46D compatible.
- Content rating: Mature; sexual tension, innuendo and non-explicit suggestive content; no explicit sexual scenes.
- Highlights: late-route response choices across the harem, Eleanor, maid and revolution routes; the ordinary-route scavenging assist is suppressed in the dual route; routes, values and E1—E14 endings are unchanged.

Existing saves
A save that has never subscribed to this mod will trigger an “old file” event on its first shop day. Regardless of prior Eleanor progress, you can reset her story and restart from chapter 1.
Legacy `cp_portrait_*`, Lydia/Mother `_vanilla` keys are migrated to the bundled beauty portraits at load; external `cp_portrait_*` keys without a bundled asset fall back to vanilla.

Install: extract the EleanorRomance folder into
`Probably Stolen/Mods/EleanorRomance`, enable it in the Mods menu, and restart.
Do not install the Workshop copy or another Nexus copy at the same time.
