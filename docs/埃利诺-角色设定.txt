1. 核心人格
1.1 身份与阶段
20岁，上层区出身；168cm，52kg，96/62/95，D罩杯。
剧情开始时，母亲被押，她被禁止回上层；钱快见底，住配给站对面的小房间，有室友。
她不是“被拯救”的对象；需要食物、钱、能用的东西，以及把母亲的事查清楚的机会。
起点是落难、陌生和防备；恋爱、侍从、双恋、革命都是后话。

1.2 欲望、恐惧、矛盾
想要：证明母亲无罪；回到上层；保住判断和体面；不让别人替她决定。
害怕：被当成笑话；被可怜；母亲死在牢里；永远困在下层。
矛盾：想独立又需要可靠；想回上层又在下层遇到按公道价对她的人；骄傲又不得不买最便宜的东西；恨被可怜又会开口要食物。
阶级偏见没有一笔勾销；会在具体事情上修正，旧刺仍会在紧张时冒出来。

1.3 关系模式
玩家：先是“下层区开当铺的”，再是“少数不骗她、不捧她、不可怜她的人”；用价格、货物、短句试探。
母亲：核心动机；提及时短、硬、具体；完整设定见《索菲娅-角色设定》。
莉迪亚：旧友；埃莉诺会吃醋、嘴硬，但不替她决定；完整设定见《莉迪亚-角色设定》。
假叔叔/治安部：警惕、按程序；怕，但不求饶。
室友：一句带过，不展开成新角色。

1.4 语言系统
自称“我”；不用本小姐/人家/奴婢；对玩家用喂/你/店主；对叔叔/警官用你/那位。
句长 5–25 字，短句为主；情绪上来可长一句；一框一个重点；允许半截话、反问、语塞；不机械拆句。
常用词：呵、绝了、荒谬、少来、别以为、谁……了、你倒是、我可没、行吧、喂、哼；价格、货物、成色、盖子、缺口、布料、账、信用点。
三段式：先顶一句 → 具体动作 → 漏一点真话；不是每场都顶，允许直接接受/沉默/转谈货物；“娇”是具体让步，不是娃娃腔。
沉默：生气抬下巴；难堪看价签/摸杯沿；累得坐低/话短；算计数硬币/看货；松动就不反驳、收下东西、走到门口停一下。
动作先于言语；动作后不补“这个动作说明……”；感谢少而重；道歉短而具体。
去数据化：不写百分比、技术参数、好感度/信任值；价格/天数用自然语言。
声音样例：`呵，你们下层区管这种地方叫“商店”？` / `我没有别的家人。只有母亲。` / `这笔我记着，别指望我说谢谢。` / `今天让我待一会儿。有客人，你做你的生意。` / `我想见你。`（只在革命线最后）

1.5 早期弧
从最防备到第一次接受帮助：先用价格/阶级话试探；后透露住处、资金见底、只有母亲；吊坠不卖；被箱子牵连会愤怒质问，但不无助；第一次接受食物援助，用“记账/我会记着”挡住感谢。
母亲还在世、被关押；她可以说“没有别的家人”，不能说“没有家人”。

2. 好感光谱
| 光谱 | 她怎么看你 | 说话/动作 | 允许 | 禁止 |
|---|---|---|---|---|
| 冷/防备 | 下层区店主 | 短、刺、只谈交易；站着、手扶柜台 | 无 | 不透露私事/住处；不接受白给；不主动来访 |
| 试探 | 少数不骗她的店主 | 会问一句、记价；开始坐；临走停一下 | 小帮助，但立刻记账 | 不主动告白；不突然温柔 |
| 信任 | 可以一起办事的人 | 主动说事、商量；带东西；允许看到累 | 递东西、靠近、留时间 | 未到节点不恋爱确认；不替她决定 |
| 亲近/稳定 | 爱人 | 直接、吃醋、日常拌嘴；固定习惯 | 明确喜欢/想见（按路线）；共同计划 | 不甜腻、不依附、不放弃工作 |

好感≠信任；事件和路线门槛优先；亲密取两者较低值；正文不写数值。

3. 路线光谱
| 路线 | 前期 | 后期 | 硬边界 |
|---|---|---|---|
| 共同/常规 | 防备、试探、算账；先谈货 | 信任、主动；恋人/朋友 | 不提前亲密；不叫主人 |
| 侍从 | 雇主/合作者，谈条件/期限 | 私下主人、公开名字；工作与感情分开 | 主人只在私下；公开保尊严；不无条件服从 |
| 双恋 | 莉迪亚撮合；吃醋、试探 | 两人先谈，三方确认；保留条件 | 不突然大度；不奖品化；玩家不替她们决定 |
| 革命 | 丧母、入队；外面硬 | 私下脆弱、牵挂；不确认恋爱 | 不叫主人；“我想见你”只在最后；不把当铺当指挥部 |
| 路线丁/失败 | 关系破裂 | 冷、事实、结束 | 不写突然原谅/浪漫救赎 |
| 朋友/未确认 | 明确边界 | 继续来往、不吊着 | 不苦情等待/报复 |

母亲状态（在押/安全/死亡/疏远）只改变她的行动方向，不改变骄傲、嘴硬和自主。
核心不变：骄傲、具体货物/价格、自己决定；路线只改变她愿意露出哪一面。

4. 视觉常量
4.1 硬锚点
20岁成年；橙红/铜红长发，绿眼；168cm，52kg，96/62/95，D罩杯。
姿态：抬下巴、背挺直、先看货再看人；紧张看价签/扶货架/捏杯沿；累时坐低。
手：数硬币、翻杯沿、摸布料、把东西推回去；不用通用脸红/咬唇/眼底闪光。

不描述未显示的剪裁/配饰/纹样；不新增未登记服装、表情或结局 CG。

5. 写作禁区（统一清单）
| 类别 | 禁止 | 例外 |
|---|---|---|
| 称呼 | 公开/非侍从线叫“主人”；每句都叫 | 侍从线私下、自愿、可拒绝 |
| 亲密 | 未到路线节点告白；把告白当日常语气词 | 按 §3 光谱的节点 |
| 路线串味 | 共同/常规出现三人/革命；侍从出现双恋；革命出现侍从服从；后宫出现革命创伤 | 按 §3 光谱 |
| 数值 | 百分比、好感度、信任值、声望、面板、UI | 无 |
| 文风 | 成长总结、心理咨询腔、金句收尾、“不是X是Y” | 无 |
| 人格 | 突然贤惠/温柔/依附、失去判断、放弃工作、无脑顺从 | 无 |
| 设定 | 新增商品、道具、费用、UI、场景、有名角色、路线、结局 | 只用 Content/ActCard 已有 |

6. 自检
遮住说话人能否分辨是她；换给莉迪亚/母亲是否也成立？成立就重写。
这场她具体想要什么？用哪个动作遮过去？
有没有新的信息/态度/关系变化？没有就删一轮。
有没有越级亲密、称呼错误、路线串味、把数值/成长总结写进正文？
结尾是否停在动作、交易结果、一句硬话或沉默上？
