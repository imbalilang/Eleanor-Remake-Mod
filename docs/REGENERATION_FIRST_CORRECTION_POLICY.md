# 修正策略：重写提示词并重生成优先

日期：2026-11-20

## 结论

对已生成图片做修改时，不一定要基于上一轮产物继续编辑。对于多项结构性修改，直接重写完整提示词并从原始源图重新生成，通常比连续局部改图更稳。

本次 Grok 验证：

- 没有继续编辑上一轮 Grok 输出
- 用原始参考图 + 风格图 + Lydia 身份图重新组织完整提示词
- 一次生成同时完成：换脸、去眼镜、去金色光环、去格纹外套、保留白色胸托、保持姿势、像素化
- 结果优于连续编辑链

## 触发重生成的条件

满足任一条件时，优先重写提示词并从原始源图重生成：

1. 一次修改包含 2 个以上结构性元素
2. 上一轮已经出现过风格、像素密度或颜色漂移
3. 需要同时改脸、服装、背景、配饰或姿势
4. 连续局部编辑超过 1 次
5. 模型对局部指令理解不稳定

## 标准流程

1. 找到干净原始源图
2. 单独准备风格参考
3. 单独准备角色身份参考
4. 把全部要求重写成一份完整提示词
5. 一次性生成
6. 跑清晰度门槛
7. 如果仍需修改，重复上述流程，而不是在产物上继续叠改

## 模型差异

- Grok：对完整重写提示词理解较好，适合一次性重生成
- 腾讯混元：内容尺度最宽，但连续改图漂移明显，更应重生成
- OpenAI：编辑能力较强，但多项结构修改仍建议重生成
- Seedream：适合高频重生成，不适合长编辑链
