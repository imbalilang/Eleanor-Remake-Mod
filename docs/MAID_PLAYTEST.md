## F9 定位工具

游戏现有开发模式启用后，F9 → Command 增加中英对照按钮：侍从入口、旧800序章、女仆首秀、侍从告白、基础结局、王尔德P1、23章后未付P1、归来24～28、乙线撤案新闻、侍从状态。

这些按钮会重设本MOD剧情状态，归来按钮还会建立**未实际扣钱的调试付款夹具**。仅用于独立测试存档的画面和交互定位，不计为正常经营流程；不能据此验证费用是否平衡。状态按钮不改进度。

实际经营至少记录纯现金、人脉、混合三种路径的可用资金、原生升级是否被挤压、声望恢复天数、准备各项目的时间及原版终局日期。当前基准总额：新档纯现金17800；全人脉9800及两区各20声望；旧档各减800。实际报价保留原版折扣与wildFavor抵付。
