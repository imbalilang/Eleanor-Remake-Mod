# 清单式对白与原版句长

2026-11-21 · 简体中文 · 对照 1.25 发布包与本次工作区正文

## 玩家听见了什么

> “营养果，耐放的，两箱。”、“毯子，厚的，四张。”、人，活的，不这么说话。

后宫入口《窗口》里，莉迪亚咬着笔帽，要给刚到下层的朋友送东西。两框连续按“货名、要求、数量”填满三项，连停顿都一样。换成任何采购员都能照读。选“让她列完”还会原样听一遍果子和毯子。两句原来分别只有 8 字、6 字，单看长度都会放过。

这回她说“营养果得挑耐放的，先给她送两箱。”“再拿四张厚毯子。”“对了，她家楼梯没灯！上回我可是摸着墙下来的。”她一想起上次摸黑下楼，就自己添了灯。埃莉诺这时插一句“我没让你送。”玩家肯让她继续，她才接“灯有一盏就够了，灯泡得备三只，还有——”。不让送的分支仍讲得出两箱果子摆在门口会怎样。

革命军《空着手》的“外套一件，鞋一双，铁盒一个。”保留。她在转述队里清点一个死者的遗物，下一句有人问外套谁要，没人接话。恋爱线“硬的，嚼着带响儿的那种。”也保留。母亲刚问她小时候喜欢哪种甜食，她答的正是入口时的感觉。

## 原版实测

基准取原游戏埃莉诺相关的 18 场官方简中。对照稿中的 141 次 NPC 发言（含分支复用与纯动作）逐行核过本体 Dialogue_zh 表。可比的埃莉诺口播去重后是 109 框。MOD 取新档五条路线的章节正文、选项后的回答与交易反应，补入实际复用的侦探费结账、复核回执、撤案后对话和后宫日常 2、3。跳过旧档专用章节、菜单、选项标签、新闻与纯旁白。数字代表剧本文本分布，玩家选择不同路线时的遇见频率会不同。[原作逐场对照](../原作Eleanor章节_对照稿_2026-11-10.md) · [新档范围与运行依据](../新档全章节文案AI感分级与修复批次_2026-11-21.md)

每项按说话人和相同文本去重，字数只数汉字、字母与数字，数字占位符算 1 字。“框内单句”按句号、问号、叹号切分，逗号、顿号和省略号保留在同一句。“完整语句”还接回同一人以下一框续完的逗号尾句，仅接同一块的相邻行、或原作稿上连续的同人发言。“单框口播”累计框内所有说出口的话。“对白框含动作”加上该框斜体里的动作字数，仍排除纯动作框。P95 指样本从短到长排列后第 ⌈0.95 × 样本数⌉ 个值。

下表用埃莉诺对埃莉诺。每格依次给出 **中位数／P90／P95／最长**，单位为字。

| 口径 | 原游戏 | MOD 1.25 | 本次修后 |
| --- | --- | --- | --- |
| 完整语句 | 10／22／28／43 | 8／17／19／43 | 8／17／19／43 |
| 框内单句 | 10／19／22／37 | 8／17／19／32 | 8／17／19／29 |
| 单框口播 | 13／23／25／37 | 13／24／27／38 | 13／24／26／37 |
| 对白框含动作 | 13／23／25／37 | 15／25／28／40 | 15／25／28／37 |

修后样本有 1,274 个不同的埃莉诺口播框、1,904 个框内单句。最长的 43 字完整语句出自共同线保留的原作拾荒段，本体也分三框才说完。计入所有角色后，本体 135 框、MOD 2,469 框，单框口播 P95 都是 25 字。含动作的整框 P95 分别为 25 字、27 字。原版对照中的 NPC 以埃莉诺为主，MOD 还包含店主、莉迪亚等人的应答，人物结论优先用上表。

这轮主要改掉的是局部的生硬和拥挤。生日密码前一框已写她输入自己的生日，一次就打开。原来下一框又复述“她拿我生日锁这种东西”，才讲到她十岁那天的委屈。修后这一框从 38 字降到 26 字，只留下她冲母亲嚷过的话。《空着手》把扶椅背、贴墙、坐下、膝与手的位置压成“把椅子抵住墙才坐下，双手搁在膝上”，让“这椅子一腿长一腿短”还像人在故意岔开话题。三个原先超过 37 字的含动作框和一个超长口播框均已回读。

## 后续逐章怎么用

- 遇到连续两框都按“东西、什么样、多少”说，连同上下两句和分支出口一起念。找出人物眼下想让对方做什么，把要求放回一句能说出口的话。她如果是在点数、背口供、模仿别人或等人插嘴，保留这个场合需要的停顿。
- 普通口语在同一框里一句超过 **22 字**，或一框连动作超过 **25 字**，列为回读候选。先看上一框已经给过什么，再看对方本来能在哪儿插话。可以少报一遍、收掉多余动作，也可以原样留下。莉迪亚挑果子的第一句从 8 字增加到 14 字，听起来自然比字数更重要。
- 新增或重写的对白框超过原版样本最长的 **37 字**，优先核查。需要一口气讲出的事实、有铺垫的回忆或情急时的抢话可以保留。原版分框续说的台词按完整语意读，避免靠改句号或另开一框制造合格数字。

在仓库根目录执行以下命令。第三行会列出高于对应原作 P95 的文字与行键，可直接在编辑器中定位。

```powershell
python tools/build_content.py
python tools/review_zh_dialogue_length.py --zh dist/workshop-1.25/EleanorRomance/Localization/zh.csv
python tools/review_zh_dialogue_length.py --over
```

## 接入与核对

简中已从 Content 重新生成，全部 5,550 个键与 1.25 一一对应。新的《窗口》列单同步到英、日、韩。核对时还发现，侍从“分三堆”“夹层里的盘”的两个已改段落曾把动作从对白中独立成行，日、韩文仍按拆分前的行号播放。已按现有说话人重新对应这两个块的 71 行，英文本中挤在下一句的动作也移回对应行。日、韩各补齐 9 个已有的游戏行键。其余外语章节未作通篇文风评估。

项目内容检查和 Release 编译通过。用本机游戏程序集离线展开 161 条路径，28 个改动键均能抵达。《窗口》的三个怀表选项分别接三个送礼选项，九条都先经过笔记本，再走到各自的打断或收本回应。另核了未垫侦探费、保护线母亲购物和革命军让价反应，以及四处中段续读。已认可的 dv11、手镯和告白关键句逐键对照 1.25。交付为工作区游戏文本，本次未推送工坊。验证到离线顺读，尚无实机点读或新玩家回访。
