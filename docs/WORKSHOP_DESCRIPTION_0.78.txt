[h2]上层区的富家千金爱上在下层区开当铺的我：埃莉诺剧情扩展[/h2]

“呵，你们下层区管这种地方叫‘商店’啊？”

她是上层区最大水培农场前负责人的独女。母亲被以挪用公款罪关押，家族一夜崩塌，她跌进自己曾最看不起的下层区。
你，是这里的一家当铺老板。

靠识货、开价、留证和承担风险，先成为她愿意信任的人。你们可以成为平等的恋人、继续做朋友，也可以选择一份双方说清条件的侍从约定。她的骄傲、判断与救母决心始终保留。

[h2]English[/h2]
An expanded Eleanor story with equal romance, friendship and an optional attendant relationship, four story-gated Wilde projects, five Upper Level return visits, real shop interactions and an independent case review. Original-style and Maiden's Pawnshop-style maid portraits are included; no other mod is required.

Version 0.78 fixes the tool-supply and chapter 25 sample visits spawning the unregistered wrench_old placeholder, which showed the raw id on hover; the native wrench_orange is now used, and existing placeholder wrenches in old saves are repaired on load with the correct name, icon, value and tool types. It also replaces StartCoroutine on a game MonoBehaviour with ModHelper.Delay, removing the Modding API 100-Rev13 threads finding so the mod remains loadable after the 2026-12-10 security update. Capabilities remain empty, so no developer verification or player re-authorization is required. Game 1.0.0.13 / build 26525552, with public and open_beta sharing the same build.

Recent content keeps all attendant confession responses on the chosen romance route, clarifies voluntary renewal, and offers two ways to repair trust. Raising rescue concerns opens a discussion; full withdrawal and irreversible actions have explicit consequences and confirmation. Existing ordinary-lover and friend saves retain their choices and paid support.

The story also includes shared-appraisal dialogue, a morning reunion and a customer update during existing visits. After chapter 28, the attendant romance can receive an optional Upper Level party invitation, followed by native newspaper coverage. The party uses ordinary dialogue and narration, with no new scene, payment or evening outing cost. Vanilla reuses Eleanor's Upper Level portrait; Maiden's Pawnshop uses a new wine-red gown.

Scavenging assistance is now a visible landfill event: +2 attempts and injury immunity for the day, with a 70% chance in the native random-event phase. Fixed-day events retain priority. Wilde's projects each have one cash option; the last three receive a half-price base cost when the stated reputation conditions are met, without spending reputation. Existing paid connection plans keep their history and results.

Normal start on day 23; optional early-start perk on day 12. All-ages. Chinese and English each contain 2294 keys. In-game feedback remains welcome.
