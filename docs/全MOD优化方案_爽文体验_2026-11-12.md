# 全 MOD 优化方案：从卢 MOD 学习，但围绕“爽文体验”

日期：2026-11-12
范围：Eleanor Story Expand 全 MOD
状态：分析与方案，未实装

## 0. 结论

**补充原则：正如 MOD 的名字一样，我们不是一个特别严谨的 MOD，不需要太讲道理和逻辑。主要目的是通过与埃莉诺的恋爱过程，让玩家获得爽的情感体验。《深空当铺》有大量数值和严谨的世界观，但在情感上比较匮乏；本 MOD 的优化优先级是情感爽点，而不是系统严谨性。**

我们的核心资产不是“多路线”“旧档兼容”“路线图”或“测试工具”——这些是支撑，不是卖点。真正的卖点是 **爽文体验**：四条路线用不同的套路，让玩家体验“被上层女性选择、需要、争夺、服从或等待”的幻想。

因此，向《卢：可能是结婚？》学习时不应当：

- 缩窄成单角色 MOD；
- 用进度面板解决体验问题（已明确否决）；
- 继续增加经营系统、饰品或声望门槛。

应当学习的是：

- 让玩家亲手说出爽点台词，而不是读固定台词；
- 让感情事件连续发生，不被经营系统打断；
- 让每个角色有自己的声音、欲望和专属时刻；
- 让玩家在关键节点有“被选中”的实感。

## 1. 四条路线的爽点定位

| 路线 | 核心幻想 | 主要爽点 | 当前问题 | 优化方向 |
|---|---|---|---|---|
| A 恋人线 | 阶级反差下的相互选择 | 她放下骄傲、当众维护你、主动回来找你 | 玩家多为旁观者，关键台词固定；经营门槛打断节奏 | 增加“她选择你”的选择和公开场合；把声望改为支线 |
| B 后宫线 | 被两名上层女性同时渴望与争夺 | 被争抢、被需要、三方确认、专属约会 | Lydia 感情铺垫薄；双恋仅 13 个选项；检查点切断情感 | 提高选择密度；补 Lydia 的欲望与主动；增加争风吃醋但保持三方同意 |
| C 侍从线 | 支配、被服侍、身份反差 | 她自愿归属、服从与照顾、契约续签 | 玩家容易变成接受服务的人，缺少“下令/决定”的爽点 | 增加命令式选择、她主动留下、公开/私下反差 |
| D 革命军线 | 被依赖、不可替代的避风港 | 她冒死回来、只对你卸下防备、安静占有 | 玩家台词极少，主要作为供货者和听众 | 增加“她回来找你”“你决定她的去留/行动”的选择；强化你对她不可替代 |

## 2. 卢 MOD 真正值得学的部分

《卢：可能是结婚？》约 1,379 行、188 个选择；我们的双恋线约 295 行、13 个选项。差距不只是字数，而是：

1. **玩家台词选择化**：它把几乎所有玩家发言变成选项，让玩家决定“怎么说”，而不是读“我说了什么”。
2. **选择即爽点**：玩家能亲口说“不许在我的店里杀人”“我也想你了”“我还需要时间”。这些话由玩家说出，爽感远高于系统代说。
3. **角色声音统一**：短句、绰号、玩笑、停顿、动作旁白；角色不解释自己的心理，让玩家从反应里看出来。
4. **感情线连续**：受伤 → 旧军令 → 过去 → 立规矩 → 约会 → 告白 → 礼物/吃醋/道歉 → 求婚 → 婚后，中间没有声望或经营门槛。
5. **持续的同意/拒绝**：玩家可以暂缓、拒绝、做朋友；被选择的路线因此像玩家赢来的，而不是默认发放。
6. **专属纪念物和时刻**：鲜花、戒指、钥匙卡、约会、婚后闲聊，都是爽文的“战利品”。

注意：该 MOD 目前因违反 Steam 社区准则被下架，也有“AI 味重”和后台权限的批评。学习其结构，不照搬其内容、权限或批量文风。

## 3. 优化方案

### 阶段一：爽点选择化（最高优先级）

目标：不增加篇幅，把玩家从“读者”变成“说话的人”。

- 把四条路线中表达**立场、欲望、占有、保护、拒绝**的固定玩家台词改成 2—3 个短选择。
- 所有选项都继续剧情，只改变对方当场反应；不做“选错就断线”的假选择。
- 选项必须是玩家会说的话，不用系统说明做标题。
- 目标：感情场景约每 8—12 行一次选择；每条主路线至少 40—60 个选择点。

示例：

- 恋人线：她当众维护你时——`“站我这边就好。”` / `“不用为我吵架。”` / `“我自己来处理。”`
- 后宫线：两人争你时间时——`“今天陪她。”` / `“三个人一起。”` / `“先把话摊开。”`
- 侍从线：她问今晚要不要留下——`“留下。”` / `“你可以自己选。”` / `“今晚别走。”`
- 革命军线：她又要出任务时——`“我等你。”` / `“这次别去。”` / `“东西我准备好了。”`

### 阶段二：爽点节奏重构

目标：让感情线连续发生，而不是“谈恋爱像做任务”。

- 每条路线按“吸引 → 拉扯 → 反转 → 专属选择 → 公开确认 → 日常/结局”的节奏重排。
- 同一路线连续两次感情事件之间，最多插入一次经营/声望事件；声望与饰品改为可选强化或支线。
- 每条路线至少安排 3 次“她选择你/需要你/主动靠近你”的明确爽点，以及 1 次“你为她付出，她因此改变”的反转。
- 后宫线增加争抢与吃醋，但不能让两名女性被动共享；玩家必须做出平衡选择。
- 侍从线增加“她自愿留下”的时刻；革命军线增加“她活着回来找你”的时刻。

### 阶段三：角色专属爽点事件

目标：补角色深度，不再加系统。

每条主路线补 2—3 个 8—12 行的专属事件，每个事件 1—2 个选择，围绕一个明确的爽点：

- 恋人线：上层公开场合她介绍/维护你；她放下身份来下层找你；她第一次主动送你贴身物件。
- 后宫线：两人争一次约会；三方第一次共同外出；吃醋后的道歉与规则；玩家明确分配时间。
- 侍从线：她替你看店/照顾你的一天；契约续签时她主动选择留下；公开场合与私下称呼的反差。
- 革命军线：她受伤后回到店里；你准备的东西救了她；她第一次为了你推迟行动。

每个事件至少包含：一个动作/物件、一句角色专属台词、一个玩家选择、一个关系状态变化。

### 阶段四：文本与声音

目标：让角色像角色，而不是设计文档。

- 每个角色一份“说话方式”清单：句子长度、称呼、回避方式、什么时候说真话。
- 感情场景禁止出现“关系”“资格”“奖励”“门槛”“日常”等系统词。
- 多写动作和物件：披肩、耳夹、胸针、账本、柜台、药箱；少写“我现在明白你为什么重要”这类总结。
- 玩家台词保持短、准、克制；让选择承担表达，不靠长台词。
- 中文先定稿，英文按角色语气重写，不逐字翻译。
- 做一次朗读/删减 pass，删掉解释角色心理的句子。

### 阶段五：爽点呈现

目标：强化已有内容，不新增系统。

- 继续使用短顶部提示，避免把规则塞进对白。
- 饰品、纪念物、结局页作为爽点战利品；描述只保留一句效果和风味。
- 入口保持低调但明确：满足条件时给出一次短提示；不做进度面板。
- 路线图与阅读稿继续作为外部资料，不要求玩家先读。

### 阶段六：质量与发布

- 保留现有 JSON 内容管线、双语文案、路线图、旧档兼容和测试工具——它们是基础设施，不是宣传卖点。
- 每次更新聚焦一个体验问题（例如“选择化”“Lydia 主动”“侍从命令感”），不要同时堆大量系统改动。
- 实机验收重点：爽点是否由玩家触发、选择是否有不同反应、感情线是否被门槛打断。
- 不引入不必要的后台权限；避免批量 AI 腔和重复句式。

## 4. 验收指标

- 感情场景选择密度：约每 8—12 行一次。
- 每条主路线至少 40—60 个选择点，其中至少 10 个是“表达欲望/立场/占有/拒绝”的爽点选择。
- 每条路线至少 3 个“她选择你”的事件、1 个“你改变她”的反转。
- 连续两次感情事件之间最多一次经营/声望事件。
- 感情对白中系统词为零；玩家台词以短句为主。
- 每条路线至少 2—3 个专属场景，使用既有角色/美术资源，不新增系统。

## 5. 明确不做

- 不做游戏内进度面板（不影响现有体验，也不是玩家需求）。
- 不缩窄成单角色 MOD；四条路线的广度是我们的优势。
- 不在补足角色内容前继续增加饰品、声望或经营系统。
- 不照搬卢 MOD 的后台权限、批量文风或已被下架的内容。
- 不用“更多字数”冒充“更好体验”；优先选择密度和爽点质量。

## 6. 建议顺序

1. **阶段一**：先改四条路线的关键固定台词，成本最低，爽感提升最直接。
2. **阶段二**：优先重排后宫线与恋人线，去掉感情事件之间的经营打断。
3. **阶段三**：先补 Lydia 与 Eleanor 的专属事件，再补侍从与革命军线。
4. **阶段四—六**：随每次内容更新持续做文本润色、呈现和验收。
