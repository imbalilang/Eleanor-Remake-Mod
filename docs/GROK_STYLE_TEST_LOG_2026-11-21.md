# Grok 图生图 / 尺寸 / 画风测试记录 — 2026-11-21

## 结论先行

1. **不要再用多张画风参考图。** 多张像素风格图会污染 CG 内容，带入源图没有的配件、发饰、构图和细节。
2. 画风流程固定为：**1 张内容母图 + 1 张像素风格锚点**。需要加强画风时，优先重跑或改提示词，不增加第二张风格图。
3. 改尺寸不要直接让模型把方图压进 16:9。必须先把内容放进 16:9 画布，只补左右，再洗画风。
4. Grok 大尺度 CG 允许 4/5，但必须只有一项指标出界、相对偏差不超过 40%，且无 T0；规则见 `docs/CG_STYLE_ACCEPTANCE_GROK_2026-11-21.md`。

## 尺寸结论

直接把 1024×1024 内容母图洗成 2048×1152，会让模型压缩人物上下比例。

正确流程：

1. 建 2048×1152 画布，内容方图按原比例居中；
2. 左右补床面/枕头，不改人物；
3. 用补边后的 16:9 图作为内容母图，再洗画风。

## 多风格参考污染结论

P2–P5 的位置测试虽然全部 5/5，但后续证明多张风格参考会污染内容，例如：

- 把参考图里的玫瑰/发带带回来；
- 改变服装、发饰、构图；
- 让模型把风格参考当内容参考。

因此：

- `harem_two_bunny_bed_grok_restyle_p5` 只作为历史证据保留，不再作为新任务的配方；
- 新任务一律 **1 内容母图 + 1 风格锚点**；
- 内容母图本身必须先把玫瑰、错误发饰、错误腿环修掉，不要靠风格参考去压制。

## 当前可用配方

- 内容母图：已修正的 16:9 CG
- 风格：`pixel_style_anchor_white_B.png` 一张
- 提示词：明确 discard smooth rendering，保留比例，禁止新增配件
- 模型：`x-ai/grok-imagine-image-2.0`
- 参数：`size="2048x1152"`，`quality="medium"`
- 验收：5/5 优先；4/5 按 Grok 大尺度规则，且只能一项出界
