# 既有 CG 洗画风流程

适用于《CG规划》里已有底图、需要统一像素画风的事件 CG。每张按 **整体处理画风 → 核对脸部 → 对齐环境 → 整图复验 → 960×540 入库** 的顺序走。整图尚有影响观感的差异时，回到对应环节调整，反复复验直至通过。

## 1. 选底图和参考

| 参考 | 用法 |
| --- | --- |
| 事件底图 | 选出构图最稳、最符合分场的原图。登记事件 ID、底图和原尺寸，确认本场的机位、动作、服装与关键道具。 |
| [原图参考](../Art/原图参考/STYLE_ANALYSIS.md) | 用对应角色的原画或定稿立绘对脸、核对角色与服装。看眼型、瞳色、眉眼比例、脸颊和下巴，表情与视线取自本场。 |
| [场景参考](../Art/场景参考/SCENE_STYLE_ANALYSIS.md) | 选与本场地点最接近的参考，取建筑结构、家具、光源与材质设定。 |
| [唯一 CG 画风母图](../Art/cg_style_master.png) | 用户确认的埃利诺侧躺图。全片以它校准轮廓线宽、像素阶梯、发束高光、布料层次和明暗色块。各场的光色、服装和背景按分场选取。 |

开工先按事件 ID 核对 [CG规划.xlsx](../CG规划.xlsx) 的分场。确认缺少的剧情道具或机位要求，按该场安排修改。

## 2. 整体洗画风

从事件底图出发，以唯一画风母图为准做一遍整画面的像素重绘，建立统一的线条粗细、像素尺度和明暗色块。沿用底图的构图、人物位置、动作和服装，保住原图的表现力。头发、皮肤、衣服和道具用相近的像素尺度。主要体积由连贯的明暗色块表达，高光、边缘磨损和必要的织纹再用小像素簇补足。

按 [CG 提示词模板](CG_PROMPT_TEMPLATE.md) 记录生产设置。每轮写清底图、参考的用途、要重绘的区域、需要保留的画面内容。首轮出图后做 960×540 预览，检查是否出现全图泛光、均匀噪点、粗马赛克或平滑插画轮廓。

## 3. 核对脸部

用同一角色的原画、定稿立绘与相近表情核对脸型、眼型、瞳色和眉眼比例。在同一轮也检查上眼缘、虹膜和鼻尖的色块在 960×540 能否读出像素感。脸型已经对得上时，可只重画线条和色块。保留本场的头部角度、视线、表情和遮挡。

局部重绘从当前最佳版本裁出对应区域，保留刘海、饰物或道具边缘等对齐点，记下裁框坐标。生成后按原坐标用遮罩合回，检查发丝、下颌和遮挡交界。重要的锁定区域可用像素差分核验。每轮另存版本。

## 4. 对齐环境

用原作场景参考校对地点、建筑结构、光源与材质。先确认场景能否在空间站设定下成立，再处理表面细节。必要时重画背景结构，比如把上层区的玻璃顶外景调整成有梁架、内层步道与人工采光的封闭中庭。保住原场面的空间关系，例如扶着的栏杆、坐着的台阶和手里拿的道具。

按材质整理色块。金属的磨损集中在接缝和边角，石面与布料的阴影按形体合并，暖光收在有明确灯源的位置。不同地点保有各自的亮度和色温。合成后检查头发缝隙、手与支撑物、裙摆与背景的接触边。

## 5. 整图复验与返修

在 **960×540** 下，先用事件底图和上一版核对当前版的剧情动作、角色与服装，再和唯一画风母图检查像素阶梯、线宽、色块与层次。已实装 CG 可用于核对剧情与显示效果。

- 检查发束、皮肤、布料和环境的像素尺度、轮廓与明暗色块是否协调。
- 检查画面焦点、光源方向、手和关键道具。放大图用于排查双边、漂移和接缝。
- 发现可见差异就回到对应步骤。脸过平滑就重画眼缘和虹膜，环境质感或世界观有冲突就修场景，人物上色偏油或偏碎就收高光、归并阴影。每轮修完都回到 960×540 的整图对照。
- 原尺寸下提升不明显时沿用更符合分场的版本，继续用同一标准验收。人物、场景和整图画风都通过后收稿。不同景别、光线和角色的重复性验证沿用 [CG 画风约定](CG_STYLE_CONTRACT.md)。

## 6. 导出并打入游戏

1. 整图通过后，按[运行图导出标准](CG_RUNTIME_EXPORT_STANDARD_2026-11-23.md)从事件定稿原图单次 Lanczos 导出 **16:9、960×540 无损 PNG**。事件定稿原图、运行图、提示词和参考记录按[提示词留档规则](CG_PROMPT_ARCHIVE_POLICY.md)归档。
2. 按事件 ID 核对游戏实际引用的资源键，将运行图放到 `Textures/Items/<资源键>.png`，按同名键替换草稿或补入缺失的正式纹理。
3. 核对接入文件能解码、尺寸为 960×540、哈希与定稿运行图一致，并检查事件仍引用该键。运行 `tools/check_project.py`。打包时用项目打包流程生成与本包纹理对应的 `release-files.json`。

## 已接入的示例

- [《看书害羞》](../Textures/Items/er_event_love_book_cg.png)（`love_night_book`）。从租屋 v3 整体洗画风，原画对齐眉眼，场景参考校准墙板和壁灯，整图复验时再收铜发亮边、合并白裙碎褶。
- [《再坐一会儿》](../Textures/Items/er_event_harem_lydia_date_cg.png)（`dv10`）。从上层区约会 v3 整体洗画风，校准莉迪亚脸部的像素线条，再重绘封闭中庭和人工照明，保留撑手回望与玫瑰裙。
