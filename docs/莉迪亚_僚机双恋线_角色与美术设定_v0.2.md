# 莉迪亚：明艳闺蜜千金与僚机双恋线

## 1. 核心人物

莉迪亚是27岁的成年女性，上层区家境宽裕的漂亮闺蜜。爱漂亮、爱热闹、喜欢浪漫故事，有一点小虚荣。她笑起来明亮，会主动靠近、追问进展，也知道自己打扮得好看。

她懂得观察埃莉诺，却没有自己以为的那么懂爱情。她觉得只要挑好地方、递对一句话，朋友就能顺利恋爱；安排被拆穿时会着急、嘴硬，有时自己也笑出来。真正被玩家认真关注时，她不再知道下一句该怎么说。

她是有成年生活能力、审美与判断的女人。甜美不等于幼稚无能，愿意撒娇不等于每件事都依赖男人。她可以逛街、帮熟悉店家布置展示，也会为自己的购买问清依据，不再以职业经纪人或社交女强人为主要定位。

保留她对下层区的旧偏见、镯子试探与关心朋友却过度安排的错误；改的是表现方式，不能用“其实她一直都很善良懂事”消除过去的行为。

## 2. 完全重设的视觉方向

| 部位 | v0.2方向 |
|---|---|
| 发型 | 蜂蜜棕长卷发，松松半扎，发尾蓬松，侧边小缎带或珍珠发夹 |
| 面容 | 明确成年，偏圆润的脸，琥珀色眼睛，柔和眉形，笑起来明亮；避免幼态大头比例 |
| 身材 | 丰满、柔软，腰线清楚，自然胸腰比例；性感来自整体与剪裁 |
| 上衣 | 奶油白方领，略低但不透明，轻盈袖子，露锁骨与适度胸线 |
| 裙装 | 柔和玫瑰色高腰裙，贴合腰胯，裙摆保留轻快活动感 |
| 饰品 | 小珍珠耳饰、细手链、浅色小包；一处简洁金属扣融入空间站风格 |
| 姿态 | 探头进店、拨发、坐近一点、转身展示新裙子；认真时会捻发尾、抚平裙腰 |

移除深栗短发、锐利眉眼、职业西装、黑金成套首饰和笔记夹的主视觉组合。不是在旧造型上换一个粉色领结，而是明确改变整体气质。

服装是日常逛街与见朋友可穿的衣服，不是舞会限定装。保持全年龄内容尺度，不用透视面料、裸露或情趣配件。全身设计可以突出裙形，小头像内则优先保留脸、卷发、发夹与方领。

## 3. 让吸引力随剧情改变

- 前期：主动调侃，坦然希望被夸。“好看就夸呀，我又不会瞪你。”她兴致勃勃地帮埃莉诺，不先对玩家发出恋爱承诺。
- 中期：玩家记得她自己的胸针、发夹和小失误。她原本接得住夸奖，认真动心后反而整理没歪的裙腰，说“今天不用练习”。
- 失落期：不再追问两人见面细节，借口也变得笨拙。少用眼泪，多用笑到一半停住、捻发尾又松开的动作。
- 确认后：仍活泼、爱漂亮，可以直接说想念，也能安静依偎。不是恋爱成功后突然改成无所不能的女主人。

不要把身体特征变成每场戏的主题。发夹和裙腰动作要少量使用、有前后呼应，不能每句台词都附一遍。

## 4. 人生、机会与回归逻辑

莉迪亚有亲友、爱好和自己的选择，不再持续以商务约见作为来访与离开的理由。她熟悉店家，能够打听实际空缺、陪埃莉诺看房；她不能决定雇主录用，也不能替官方签发通行或撤销母亲案件。

双恋甲线：她向熟悉商行询问是否有记录和到货核验岗位；埃莉诺试工，雇主决定录用并办手续。双恋乙线：保留研究方已有机会，她帮助住处和往来安排。

共同普通甲线仍可留在下层区；不因为更新莉迪亚的人设就统一搬迁。侍从线也不因她有熟人而跳过原筹备，拒绝空职位的剧情改成她热心问到机会后，陪埃莉诺把职责问清。

她不是靠资源赢得恋爱。埃莉诺接受双恋，不能被写成偿还介绍工作与照顾生活的人情。

## 6. 共同路线实施边界

第9、10章同步她的好奇、热心过头和旧偏见修正，镯子交易事实不变。第21章在未入双恋时表现友情与对原恋情的祝福，不含隐约告白。侍从称呼场景是闺蜜的惊讶与保密，不暗示她也想当侍从。悲剧时收起嬉闹，陪伴和听她说话，不以活泼冲淡母亲死亡。
